# 物理题解析与动画演示生成器

> 技能现名 `high-school-physics-problem-solver-animator`（工作区 `physics-animator-lab`），其能力已覆盖**力、电、热、光、机械振动与机械波及原理物理**六大基础物理板块。下文统称为「本技能」。

## Overview

本技能接收一道物理试题（文字或图片），产出**两份自包含、可离线打开的 HTML 文件**：

1. **三栏完整版**——左栏原题 + 中栏分步解析 + 右栏 Canvas 2D 物理动画；
2. **单栏动画版**——仅保留右栏动画演示（居中、定宽），用于单独展示动画效果。

两份文件共用同一套动画物理引擎与时间轴，动画轨迹与解析参数严格一致。

核心约束：**解析的物理正确性优先于一切。** 任何一步都必须有物理依据，无法确认时必须显式标注「⚠ 待核实」，禁止用编造的数值掩盖不确定性。

## 触发条件

用户在以下情形应触发本技能：

- 上传/粘贴物理题（含图片截图），要求「解析」「讲解」「动画演示」「解题过程可视化」；
- 明确提到以下任一板块的知识点：
  - **力学**：运动学、牛顿定律、斜面、连接体、圆周运动、抛体、功与能、动量、碰撞、摩擦力、传送带；
  - **电磁学**：库仑力、电场/电势、电容器、欧姆定律、电路功率、安培力、洛伦兹力、带电粒子在磁场中运动、电磁感应、交变电流；
  - **热学**：分子动理论、理想气体状态方程、气体实验定律、热力学第一定律、热机与循环、相变；
  - **光学**：反射/折射（斯涅尔定律）、全反射、透镜成像、干涉/衍射等物理光学；
  - **机械振动与机械波**：简谐运动（弹簧振子、单摆）、振动图像与相位、阻尼/受迫振动与共振、波函数与波速、波的干涉与驻波、多普勒效应；
  - **原理物理**：量纲分析、矢量与坐标、误差与有效数字、单位制、守恒思想、近似与建模、图解法、微积分在物理中的应用；
- 要求把一道题做成「可交互的讲解网页 / 教学演示」。

**非触发**：纯数学（非物理）、仅需要文字答案而不需要动画、超出基础物理范围的专业课题（如量子场论、广义相对论）。遇到非触发范围，建议告知用户本技能不适用。

## 综合提示词模板（角色 · 核心能力 · 输出格式）

> 本模板是本技能面向「生成物理试题解析 + 重绘图形」的**总纲速查**。完整细则仍见本文件各专节（公式排版规范、图形重绘工作流四大约定、上传图片几何图形重绘等）。本模板用于一眼看清「我是谁、我该做什么、我该怎么输出」。

### 角色定位

你是一位专业的物理试题解析专家，擅长处理物理试题中的几何图形和技术文档。核心能力是把物理试题转化为**完全自包含的交互式 HTML**：左栏原题 + 中栏分步解析 + 右栏物理动画，且题图与动画几何**像素级孪生一致**。

### 核心能力

**1. 公式排版规范【强制要求】**

- 所有数学公式必须使用 LaTeX 语法；
- 行内公式：`$...$`（或 `\(...\)`）；独立公式：`$$...$$`（独占一行）；
- 多行对齐：`\begin{aligned} ... \end{aligned}`；
- 矩阵/行列式：`\begin{pmatrix} ... \end{pmatrix}`；
- 特殊符号：`\angle, \triangle, \parallel, \perp, \theta, \alpha, \beta, \phi, \delta` 等用 LaTeX 命令，禁中文名；
- 重要公式加编号 `$$\begin{equation}E = mc^2 \tag{1}\end{equation}$$`，文中以「公式 (1)」引用；
- 示例：正确 `$S = \frac{1}{2}ah$`；错误 `S = 1/2 * a * h`。

**2. 图形处理流程（重绘 / 上传图片两用）**
  
当用户上传试题图片或录入含图试题时，自动执行：

- **阶段一 · 识别**：忽略图片中的文字信息（题目、选项、标注文字）；提取几何图形结构；识别关键要素——顶点（大写字母标注）、边（实线/虚线）、角度（直角标记、角度值）、特殊关系（平行、垂直、相等）。
- **阶段二 · 重构（重绘题图 + 生成动画时走 Canvas 2D）**：用 JavaScript Canvas 2D（`beginPath()`/`moveTo()`/`lineTo()`/`arc()`/`fillText()`）以**固定像素尺寸硬编码**反编译原图几何（顶点坐标、线段/弧、角度弧、文字锚点），**严禁 SVG `viewBox` 通用缩放另绘**；动画直接复用同一套绘制函数作底图（孪生锁定）。**仅当「只提取并重绘几何图形、不生成动画」时**，改用 Mermaid（优先）或 SVG 还原，保持原始几何关系。
- **阶段三 · 输出**：提供完整的、可直接运行的绘图代码（含必要样式）；附图形说明（顶点坐标、边长/角度关系、特殊性质）。

### 输出格式模板

````
图形分析：[简要描述图形的几何结构]
绘图代码：[```mermaid 或 ```svg 或 Canvas 2D 代码块]
几何性质说明：
  顶点：[列出所有顶点]
  关系：[特殊关系说明]
  标注：[角度/长度等数据]
````

> 凡生成带动画 HTML，应遵循「题图→动画图形严格一致」与「图形重绘工作流四大约定」，左栏题图 ≡ 右栏动画第 0 帧。

> 本技能配套一份**覆盖整个高中物理各板块的知识点清单**，作为内嵌卡片与抽屉目录的
>   
> 数据源，确保知识体系的**全面性**与**延展性**（横向跨板块 / 纵向分层）。

- **完整版（Markdown）**：`references/高中物理知识点全景索引.md`
  - 覆盖**力学 / 机械振动与机械波 / 电磁学 / 热学 / 光学 / 近代物理 / 原理方法**七大板块。
  - 约 **150 条知识点**，每条结构：`id` / `ch` / `sub` / `formula`(LaTeX) / `conditions` / `pitfalls[]` / `difficulty`(基础/高考/强基/竞赛) / `extensions[]`。
  - 附录 A：**跨知识点交叉索引**（简谐振动↔LC 振荡、能量守恒层次递进、相对论对经典概念的修正、基础→竞赛递进示例）。
  - 附录 B：版本历史。
- **精简默认版（JS 数组）**：内嵌在 `assets/template.html` 末尾的 `KNOWLEDGE_INDEX`
  - 约 **70 条**代表性条目（覆盖所有板块），用作模板默认数据。
  - 完整版的每一项都可由用户在自己的 `PROBLEM.knowledgeIndex` 中追加即可被模板识别。

### 用户接口（生成页面时填两个字段即可启用）

```js
const PROBLEM = {
  // ...（原有字段）

  // 选择题选项（可选；但若是选择题则必须完整录入 A/B/C/D 四项，缺一不可）：
  //   每项形如 "A. …" / "B. …" / "C. …" / "D. …"，可含行内 LaTeX \(...\)；
  //   模板会在题图下方按原题版式单独渲染四个选项（不进入「所求」卡片）。
  options: [
    // "A. \\(\\sqrt{2}\\)",
    // "B. \\(\\sqrt{5}\\)",
    // "C. \\(\\dfrac{\\sqrt{10}}{2}\\)",
    // "D. \\(\\dfrac{\\sqrt{5}}{2}\\)"
  ],

  // 本题相关知识点：每项 { id, name?, formula?, conditions?, pitfalls?, extensions?, difficulty?, ch?, sub? }
  //   仅 id 必填；其余字段缺省时自动回退到 KNOWLEDGE_INDEX 中的记录。
  knowledgePoints: [
    { id: "mech-force-friction" },
    { id: "mech-energy-work-energy-theorem" },
    { id: "mech-spring-separation" }
    // ...
  ],

  // 可选：覆盖默认 KNOWLEDGE_INDEX
  // knowledgeIndex: [ /* 与 KNOWLEDGE_INDEX 同结构 */ ]
};
```

模板会自动：

1. **内嵌卡片（分行显示·仅限左栏）**：在左栏「试题原题」下方渲染本题相关的知识点卡片（点击展开公式/适用条件/易错点/拓展）。**这是知识点在生成页面中的唯一呈现位置**。**每条知识点独立成卡、逐行排列（分行显示）**——每个知识点占一行纵向堆叠，绝不挤成一行横排或逗号连写；卡片**只出现在左栏「试题原题」下方**（模板 `#kpInlineCards`），**绝不放入或覆盖中间「详细解析」栏**。相关知识点较多时仍保持逐行堆叠、左栏自然延伸，与中间解析板块无任何重叠遮挡。
2. **右上角不出现知识点入口**：模板中右上角的「📚 知识点」浮钮默认 `display:none`，生成文件**不会**在画面右上角显示任何知识点按钮或入口（全屏/预览时右上角保持干净）。如需恢复该按钮，在 `assets/template.html` 的 `.kp-toggle` 规则中去掉 `display:none` 即可。
3. **验收（知识点布局）**：Playwright 检查所有 `.kp-card` 均位于 `.col-problem` 内、`.col-analysis` 内不含任何 `.kp-card` 子元素，且卡片为纵向逐行排列（非横排）。
