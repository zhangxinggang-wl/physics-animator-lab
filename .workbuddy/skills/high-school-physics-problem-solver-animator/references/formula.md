### 公式排版规范（强制）

> 本规范是**最高优先级约束**，覆盖所有领域、所有题目。任何生成的解析与 HTML 都必须满足；第 5 步的公式规则以本节为准。
>   
> **2026 修订新增**（标准定界符 `$...$`/`$$...$$`、公式编号 `\tag`、多行 `aligned`、矩阵 `pmatrix`、以及「上传图片几何图形重绘 Mermaid/SVG 工作流」）见本文件新增的「## 公式与符号规范」与「## 上传图片几何图形重绘」两节，二者与本节约束**同源、同等强制**。
>   
> **覆盖范围含「每一问详细解析最后一行（结论式）」**：每一问解析收尾那一行用到公式时，该行的**每一个公式**也必须逐条满足本规范的六点 LaTeX 规范与四点 HTML 技术要求，不得因为「只是结论」就放松。

#### 一、LaTeX 公式语法（核心要求）

1. **全部使用 LaTeX**：所有数学公式——**包括题目原文与解析**——必须用 LaTeX 语法编写，**严禁使用纯文本近似或程序代码风格**（如 `1/2`、`sqrt(x)`、`v0`、`x2`、`sin(x)`、`E_m/sqrt(2)` 这类写法一律禁止）。
2. **具体转换规则（必须逐项落实）**：
   - 分数：`\frac{分子}{分母}`，必要时用小分数 `\tfrac{1}{2}`；**禁止用 `/` 表示分数**。
   - 根号：`\sqrt{被开方数}`，多重根号用 `\sqrt[n]{...}`。
   - 上下标：`x^2`（上标）、`v_0`（下标）；多字符上下标用花括号 `v_{x0}`。**下标在两类语境写法不同（强制）**：① **题图 Canvas 2D 标签**——经 `FIG.text`/`FIG.vec` → `ctx.fillText`，不经 MathJax，下标必须用 **Unicode 下标字符** `R₁`/`R₂`/`v₀`，**禁止写字面 `R_1`/`v_0`**（canvas 无法渲染 LaTeX，会原样显示下划线）。② **HTML 文本语境**（题面 `given`/`asks`、解析 `note`、步骤 `title`、数据面板名称 `r[0]`）经 MathJax 排版，下标必须写进 LaTeX 行内定界符；但注意 **这些字段写在 JS 字符串字面量里**，源码里的反斜杠必须写成**双反斜杠** `\\(R_1\\)` / `\\(v_0\\)`（单 `\(` 会被 JS 解析成普通括号 `(`，导致整段 `given`/`asks` 数学完全不被排版、下标原形毕露），或用单美元号 `$R_1$` / `$v_0$`（美元号在 JS 字符串里无需转义，最省心）。**禁止裸露 `R_1`/`R_2`/`v_0`**。
   - 希腊字母：`\alpha \beta \gamma \theta \phi \omega \pi \mu \lambda \rho \sigma \Delta \Sigma` 等，**禁止用中文或 Unicode 近似**（如 `½`、`√`、`→` 取代公式语义）。
   - **角度符号强制（θ α β φ δ，禁止中文名）**：物理常用角度一律用其**符号** $\theta$（西塔）、$\alpha$（阿尔法）、$\beta$（贝塔）、$\phi$（斐）、$\delta$（德尔塔）表示，**禁止写成「西塔 / 阿尔法 / 贝塔 / 斐 / 德尔塔」等中文名，也禁止 Unicode 近似**；LaTeX 命令须为 `\theta \alpha \beta \phi \delta`（磁通量等用大写 `\Phi`）。**随时间变化的角度必须用 $\theta(t)$ 或 $\phi(t)$ 表示**（如单摆摆角 $\theta(t)$、简谐波相位 $\phi(t)$），不得只写裸 $\theta$/$\phi$——否则看不出它是时间变量。
   - 三角函数/双曲：`\sin`、`\cos`、`\tan`、`\cot`、`\sec`、`\csc`，**禁止省略反斜杠**。
   - 矢量：`\vec{v}` 或 `\mathbf{v}`（建议矢量加箭头 `\vec{}`）。
   - 导数：一阶 `\frac{dv}{dt}` 或牛顿点记法 `\dot{x}`、`\ddot{x}`；偏导 `\frac{\partial y}{\partial t}`。
   - 积分：`\int_a^b f(x)\,dx`（微分前用 `\,` 加间隔）。
   - 单位：**强制「正体（upright）」写法**——物理量单位必须正体，禁止斜体。两种合规写法：① **首选：单位作纯文本置于公式环境外**（源码干净、天然正体），如 `$m_A=0.4$ kg`、`$g=10$ m/s²`、`$v_0=2$ m/s`；② **单位必须嵌在数学式内时**（分式、复合量等无法外提），用 `\mathrm{}` 强制正体，如 `$a=9.8\,\mathrm{m/s²}$`、`\(\sim300\,\mathrm{K}\)`。**禁止**把单位裸写在公式环境内却不包裹（如把 `m/s`、`kg` 直接放进 `$...$` 会渲染成斜体，正是「单位用了斜体」的根因）；**禁止**用 Unicode 近似（如把 m/s 写成「米/秒」）。详见第 7 项。
3. **行内公式定界符**：`\( ... \)`。出现在 `note`/`given` 等文字中的公式必须如此包裹，例如 `匀强磁场 \(B = 0.10\) T`（单位 T 作为公式后的纯文本，天然正体）。
4. **独立成行公式定界符**：`\[ ... \]`（也可用 `$$ ... $$`）。独立公式独占一行、居中显示。
5. **HTML 必须【自包含 MathJax 3】（强制）**：生成文件必须**把 MathJax 3 渲染引擎（SVG 版 `tex-mml-svg.js`）直接内联进 `<script>`**，完全离线、不依赖任何 CDN；行内 `\(...\)`、独立 `\[...\]` / `$$...$$` 均由该内联引擎渲染。模板 `assets/template.html` 已内置此内联引擎，复制后**勿改动其 MathJax 配置、勿把内联引擎改回 CDN 外链**——否则在无网/被墙的机器上，公式会回退成原始 LaTeX 源码（`\[ t_1 = \frac{...} \]`），这正是「公式问题没解决」的根因。
6. **题目原文公式也要转换**：题干、已知条件、图示标注里的公式（如 `B=0.5T`、`v0=2m/s`、`y=Asin(ωt)`）**同样按上述规则改写为 LaTeX**（`\(B = 0.5\) T`、`\(v_0 = 2\) m/s`、`y = A\sin(\omega t)`），不能遗漏、不能保留代码风格。

> ### ⚠ 最终答案（结论式）公式的强制要求（最高优先级）
>
> **每一问解析「最后一行结论式」里的所有数学内容都必须用 LaTeX 书写**，不得写成纯文本或代码风格。这是用户反复指出的痛点，生成时务必逐字符核对。常见错误与正解对照：
>
> - ❌ 错误：`h=0.10m`、`v=28.3m/s`、`ΔE=6J`、`t=3.53s`（等号直接连裸数字与单位，未进入公式环境）
> - ✅ 正解：`h = 0.10\,\mathrm{m}`、`v = 28.3\,\mathrm{m/s}`、`\Delta E = 6\,\mathrm{J}`、`t = 3.53\,\mathrm{s}`
> - ❌ 错误：`v=sqrt(vx^2+vy^2)`、`F=m*v0^2/R`、`a=1/2*g*t^2`
> - ✅ 正解：`v = \sqrt{v_x^{2} + v_y^{2}}`、`F = \frac{m v_0^{2}}{R}`、`a = \frac{1}{2} g t^{2}`

```
> 要点：单位必须正体——**首选把单位写成公式环境外的纯文本**（如 `$v_0=2$ m/s）；当单位必须嵌在数学式内时，用 `\mathrm{}` 强制正体**（如 `$v=10\,\mathrm{m/s}$`）；等号、加减乘除、上下标、根号、希腊字母、三角函数、矢量、积分、导数**一律 LaTeX 化**，绝不允许在结论行出现 `=`、`/`、`sqrt(`、`v0`、`sin(` 这类原始符号。
```

> **「最后答案」与前面步骤公式共用同一条渲染管线（关键）**：模板在 `renderSteps` 中会把**每一问的最后一个步骤**自动加上 `答` 前缀并高亮（`.step.answer`），该步骤的 `tex` 字段即本问的【最后答案】——它和前面每一步的公式走**完全相同的 `\[...\]` 渲染管线**，排版（居中、分式、根号、上下标、单位正体）与前面的公式**完全一致**，不存在「结论行排版更随意」的例外。
>   
> 步骤下方的「说明 / 依据」（`note` / `basis`）由模板以 `innerHTML` 渲染并交给 MathJax 处理，其中**任何公式都必须用 `\(...\)` 行内 LaTeX 包裹**（如 `竖直上抛分运动，由 \(v_{0y}=gt_1\) 得`）；若不包裹，公式会以原始代码（如 `v_{0y}=gt_1`）形式裸露显示，与前面公式的规范排版脱节——这正是用户多次指出的「最后答案公式不规范」的根因之一。

1. **单位 / 角度 / 变化量 / 根号 的强制写法与禁止项（防止「公式没渲染」误判）**：以下四类写法适用于**所有文字字段**（`given` / `note` / `basis` / `readouts` 名称 / `tex` / 每问结论式），**不限于 `tex`**：
   - **单位（强制「正体 upright」写法）**：物理量单位必须正体，**禁止斜体**。两种合规写法：① **首选——单位作为纯文本写在公式环境外**（天然正体、源码干净），如 `$m_A=0.4$ kg`、`$g=10$ m/s²`、`$x_0=0.1$ m`、`$v_C = 3.0$ m/s`；② **单位必须嵌在数学式内时**（分式、复合量、量纲式等无法外提），用 `\mathrm{}` 强制正体，如 `$a=9.8\,\mathrm{m/s²}$`、`$\sim300\,\mathrm{K}$`、`$\frac{20\,\mathrm{m/s}}{4\,\mathrm{s}}=5\,\mathrm{m/s²}$`。**禁止**把单位裸写在公式环境内却不包裹（如 `m/s`、`kg` 放进 `$...$` 会被当成变量渲染成斜体，正是「单位用了斜体」的根因）；**禁止**嵌套 `\mathrm{\mathrm{kg}}`。
   - **电阻 / 面积 / 体积单位符号（强制）**：① **电阻**单位一律用字面符号 `Ω`（欧姆），**禁止** `\Omega` 等 LaTeX 命令、禁止 `Ohm`/`ohm` 英文单词；数值与单位间用细空格（方程字段 `\,Ω`）或紧贴公式后的纯文本（文字字段 `\(R=2\) Ω`）。② **面积 / 体积**一律用 Unicode 上标 `m²`/`cm²`/`mm²`/`km²`/`m³`/`cm³`/`mm³`/`km³`，**禁止** `m^2`/`m2`/`m^3`/`m3` 这类代码式写法——尤其不能把 `^2`/`^3` 留在公式环境（`\(...\)`/`$$...$$`）之外的裸文本里（会原样显示成 `m^2`，正是「面积单位不规范」的根因）；方程字段内也建议直接写 `m²` 而非 `m^2`。③ **加速度**单位一律用 Unicode 上标 `m/s²`，**禁止** `m/s^2`/`m/s2` 这类代码式写法——尤其不能把 `^2` 留在公式环境（`\(...\)`/`\[...\]`）之外的裸文本里（会原样显示成 `m/s^2`）；方程字段内也建议直接写 `m/s²` 而非 `m/s^2`。
       
     **在支持 JS 的浏览器中**：公式环境外的纯文本单位天然正体；公式环境内用 `\mathrm{}` 包裹的单位也渲染为正体。**注意**：裸写在公式环境内的单位（如把 `m/s` 放进 `$...$` 不加 `\mathrm`）会被当成变量显示为斜体，必须按上方两种写法之一处理。
   - **角度 / 度**：用 `\^{\circ}`，如 `60\^{\circ}`、`\theta=60\^{\circ}`。**禁止** Unicode 字符 `°`、禁止 `^o` / `^0`、禁止 `度` 字（如 `60度`）。
   - **变化量（Δ）**：用大写 `\Delta`，如 `\Delta E`、`\Delta s`、`\Delta t`。**禁止** Unicode `△`。
   - **根号**：用 `\sqrt{被开方数}`，如 `\sqrt{v_x^{2}+v_y^{2}}`、`\sqrt{2gh}`。**禁止** Unicode `√`、禁止 `sqrt()`。
2. **Math input error 零容忍（强制）**：解析与题面中的**每一处 LaTeX 都必须可被 MathJax 成功解析**，绝不允许出现 `Math input error` 红字报错。常见根因与规避：① **JS 字符串里的反斜杠必须写成双反斜杠**：写在 `given`/`asks`/`note`/`basis`/`title`/`tex` 这些 JS 字符串字面量中的 LaTeX（如 `\\(v_0\\)`、`\\frac{1}{2}`、`\\cos`）反斜杠必须转义为 `\\`，单写 `\(` 会被 JS 当作普通括号、整段公式不被排版而裸露出 `_0`/`frac` 等导致解析失败；或改用美元号 `$v_0$`/`$$...$$`（美元号在 JS 字符串里无需转义，最省心）。② **花括号必须成对**：`\frac{分子}{分母}`、`\sqrt{...}`、`_{...}`、`^{...}` 缺右花括号会整条公式报错。③ **只用语雀/ MathJax 支持的标准命令**：`\dfrac` `\tfrac` `\mathrm` `\vec` `\mathbf` `\hat` `\dot` `\ddot` `\partial` 等可用；**禁止自造宏或拼写错误命令**（如把 `\vec` 误写为 `\mv`）。④ **中文/汉字不得进入数学环境**：物理量的中文名须放在 `\(...\)` 之外（如 `质量 \(m=2\) kg`），把 `质量` 写进 `$质量$` 会让 MathJax 把汉字当变量并极易报错。⑤ **行内与独立定界符不可混用**：`\(...\)`/`$...$` 行内、`\[...\]`/`$$...$$` 独立，二者不可交叉（如 `\(...$$`）。生成后**必须**用 Playwright 断言：页面中 `mjx-container.mjx-error` 数量为 0，且 `document.body.innerText` 不含 `Math input error`（见「## 质量门禁」第 25 条）。

#### 二、HTML 技术要求

- **三栏布局（强制）**：页面主体固定为左—中—右三栏，顺序不可调换：
  - **左栏：试题原题**（题干 + 已知条件 + 所求，含题目的原始配图信息）
  - **中栏：详细解析**（五个步骤卡片，逐步骤含公式、说明、物理依据）
  - **右栏：动画显示**（Canvas + 播放/重播/时间轴滑块 + 时间读数）
- **禁止倍速下拉控件**：右侧动画控件只允许「播放按钮、重播按钮、时间轴滑块、时间读数」四类元素，**不得出现任何带上下三角的 `<select>` 倍速下拉**（用户明确要求取消）。模板已移除，勿再加回。
- **MathJax 3 引擎（已内联、完全离线自包含）**：模板已把 MathJax 3.2.2 的 SVG 版引擎 `tex-mml-svg.js` 直接内联进 HTML，**无需联网即可渲染**；SVG 输出不依赖任何外部字体文件，是真正的单文件自包含。若内联引擎因极端情况未能启动，10 秒后降级为去定界符的 LaTeX 原文显示（仅兜底，正常不会触发）。
- **字体大小适中**：正文 14–16px、公式可读、行距舒适，避免拥挤或过小。
- **题目与解析分区清晰**：原题（左）、解析（中）、动画（右）三区各有独立卡片容器与标题，视觉边界明确，不得混排。
- **交互控制（强制）**：动画区必须提供 5 类控件——**播放/暂停**、**上一步**、**下一步**、**重置**、**时间轴滑块**。「上一步／下一步」按 `STEPS` 的 `t0` 时间锚点跳转并暂停，做到「点一次推进一个解析步骤」；「重置」回到 `t=0` 并清空高亮。
- **数据面板（强制）**：动画区下方必须有「数据面板」，内含三块——① 当前解析步骤标题；② 该步骤的完整说明文字（含行内公式，由 MathJax 渲染）；③ 关键实时数据网格（数值每帧刷新）。面板是「解析—动画」一致性的核对窗口，不可省略。
- **数据面板里的字母符号与详细解析同规范（强制）**：① 红色三角右侧的「当前解析步骤标题」通过 `panelStep.innerHTML = "▶ " + s.title` 写入，并随 `typesetEls([panelNote, panelStep])` 走与解析同一条 MathJax 渲染管线，标题里的 `\(v_A\)`、`\(a'_B\)` 等必须呈现规范斜体 + 上下标，**不得出现字面 `\(`/`\)`/`\quad`/`\boldsymbol`**。② 数据网格 `.kv` 的名称里含字母符号时同样要规范——把名称写成 `\(s_A\)`、`\(v_A\)`、`\(\Delta s\)` 等，再用持久单元格（行结构按行数缓存，每帧只更新数值 `v.firstChild.nodeValue` 与 `u.textContent`，名称里的 MathJax 只排版一次）保证不卡帧。`readouts()` 名称字段里出现字母符号时，**必须用 `\(...\)` 包裹**才能进入这条渲染管线；写裸字符串 `v_A` / `a'_B` 只会以字面下划线 / 西文撇号显示，与解析风格不一致。
- **步骤联动**：播放时中间栏当前步骤卡片自动高亮（`.step.active` 橙红色）并滚动到可见区，学生随时知道「现在演到解析的哪一步」。
- **解析栏禁止内部滚动（强制）**：中间栏**不得**设置 `max-height` + `overflow:auto`——那会产生一条独立的右侧滚动条，把公式折叠在看不见的地方。正确做法是让五个步骤与公式**上下完整平铺**，需要时由浏览器整页滚动。
- **公式区不得出现滚动条、行距要紧凑（强制）**：`.step .tex` 必须隐藏横向滚动条外观（`scrollbar-width:none` 与 `::-webkit-scrollbar{display:none}`）。**独占一行数学公式的上下行距要适当收紧**（用户要求）：模板把 `.step .tex` 设为 `padding:2px 2px 6px`、`line-height:1.6`，并压缩 MathJax 显示公式自带的大段留白（`.step .tex mjx-container[display="true"]{margin:.12em 0}` 与 `.step .note mjx-container[display="true"]{margin:.12em 0}`）。验收标准：公式容器 `scrollWidth - clientWidth === 0`，MathJax 输出不被上下裁剪即可。
- **左右栏吸附**：`.col-problem`、`.col-animation` 设 `position:sticky; top:14px`——滚动查看长解析时，题目与动画始终留在视野内。
- **改变窗口大小后动画不空白（模板已修复）**：`resize()` 重置 `cv.width` 会清空【动画】画布，而 `drawFigures()` 只补画左栏题图。模板现已在 `resize()` 末尾补调 `render()`（并先把 `lastStage` 复位，保证 `updatePanel` 重新点亮当前步骤）。校验方法：Playwright 先截图／`page.setViewportSize()` 触发 resize，再取 `#cv` 的 `getImageData` 统计非白像素，应 > 0。

### 公式与符号规范（标准定界符 · 公式编号 · 多行推导 · 2026 修订）

> **适用范围**：本技能「试题重新录入」、各参考手册（`references/*.md`）以及所有对外技术文档。与既有 `\(...\)` / `\[...\]` 写法**并存**（HTML 模板的 MathJax 同时渲染两种定界符），但**新写内容一律首选 `$...$` / `$$...$$`**。

#### 一、数学公式规范（强制）

1. **行内公式**：用单个美元符号包裹 —— `$公式$`。
     
   例：`匀强磁场 $B = 0.10$ T，初速度 $v_0 = 2$ m/s`。
2. **独立公式**：用双美元符号包裹并**独占一行** —— `$$公式$$`。
3. **多行公式**：用 `aligned` 环境按等号对齐（每行以 `\\` 换行）：
     
   `$$\begin{aligned} f(x) &= ax^2 + bx + c \\ &= a\Bigl(x+\frac{b}{2a}\Bigr)^2 + c - \frac{b^2}{4a} \end{aligned}$$`
4. **所有数学符号用 LaTeX 标准命令**：
   - 分数 `\frac{分子}{分母}`（必要时 `\tfrac{1}{2}`）；
   - 上下标用 `^` 与 `_`（多字符加花括号，如 `v_{x0}`）；
   - 根式 `\sqrt{被开方数}`，多重 `\sqrt[n]{...}`；
   - 希腊字母 `\alpha\ \beta\ \theta\ \pi\ \mu\ \omega\ \Delta` 等（禁 Unicode 近似）；
   - 三角函数/双曲 `\sin\ \cos\ \tan`；导数 `\frac{dv}{dt}`、偏导 `\frac{\partial y}{\partial t}`、积分 `\int_a^b f(x)\,dx`；单位**强制正体**：首选公式环境外纯文本（`$g=10$ m/s²`），必须嵌在数学式内时用 `\mathrm{}`（如 `$10\,\mathrm{m/s}$`、`$\,\mathrm{J}$`）；**禁止**把单位裸写在公式环境内却不包裹（会渲染成斜体）。
5. **向量**：`\vec{v}` 或 `\mathbf{v}`（建议运动学矢量用 `\vec{}`，矩阵/张量用 `\mathbf{}`）。
6. **矩阵**：用 `pmatrix` 环境，不用 `array` 或文本近似：
     
   `$\begin{pmatrix} a & b \\ c & d \end{pmatrix}$`、
     
   `$\begin{pmatrix} F_x \\ F_y \end{pmatrix} = \begin{pmatrix} m & 0 \\ 0 & m \end{pmatrix}\begin{pmatrix} a_x \\ a_y \end{pmatrix}$`。

#### 二、公式编号与引用（重要公式必加）

- 需要引用的重要公式统一编号（编号右对齐，由 MathJax 自动渲染）：
    
  `$$\begin{equation} E = mc^2 \tag{1} \end{equation}$$`
- 文中引用用「公式 (N)」句式：「如**公式 (1)** 所示」「联立**公式 (2)(3)** 解得……」「将**公式 (4)** 代入**公式 (1)**」。
- 多步推导用 `aligned` 并在末行 `\tag{}`：
    
  `$$\begin{aligned} f(x) &= ax^2 + bx + c \\ &= a\Bigl(x+\frac{b}{2a}\Bigr)^2 + c - \frac{b^2}{4a} \tag{2} \end{aligned}$$`

> 各参考手册「核心公式速查」中的关键公式已按本规范加 `\tag{}` 编号；正文以「公式 (N)」引用，便于跨手册对照。

#### 三、与既有写法的兼容说明

- 本技能 HTML 模板的 `STEPS[].tex` 字段由模板自动以 `\[...\]` 包裹、`note`/`given` 文字字段以 `\(...\)` 渲染；二者与 `$...$` / `$$...$$` **等价**，MathJax 均支持。
- **新写文档/手册一律用 `$...$` / `$$...$$`**；仅在维护旧模板内部代码字符串时保留 `\(...\)` / `\[...\]`。
- 模板 MathJax 配置已同时启用 `['$','$']` 与 `['\\(','\\)']` 行内、`['\\[','\\]']` 与 `['$$','$$']` 独立，故两种写法生成的页面都能正确渲染。

### 公式渲染原理与正确查看方式（防误判 · 强制阅读）

> 用户曾因在「不执行 JavaScript 的环境」中查看本技能生成的 HTML，看到原始 LaTeX 源码，误判为「公式没渲染 / 单位前有多余 \mathrm / 度的上标不对 / 根号不对」。本节说明原理与正确查看方法，避免此类误判。
>   
> \> **本技能已采用「单位强制正体（upright）」规范**：物理量单位一律正体、禁止斜体。实现方式——① 首选把单位写成公式环境外的纯文本（天然正体、源码干净，如 `$g=10$ m/s²`）；② 必须嵌在数学式内时（分式、复合量），用 `\mathrm{}` 强制正体（如 `$a=9.8\,\mathrm{m/s²}$`）。数学符号（`\Delta` 变化量、`\sqrt{}` 根号、`^{\circ}` 度）因无等价的纯文本写法，必须保留 LaTeX 命令——它们在支持 JS 的浏览器中正常渲染为 Δ/√/°；若在不执行 JS 的查看器里看到这些源码（含单位里的 `\mathrm{}`），属正常的「查看方式问题」，并非生成缺陷。

1. **公式是 LaTeX 源码，由运行时 MathJax 渲染**：本技能所有公式以 LaTeX 源码写入 HTML，文件内置 **MathJax 3（SVG 版）脚本**；浏览器打开后，该脚本把 LaTeX 画成标准数学符号。**渲染依赖 JavaScript 执行**——`<script>` 必须运行。
2. **正确查看方式（唯一权威）**：用**支持 JavaScript 的浏览器**打开生成的 `.html` 文件（双击用 Chrome / Edge / 系统默认浏览器；WorkBuddy 预览面板基于 Chromium，同样可正常渲染）。打开后公式应为排版好的数学符号，**不是反斜杠源码**。
     
   3\. **误判来源**：若用**不执行 JS 的环境**查看——部分 Markdown 预览器、某些聊天 / 网盘 / IM 内置预览、或直接阅读 HTML 源码——页面会显示**原始 LaTeX 文本**：数学符号（`\Delta`、`\sqrt{}`、`^{\circ}`、`\theta` 等）以及公式中单位里的 `\mathrm{}` 会作为源码出现。**这是查看方式问题，不是生成缺陷**——请用支持 JS 的浏览器打开以获得规范排版（单位正体、公式排版正确）。
3. **自检（交付前用 Playwright 或浏览器开发者工具）**：
   - 公式已渲染：页面存在 `mjx-container` 元素（数量应与公式数一致），且看不到 `\^{\circ}` `\Delta` `\sqrt{` `\(` `\)` 这类未排版的原始命令；单位里的 `\mathrm{}` 应已渲染为正体而非源码；
   - 控制台无报错（无 `ReferenceError` / `SyntaxError`）；
   - canvas 已绘制非空白（动画正常）。
4. **离线自包含**：MathJax 已内联，无需联网；即使断网，在支持 JS 的浏览器中仍正常渲染。

### 解析正确性门禁（强制）

用户反馈过「解析有时出错」。因此**每道题在输出 HTML 前，必须逐条通过以下 7 项校验**；任一项不通过就修正后重做，不得带疑点交付。

1. **范式对照**：解析所用的公式与思路，必须能在对应领域手册**第 8 节「典型题型正解库」**&#x4E2D;找到同类范式或可直接类比的标准形式。若属手册未覆盖的新题型，须先用 WebSearch 核对权威解法，再动笔。
2. **逐步骤复核**：五个步骤逐步自查四件事——① 所引定律名称与适用条件；② 公式形式（与手册第 2 节 / 第 8 节逐字符对照）；③ 代入的数值与单位；④ 中间结果与最终结果。
3. **量纲校验**：每个最终结果单独做量纲检验（量纲表见 `principles_reference.md` 第 8.1 节）。量纲不符，必是错误。
4. **极限检验**：令关键参数取 (0) 或极值（如 (m_2\to\infty)、(\theta\to 0)、(v_0\to 0)），结果应符合物理直觉。
5. **数量级检验**：结果与常见物理尺度对照（声速 (340) m/s、子弹 (\sim10^{3}) m/s、分子直径 (\sim10^{-10}) m、室温 (\sim300) K）。明显超出范围，必是计算错误。
6. **易错点扫描**：对照对应手册第 4 节「易错点」以及第 8 节每条示例末尾的「易错」提示，逐项排除。
7. **闭环检查**：最终结论必须正面回答题目所问并标注单位；若为选择题，须在 `PROBLEM.options` 完整录入 A/B/C/D 四项，解析中给出正确选项字母并说明其余选项为何错。
8. **最后答案公式规范（强制）**：每问最后一个步骤的 `tex` 必须是规范 LaTeX（数值 + 单位**强制正体**——首选纯文本（如 `$v=3$ m/s`），单位必须嵌在数学式内时用 `\mathrm{}` 强制正体（如 `1.2\,\mathrm{m/s}`），**禁用**斜体裸写（如把 `m/s`、`kg` 直接放进 `$...$` 会渲染成斜体）；分式/根号/上下标齐全），它会被模板自动标记为「答」并高亮，与前面步骤公式共用同一条 `\[...\]` 渲染管线；步骤下方的 `note`/`basis` 说明文字中出现的**任何公式都必须用 `\(...\)` 行内 LaTeX 包裹**。交付前用浏览器真渲染验证：确认全页 `mjx-container` 数量与公式数一致，且说明文字中无 `\(` 或 `v_{` 之类的原始 LaTeX 代码裸露。

**禁止事项**

- 严禁凭印象写公式——拿不准就用 WebSearch 核对权威来源。
- 严禁跳过量纲检验与极限检验。
- 严禁把未核实的中间结果直接用于下一步（错误会级联放大）。
- 确有疑点时，在该步骤设 `flag:true` 并写明疑点，**绝不允许编造数值**。
