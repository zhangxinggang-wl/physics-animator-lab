### 质量门禁（每题必做）

1. **物理正确**：通过对应领域参考手册第 5 节自检清单，并**逐条通过「## 解析正确性门禁（强制）」的 7 项校验**；无 `flag` 之外任何编造数值。
2. **解析闭环**：最终答案单位规范、回到题目所问。
3. **动画一致**：空间几何由与解析相同的参数公式驱动；`SIM.duration` 与物理过程时长一致（微观极快过程按第 4 步约定做时间轴放慢并标注）。
4. **语法可运行**：抽取内联 JS 通过 `node --check`。
5. **离线健壮**：MathJax 加载失败时降级为原文（去掉定界符的 LaTeX 文本）显示（模板已内置）。
6. **公式排版合规**：所有公式（含题目原文）均为标准 LaTeX 且定界符正确，无 `/` 分数、`sqrt()`、`v0`、`sin()` 等代码风格残留（对照「## 公式排版规范（强制）」与「## 公式与符号规范」）。新写内容须用 `$...$` 行内、`$$...$$` 独立；重要公式已加 `\tag{}` 编号并以「公式 (N)」引用。
7. **版面合规**：三栏布局正确（左＝原题、中＝解析、右＝动画），且**HTML 中不存在任何 `<select>` 倍速下拉控件**（用 `grep -n "<select" 输出文件` 检查，应无结果）。
8. **无滚动条、无裁剪**：解析栏 `scrollHeight - clientHeight === 0`（无内部滚动区）；每个公式容器 `scrollWidth - clientWidth === 0` 且 MathJax 输出未被上下裁剪。用 Playwright 在 1280 / 1366 / 1600 / 1920 四种宽度下各测一遍。
9. **渲染验证**：交付前用 Playwright（或等价无头浏览器）打开生成的 HTML，确认 `mjx-container` 数量 > 0、控制台无报错、公式已渲染（非原始 LaTeX 文本）。
10. **数据面板一致性**：抽样若干关键时刻（每步区间的中点、以及每个「关键结论出现的时刻」如最高点/落地瞬间/碰撞瞬间），核对数据面板显示的数值与解析结论**逐位一致**；并确认步骤高亮随播放推进、「上一步／下一步」按步跳转、「重置」回到 `t=0`。任一处不符即修正后重验。
11. **题图完整显示（含 Canvas 孪生锁定静态端）**：若题目含图，用 Playwright 检查题图确实位于 `#problemBody` 内部（题干区）。题图有两种形态，均须满足「非空白、已绘制」：① 嵌入原图时存在 `<div class="fig"><img>`，且 `img.complete && img.naturalWidth > 0`；② 生成式 / Canvas 重绘时存在 `<div class="fig"><canvas class="fig-canvas">`，且 `canvas.width > 0 && 该 canvas 非全白（已绘制几何）`。不可遗漏或外链失效。
12. **多问分组正确**：若题目多问，检查原题区 `<ul class="asks">` 中 `li` 数量等于问数（每问独立成行），解析区 `<div class="qblock">` 数量等于问数（每问独立成块），且各块内步骤数与 `STEPS` 中的 `q` 分布一致。
13. **图-动画孪生一致（Twin-Lock 像素级重合）**：左栏题图与右栏动画**不是两张图**，而是同一套 `drawSceneBody()` / `drawStaticGraph()` 的静态端（t=0）与动画端。右栏动画所有几何元素用 `FIG.*` 图元库（或自定义 `ctx`）绘制，且与左栏题图在世界坐标、比例尺、物块大小/位置/标注、角度、长度比例上**像素级一致**（QA 方法：动画暂停于 t=0，截图与左栏题图叠加应对齐；严禁右栏另用 SVG `viewBox` 重画导致坐标漂移）。
14. **知识点体系（分行显示·不覆盖解析）**：若 `PROBLEM.knowledgePoints` 非空，左栏内嵌卡片数 = 引用条数；每条知识点**独立成卡、逐行排列（分行显示）**，在卡片中展开公式/适用条件/易错点。卡片**只出现在左栏「试题原题」下方**，**绝不放入或覆盖中间「详细解析」栏**；相关知识点较多时仍逐行堆叠、左栏自然延伸。右上角不得出现「📚 知识点」浮钮（`.kp-toggle` 默认 `display:none`）；右抽屉 `kpDrawer` 默认不可见、不影响三栏布局。

### 注意事项

- 输出语言默认中文；公式用 MathJax 渲染的 LaTeX——**新写内容首选行内 `$...$`、独立 `$$...$$`**（与既有 `\(...\)` / `\[...\]` 等价，模板 MathJax 均支持）；重要公式用 `\tag{}` 编号并以「公式 (N)」引用。
- 若题目含多物体/多过程，拆分为多个子步骤，动画可分段或整体时间轴表示。
- 优先使用对应领域的参考手册，避免跨领域套用不成立的定律（如把力学动量守恒直接套到电路问题）。
- 凡涉及专业常数（如 `k`、`\varepsilon_0`、`\mu_0`、`R`、`\sigma` 等），务必注明数值与单位，必要时用 WebSearch 核对。
```
