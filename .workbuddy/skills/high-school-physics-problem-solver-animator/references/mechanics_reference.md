## 2. 核心公式速查（均用国际单位制 SI，标准 LaTeX）

### 2.1 运动学
- 匀变速直线运动：$v = v_0 + a t$，$x = v_0 t + \tfrac{1}{2} a t^2$，
$$ v^2 - v_0^2 = 2 a x\tag{4}$$
- 自由落体：$h = \tfrac{1}{2} g t^2$，$v = g t$，$g \approx 9.8\,\mathrm{m/s²}$（常取 9.8 或 10，需注明）
- 竖直上抛：上升到最高点时间 $t = v_0/g$，最大高度 
$$ H = v_0^2/(2g)\tag{5}$$
- 平抛：水平 $x = v_0 t$；竖直 $y = \tfrac{1}{2} g t^2$，$v_y = g t$；合速度 
$$ v = \sqrt{v_0^2 + (g t)^2}\tag{6}$$
- 斜抛（仰角 $\theta$）：$x = v_0 \cos\theta \cdot t$，
$$ y = v_0 \sin\theta \cdot t - \tfrac{1}{2} g t^2\tag{7}$$
  - 射高 $H = \dfrac{v_0^2 \sin^2\theta}{2g}$，射程 $R = \dfrac{v_0^2 \sin 2\theta}{g}$，飞行时间 
  $$ T = \dfrac{2 v_0 \sin\theta}{g}\tag{8}$$
- 相遇/追及：列方程 $x_A(t) = x_B(t)$，注意初始位置差与速度差

### 2.2 牛顿第二定律
- $\sum \vec{F} = m \vec{a}$（矢量，须按坐标轴分解）
- 斜面（倾角 $\theta$，沿斜面向下为正）：$a = g(\sin\theta - \mu \cos\theta)$（下滑、动摩擦 $\mu$）
- 静摩擦：$0 \le f \le f_{\max} = \mu_s N$，先假设静摩擦再验算是否超过极值
- 连接体（轻绳/轻杆，加速度相同）：整体法求 $a$，隔离法求张力 
$$ T\tag{9}$$
- 超重/失重：视重 $N = m(g \pm a)$（向上加速取 $+$）

### 2.3 圆周运动
- 向心力：
$$ F_n = \dfrac{m v^2}{r} = m \omega^2 r = m \left(\dfrac{2\pi}{T}\right)^2 r\tag{10}$$
- 竖直圆周最高点临界（绳模型）：$v_{\min} = \sqrt{g r}$；杆模型最高点可为 
$$ 0\tag{11}$$
- 圆锥摆：
$$ T \sin\theta = m \omega^2 L \sin\theta \Rightarrow \omega = \sqrt{\dfrac{g}{L\cos\theta}}\tag{12}$$
- 转弯：水平路面 $\mu m g = m v^2/r$；倾斜路面 
$$ \tan\theta = v^2/(g r)\tag{13}$$

### 2.4 功与能
- 功：$W = F s \cos\alpha$，重力功 $W_G = m g h$（只与高度差有关）
- 动能定理：
$$ W_{\text{合}} = \Delta E_k = \tfrac{1}{2} m v^2 - \tfrac{1}{2} m v_0^2\tag{14}$$
- 机械能守恒条件：只有重力或弹力做功 
$$ \Rightarrow E_{k1} + E_{p1} = E_{k2} + E_{p2}\tag{15}$$
- 弹簧弹性势能：
$$ E_p = \tfrac{1}{2} k x^2\tag{16}$$
- 功能关系：除重/弹力外其他力做功 = 机械能变化量

### 2.5 动量
- 动量定理：$I = \Delta p = m v - m v_0$（冲量=动量变化，矢量）
- 动量守恒条件：系统所受合外力为零（或某方向为零）
$$m_1 v_1 + m_2 v_2 = m_1 v_1' + m_2 v_2'\tag{1}$$
- 完全弹性碰撞（一维）：
$$v_1' = \dfrac{m_1-m_2}{m_1+m_2} v_1 + \dfrac{2 m_2}{m_1+m_2} v_2\tag{2}$$
$$v_2' = \dfrac{2 m_1}{m_1+m_2} v_1 + \dfrac{m_2-m_1}{m_1+m_2} v_2\tag{3}$$
- 完全非弹性碰撞：
$$ v' = \dfrac{m_1 v_1 + m_2 v_2}{m_1 + m_2}\tag{17}$$
- 反冲/爆炸：动量守恒，化学能→机械能

## 3. 符号与坐标约定（强制统一，避免乱套）

1. 始终声明坐标系：例如「以地面为参考系，向右为 x 正、竖直向上为 y 正」。
2. 加速度 a 与速度同向为正减速、反向为正减速；勿把「减速」直接写成负加速度而不写方向。
3. 摩擦力方向始终与**接触面相对运动（趋势）方向相反**，须先判断相对运动方向。
4. 角度 θ 一律从水平/斜面起算，并在图中标出，避免 sin/cos 用反。
5. 能量零点自行约定（通常取最低点为重力势能 0），并在解析中说明。
6. 矢量运算写成分量式，避免纯标量混用导致符号错误。

## 4. 易错点清单（生成解析时逐项排查）

- [ ] 把「位移」与「路程」混淆（曲线/往返运动中尤甚）
- [ ] 抛体运动误把合位移当轨迹方程；平抛时间由竖直方向决定
- [ ] 静摩擦当动摩擦算，或未验证 `f ≤ μ_s N`
- [ ] 圆周运动把向心力当成「额外的力」，实际是合力在法向的分量
- [ ] 机械能守恒条件不满足时仍用守恒（存在摩擦、空气阻力、外力做功）
- [ ] 动量守恒方向选取错误，或在有合外力时误用守恒（应改用动量定理）
- [ ] 单位未统一为 SI（如 km/h 未换算成 m/s、cm 未换 m）
- [ ] 弹簧/斜面初态末态选取不一致，导致 $\tfrac{1}{2} k x^2$ 或 $mgh$ 差算错
- [ ] 数值代入时保留过多/过少有效数字，或未对结果做数量级 sanity check

## 5. 解析正确性自检清单（每题必做，不可跳过）

生成最终解析前，逐条确认：

1. **物理依据**：每一步推导都标注所用定律/公式名称（如「由动能定理」），不得出现无来源的跳跃。
2. **量纲一致**：等式两边量纲相同（速度 m/s、加速度 m/s²、能量 J、力 N）。
3. **符号约定**：全程坐标/正方向一致，图中标注。
4. **定律适用条件**：明确写出该定律为何适用（如「系统水平方向合外力为零，故水平动量守恒」）。

7. **结论闭环**：最终答案回到题目所问（求时间/速度/功/高度），单位与有效数字规范。

若任一项无法满足且无法当场核实，必须在解析中以醒目方式标注「⚠️ 该步骤待核实」，并说明疑点，**绝不允许用编造的数值掩盖**。

## 7. 公式 LaTeX 书写规范（生成 HTML 用，统一源头）

本技能生成的 HTML 用 **MathJax** 渲染公式，因此所有公式**必须写成标准 LaTeX**，禁止使用纯文本近似（如 `1/2`、`sqrt(x)`、`v0`、`x2`、中文/Unicode 希腊字母）。这是「源头」层面的硬性要求，未满足时生成的页面公式排版会出错。

### 7.1 强制规则

| 类别 | ❌ 错误写法 | ✅ 正确 LaTeX |
|------|------------|--------------|
| 分数 | `1/2`、`½` | `\frac{1}{2}` |
| 根号 | `sqrt(x)` | `\sqrt{x}` |
| 下标 | `v0`、`v_x` 写成 `vx` | `v_0`、`v_x`、`v_y` |
| 上标 | `x2`、`t^2` 写成 `t2` | `x^2`、`t^2` |
| 希腊字母 | `θ`、`π`、`μ`（Unicode） | `\theta`、`\pi`、`\mu`、`\omega` |
| 角度/单位 | `63.4度`、`63.4°`（裸 Unicode） | `63.4^{\circ}`（度用命令）；单位 `$v=10$ m/s`、`10\,\mathrm{m/s²}`（**正体**，见下） |
| 乘号/点乘 | `*`、`x` 混用 | `\times`、`\cdot` |
| 变化量 | `△E`、`△s`（Unicode） | `\Delta E`、`\Delta s` |
| 单位（强制正体） | `m/s`、`kg`、`N`、`J`、`K` 裸写在公式内（渲染成斜体）、`\mathrm{kg}` 仅用于「公式内必须含单位」处 | 文字字段 `$m_A=0.4$ kg`（公式外纯文本，天然正体）；公式内单位 `$10\,\mathrm{m/s}$`、`$\,\mathrm{J}$`（用 `\mathrm{}` 强制正体） |
| 度 | `60°`、`60度`、`60^o` | `60\^{\circ}` |


> **渲染与查看（防误判）**：上表所有公式由内置 MathJax 3 运行时渲染，**必须用支持 JavaScript 的浏览器打开**生成的 `.html`（双击文件或 WorkBuddy 预览面板）。本技能已强制「单位正体」：单位在公式环境外作纯文本（天然正体），必须在公式内时用 `\mathrm{}` 强制正体；数学符号（`\Delta`、`\sqrt{}`、`^{\circ}`、`\theta`）必须保留 LaTeX 命令，在 JS 浏览器中正常渲染为 Δ/√/°；单位里的 `\mathrm{}` 在不执行 JS 的查看器里以源码出现属正常的查看方式问题，并非生成缺陷。
### 7.2 定界符与编号约定（模板自动处理，生成时只需写纯 LaTeX 内容）

> 本技能统一采用 **`$...$` 行内 / `$$...$$` 独立** 作为标准定界符（与「物理试题解析专家」规范一致）。模板 MathJax 同时兼容旧式 `\(...\)` / `\[...\]`，但**新写内容一律用 `$...$` / `$$...$$`**。

    - **行内公式**：用 `$...$` 包裹，例如 `水平初速度 $v_0 = 10$ m/s，重力加速度 $g = 10$ m/s²`（单位用纯文本，天然正体）；必须嵌在数学式内时用 `\mathrm{}` 强制正体（如 `$a=9.8\,\mathrm{m/s²}$`）`；
- **独立公式**：独占一行、用 `$$...$$` 包裹；多行对齐用 `aligned` 环境：
  `$$\begin{aligned} f(x) &= ax^2+bx+c \\ &= a\Bigl(x+\frac{b}{2a}\Bigr)^2 + c - \frac{b^2}{4a} \end{aligned}$$`
- **公式编号**：重要、需要引用的公式用 `\tag{}` 编号，例如
  `$$\begin{equation} E = mc^2 \tag{1} \end{equation}$$`；正文引用写作「如公式 (1) 所示」「联立公式 (2)(3) 可得」；
- **`STEPS[].tex` 字段**：模板会自动以 `\[ ... \]` 包裹并交给 MathJax 渲染，**不要自己再加定界符**（模板内部同时兼容 `$$...$$` 与 `\[...\]` 两种写法）；
- **`given` / `note` 等文字字段中的公式**：用 `$...$` 行内包裹（模板内部以 `\(...\)` 渲染，二者等价）。

### 7.3 常用公式的 LaTeX 写法（对照第 2 节）

> 以下为写入 `tex` 字段的纯 LaTeX 内容（无需定界符；行内说明文字中的公式用 `$...$` 包裹）。

- 匀变速：`v = v_0 + a t`，`x = v_0 t + \tfrac{1}{2} a t^2`，`v^2 - v_0^2 = 2 a x`
- 自由落体：`h = \tfrac{1}{2} g t^2`，`v = g t`
- 平抛：`x = v_0 t`，`y = \tfrac{1}{2} g t^2`，`v = \sqrt{v_0^2 + (g t)^2}`
- 斜抛：`x = v_0 \cos\theta \cdot t`，`y = v_0 \sin\theta \cdot t - \tfrac{1}{2} g t^2`
- 射高/射程/飞行时间：`H = \frac{v_0^2 \sin^2\theta}{2g}`，`R = \frac{v_0^2 \sin 2\theta}{g}`，`T = \frac{2 v_0 \sin\theta}{g}`

## 8. 典型题型正解库（保证解析正确）

生成解析前，须对照下列「标准解题范式」与「正解示例」逐条自检，确保符号、公式、数值、单位均无误，避免给出错误解答。

### 8.1 力学标准解题范式
1. 明确研究对象与过程分段，画出受力图 / 运动示意图。
2. 建立坐标系并规定正方向，列出适用定律：牛顿第二定律、动能定理、动量守恒、机械能守恒。
3. 统一为 SI 单位（m、kg、s、N、J、W）再代入数值。
4. 先求符号解，再代值；保留分数或根号，避免过早近似。
5. 量纲校验：`\([力]=MLT^{-2}\)`、`\([功]=ML^2T^{-2}\)`、`\([速度]=LT^{-1}\)`。
6. 极限检验：令某参数取 0 或极值，结果应合理。

### 8.2 正解示例
**例1 平抛运动**：以 `\(v_0\)` 水平抛出，落于高度 `\(h\)` 处。
- 竖直：`\(h=\tfrac{1}{2}gt^2\Rightarrow t=\sqrt{2h/g}\)`
- 水平射程：`\(x=v_0t=v_0\sqrt{2h/g}\)`
- 易错：射程写成 `\(v_0t\)` 却未代入 `\(t\)`；把 `\(g\)` 与 `\(v_0\)` 混用。

**例2 圆周运动临界（拱桥最高点）**：`\(mg-N=m\frac{v^2}{r}\)`，临界 `\(N=0\)` 得 `\(v_{\min}=\sqrt{gr}\)`。
- 易错：向心力指向圆心（向下），方程为 `\(mg-N=m v^2/r\)`，勿写成 `\(N-mg=\cdots\)`。

**例3 完全非弹性碰撞**：光滑水平面 `\(m_1\)` 以 `\(v_1\)` 碰静止 `\(m_2\)`，共速 `\(v'=\frac{m_1v_1}{m_1+m_2}\)`，机械能损失 `\(\Delta E=\tfrac{1}{2}m_1v_1^2-\tfrac{1}{2}(m_1+m_2)v'^2\)`。
- 易错：动量守恒前提是系统水平方向合外力为零；竖直重力不影响水平动量。

## 9. 图形重绘强制规范（动画与题图 1:1，零错误交付）

> **录入试题即重绘（强制）**：凡题面含图形，生成 HTML 时一律按原图 **1:1 重新绘制**（方式 ② 矢量重绘），**禁止把原图位图直接塞进 `<img>` 当作「已重绘」**。重绘结果须与原图在「几何结构 / 线型线宽 / 比例尺寸 / 角度与相对位置 / 字母标注 / 填充阴影 / 坐标系」7 个维度逐一吻合（完全相同）；嵌入原图位图（方式 ①）不计入「重绘」，仅当图形确实无法用 `FIG.*` 表达或用户明确要求像素级原样时兜底。

本节把「上传试题 → 生成 HTML」时**必须完美重绘**的力学图形逐条列出。生成页面时，左栏题图（必须 `FIG.*` 1:1 重绘（禁用嵌入原图位图充当重绘））与右栏动画几何**必须完全一致**，且**右栏动画全部走 `FIG.*` 图元**（禁止手画矩形/折线冒充模型）。模板 `assets/template.html` 的 `FIG` 库已内置下列全部图元。

### 9.0 四大图形约定（GEOMETRY_REVERSE_ENGINEERING / CANVAS_PIXEL / TWIN_LOCK / CONSISTENCY_CHECKLIST）+ GREEK_SYMBOLS

> 本册 §9 所列图形与右栏动画**共用同一套几何来源（同源 world 坐标 / `FIG.*` / `W2S`）**，二者几何必须 1:1。静态题图**默认走 Canvas 2D 孪生锁定（路径 B，`__CANVAS_STATIC__`）**：`<canvas>` 在 `t=0` 由 `drawStaticGraph()` 用 Canvas 2D 上下文按原图 1:1 硬编码绘制（模板已在 `renderProblem()` 之后补调 `drawFigures()`，加载即绘制、不依赖 resize 事件），独立双击打开必显示——**严禁用 SVG `viewBox` 通用缩放另绘**（坐标漂移、破坏孪生锁定）。**仅「不生成动画的纯静态几何重绘」允许 Mermaid / 内联 SVG（含 viewBox）**（见 `figures_redraw_spec.md` §10）。四大约定与 [GREEK_SYMBOLS] 配套，详见 `figures_redraw_spec.md` §3.2 与 SKILL.md「## 图形重绘工作流」。

- **[GEOMETRY_REVERSE_ENGINEERING] 几何反编译**：重绘前先反编译原题图几何——列出四类几何基元：① 顶点坐标（以画布左上角为原点的 X、Y 像素级相对位置）；② 线段/路径（起止点与曲率）；③ 角度标注弧位置；④ 文字锚点（m、F、v₀ 等精确落点）。**不得凭空「画」相似图形**。
- **[CANVAS_PIXEL] Canvas 2D 像素级 + 禁用 viewBox**：静态题图由 `drawStaticGraph(c)` 在左栏 `<canvas class="fig-canvas">` 上以 `t=0` 绘制，使用固定像素尺寸硬编码、像素级绘制；**严禁 SVG `viewBox` 通用缩放**（坐标会漂移）。
- **[TWIN_LOCK] 孪生锁定**：右栏动画直接复用 `drawStaticGraph()`；不动元素（斜面/地面/轨道轮廓/固定墙壁）只在背景层绘一次，移动元素（滑块/小球/箭头矢量）严格按解析运动方程（如 $x(t)=v_0t+\tfrac12at^2$）逐帧移动；**动画第 0 帧与左栏题图像素级重合**。
- **[CONSISTENCY_CHECKLIST] 一致性自检（生成 HTML 前于 CoT 隐式核对）**：[CHECK_1] 动图斜面角 θ 与左图**绝对相等**（同一 `const theta = 30 * Math.PI/180` 控制）；[CHECK_2] 矢量箭头长度比例与左图一致（如左图 $F=10\,\mathrm{N}$ 画 50px → 同一 `scale = 5px/N`）；[CHECK_3] 动图标签（$v$、$a$）移动时始终锚定物体同一相对位置（如右上角）。
- **[GREEK_SYMBOLS] 希腊角度符号禁中文名**：解析与动画中 $\theta$、$\alpha$、$\beta$、$\phi$、$\delta$ 一律用符号、禁「西塔/阿尔法/贝塔/斐/德尔塔」等中文名；时变角写 $\theta(t)$/$\phi(t)$。

### 9.1 总原则（图形位置无关）
- **无论图形在试题图片的哪个位置**（左上、右下、跨栏、夹在文字间、与多题同页），都必须完整、完美地提取并重绘/嵌入，**不得省略、裁切或只取局部**。
- 上传整页试卷 / 截图 / 多题同页照片时，先把图形所在区域单独切出再嵌入或重绘（方式③）。
- **零臆造**：原题有什么就画什么，严禁自行增加原题没有的辅助元素（法线虚线、延长到图形外的线段、坐标轴、未标注的强调圆点、斜线填充替代原题的实心填充等）。

### 9.2 力学模型图元清单（必须 1:1 还原）

| 题图要素 | 对应 `FIG.*` | 零错误还原细则 |
|----------|-------------|----------------|
| 水平弹簧 | `FIG.spring(x1,x2,y,{coils,amp})` | 圈数 `coils`、振幅 `amp`、两端连接点须与题图**完全相同**；禁用竖直画法画水平弹簧 |
| 竖直弹簧 | `FIG.springV(x,y1,y2,{coils,amp})` | 方向竖直，圈数/振幅与题图一致；**禁用水平画法**画竖直弹簧 |
| 碰撞点 / 接触点 | `FIG.collisionPoint(x,y,{label})` | 高亮点须与题图碰撞位置**重合**，带字母标注 |
| 质点模型 | `FIG.particle(x,y,r,{label,color})` | 实心小圆 + 质量 `m` 标注；**禁止用手画矩形冒充质点** |
| 直杆模型 | `FIG.rod(x1,y1,x2,y2,{double})` | 粗实线（双线可选）+ 两端铰点；与题图杆长/倾角一致 |
| 竖直平面圆轨道 | `FIG.circleTrack(cx,cy,R,{arc})` | 双圆弧轨道环（顶/底/左/右关键点）；小球须**贴轨**运动 |
| 弹簧振子 | 组合 `FIG.wall + FIG.springV + FIG.particle` | 平衡位置、振幅、周期与解析一致 |
| 单摆 | `FIG.pendulum(px,py,len,angle,bobR,{...})` | 支点 + 摆线 + 摆球，`angle` 自竖直向下起算；动画**走圆弧**轨迹 |
| 圆弧面（凹/凸） | `FIG.arcSurface(cx,cy,R,{a0,a1,solid})` | 由角度区间 `a0→a1` 定凹/凸取向；题图为实体时 `solid` 加斜线填充 |
| 管道（含弯管） | `FIG.pipe(points,{...})` | 沿折线 `points` 的空心管；弯管直接多段折线，质点不穿管壁 |
| 斜面 | `FIG.incline(x1,y1,x2,y2,{...})` | 楔形，倾角由两端高度差定；配 `FIG.angleArc` 标角度 |
| 通用矢量 | `FIG.vec(x,y,dx,dy,label,{color})` | 力 `F`、速度 `v`、加速度 `a` 等任意方向箭头，长度∝大小 |
| 角度弧 | `FIG.angleArc(cx,cy,r,a0,a1,{label})` | 标出斜面/摆角/碰撞角等 |
| 定滑轮 + 绳 | `FIG.pulley(x,y,r,{...})` | 滑轮 + 两侧绳 |
| 多过程横幅 | `FIG.processBanner(text)` | 顶部过程提示（见 9.3） |

### 9.3 多过程动画（过程数 = 题设过程数，强制）
- 试题含几个物理过程，动画演示就应有几个物理过程：**不得合并、也不得多出题目没有的过程**。
- 实现：按 `t` 的时间分段（`SIM.duration` 内）对应每个过程，用 `FIG.processBanner(...)` 在动画顶部显示当前过程名（如「过程1：匀速直线运动」「过程2：磁场中圆周运动」）。
- 阶段切换时刻必须与解析中的过程转折点严格一致（如碰撞瞬间、进入磁场瞬间、脱离轨道瞬间）。
- 每个过程的轨迹/速度/受力均用 `FIG.*` 绘制，切换时连续无跳变。

### 9.4 质量门禁（对应本规范）
生成文件须通过：① 左栏题图完整（含全部子图，无遗漏）；② 右栏动画几何全部来自 `FIG.*` 且与题图 1:1；③ 弹簧方向/圈数/振幅、碰撞点、质点实心圆、直杆铰点、圆轨道双圆弧环、单摆圆弧轨迹、圆弧面/管道/斜面取向均正确；④ 多过程动画过程数 = 题设过程数且横幅命名一致；⑤ 抽取内联 JS 通过 `node --check`、浏览器控制台无报错。

## 10. 通用强制条款（线条图形重绘 · 动画与解析严格对应 · 清晰真实）

本技能最新要求，适用于**本册涉及的全部题型**，生成解析与动画前必须逐条满足：

1. **文字 OCR 入文件（图片题强制）**：若题目以图片上传，先用 OCR（本地 `_build/ocr/run_ocr.py` 或 `yescan-ocr-universal` 技能 / Read 视觉转录）把题干文字**逐字**识别进 `PROBLEM`（title/given/asks/options），遵守「题干原文一致性」；选择题还须把 A/B/C/D 四项完整录入 `PROBLEM.options`（四项**单行横排优先、单行放不下则四行纵向排列**渲染；详见技能 SKILL.md「选择题选项录入（强制）」）；OCR 易错字符（`l↔1`、`O↔0`、`α↔a`、`×↔x` 等）须人工复核订正，禁止把错识字当原题。
2. **线条图形 1:1 重绘（强制）**：题图为线条图形（实/虚线、几何形状、字母标注）时，**按照原线条图形重新绘制成完全相同的线条图形**——优先用本册 §9 的 `FIG.*` 图元（或自定义 `ctx`）1:1 重绘；几何、线型、比例、角度、标注、填充 7 维度与原图一致；零臆造（原图没有的辅助线/法线/网格一律不画）。详见 `figures_redraw_spec.md` §6。
3. **公式排版规范（强制）**：本题所有公式（含题目原文与解析、含每问结论式）一律标准 LaTeX（见本册 §7 与 SKILL.md「公式排版规范」），禁 `/` 分数、`sqrt()`、`v0`、`sin()` 等代码风格。
4. **动画与解析严格对应·清晰真实（强制）**：动画是解析的**忠实可视化**——`STEPS` 每一步 `t0~t1` 对应动画该步状态；用同一 `stateAt(t)` 同时驱动画面与数据面板；位移/速度/受力由**解析同一套公式与参数**实时计算，真实比例与数量级、绝不夸张扭曲；关键状态（最高点/碰撞/脱离/换路）高亮或 `FIG.processBanner` 明示，清晰可懂。
5. **解析禁用微积分（强制）**：写解析一律**不得使用微积分**（`\int`、`d/dt`、`\dot{x}`、微分方程），必须用**高中物理方法**：变力做功用动能定理 / 能量守恒 / 图像面积或分段求和（不用 `W=\int F\,dx`）；速度/位移用运动学公式、动量定理 `m\Delta v=BLq`、能量守恒、图像斜率与面积；变加速过程取平均力 / 平均值或图像面积，**绝不解微分方程**。`note` 允许「图像面积 / 平均值 / 分段求和」等高中表述，但 `tex` **不得出现 `\int`**；校验：Playwright 检查页面文本不含 `∫` 或 `\int`。

6. **知识点分行显示·不覆盖解析（强制）**：`PROBLEM.knowledgePoints` 引用的每条知识点均**独立成卡、逐行排列（分行显示）**渲染——每个知识点占一行纵向堆叠，绝不挤成一行横排或逗号连写；卡片**只出现在左栏「试题原题」下方**（模板 `#kpInlineCards`），**绝不放入或覆盖中间「详细解析」栏**；相关知识点较多时仍保持逐行堆叠、左栏自然延伸，与中间解析板块无任何重叠遮挡。校验：Playwright 检查所有 `.kp-card` 均位于 `.col-problem` 内、`.col-analysis` 内不含任何 `.kp-card` 子元素。


8. **动画物理引擎 · 矢量可视化 · 公式零错误（强制）**：动画每一帧必须由**物理方程逐帧数值积分**得出（如 $x=x_0+v_0t+\tfrac12at^2$、简谐 $x=A\cos(\omega t+\phi)$、圆周 $x=R\cos(\omega t+\phi_0)$、竖直圆周用能量守恒 $v(\theta)=\sqrt{v_0^{2}+2gR(\cos\theta_0-\cos\theta)}$），**严禁用线性插值（Lerp）模拟物理运动**（匀速直线除外）；动力学场景须绘制受力分析（重力/弹力/摩擦力/向心力）与速度/加速度矢量箭头，箭头长度按比例缩放反映大小；所有矢量（速度/加速度/力）用带箭头线段表示，大小近零时自动淡出消失避免杂乱；抛体/圆周/振动开启「轨迹追踪」用浅灰虚线绘历史路径；画布建立合适坐标系（原点居中或左下、边缘显示坐标轴/刻度）。公式渲染**零错误**：所有 LaTeX 合法、无 `Math input error`；校验：Playwright 检查 `mjx-container.mjx-error` 数量为 0 且页面文本不含 `Math input error`。
