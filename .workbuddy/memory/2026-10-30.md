- 物理链条（全部用 Python 独立验算，与题图【答案】三项全对）：
  - 区域 0 ≤ x ≤ √3a，B 垂直纸面向外、粒子带正电 ⇒ 顺时针偏转，
    圆心 C = (R cosθ, −R sinθ)，坐标 x(φ)=R[cosθ−cos(φ+θ)]、y(φ)=R[sin(φ+θ)−sinθ]
  - (1) θ=0 粒子圆过 O 与 P ⇒ (√3a−R)²+a²=R² ⇒ **R = 2√3a/3**；
    弦 |OP|=2a=2R sin(φ₀/2) ⇒ **φ₀ = 120°**；ω=φ₀/t₀ ⇒ **q/m = 2π/(3Bt₀)**
  - (2) 两类出射：右边界 φ_R=arccos(cosθ−3/2)−θ（θ≤60°）、左边界 φ_L=360°−2θ（θ≥60°）；
    t₀ 时仍在场 ⇒ **π/3 ≤ θ ≤ 2π/3**（θ=0 按题设「刚好离开」不计；60°/120° 为临界计入）
  - (3) θ=60° 与右边界**相切不穿出**，继续转满 240° 才从 x=0 离开（出射点 (0,−2a)）
    ⇒ **总时间 = 2t₀**

## 新增经验

- **原题图必须逐像素反解后再画**：本题 O(801,465)、√3a 虚线 x=958 ⇒ a_px=90.65，
  反解出 x 轴 −0.30a~2.48a、y 轴 ±1.3a、虚线 ±1.21a、P 点在 x=√3a。
  反解的产物才经得起「与原图完全相同」的核对。
- **三角形内高是角度标注的硬预算**：∠OCP 的三角内高只有 0.577a（弦到圆心垂距），
  角弧半径 0.34 已占大半 ⇒ 角弧与数字**不能同时放**。对策：弧只画不配字，数字走引线到空白区。
- **标注的白底衬板会挖断轴线**：凡标签紧贴坐标轴（圆心在轴上、半径线在轴上），
  白底矩形必然切掉轴线 ⇒ 标签至少下移 0.25a 以上。
- **题图取景可与动画不同，但几何必须同源**：用同一套 drawDevice + 同一套常量，
  只临时改 VIEW 取景（画完恢复）⇒ 满足「题图≡动画装置」又保证小图可读。
- **单栏 VIEW 重算**：画布恒 680px ⇒ 内宽 606、内高 375.5、理想纵比 0.61974；
  本题 xrange 保持 7.00（右侧面板随画布加宽自动右移至 px≈339），
  yrange = 7.00×0.61974 = 4.3372，ymin=−2.90（出射点 −2.309a 下留 0.59a 给标注），
  ymax=1.4372 ⇒ 实测 xscale=86.5714、yscale=86.5720 px/a（严格相等）。
- **`drawFieldTint` 里 `p[1]` 应为 `p1[1]`**：模板坑，p0/p1 两点算包围盒时写错变量名
  ⇒ 页面报 `ReferenceError: p is not defined`（audit_nosig 会抓到，audit_page 也会）。
