## 新增经验

- **单栏门禁靠文件名自动开启**：`audit_page.js` 第 30 行 `const SINGLE = /动画演示/.test(path.basename(FILE));`
  ⇒ 不认 `--single` 参数，传 `--single` 会被当成文件路径导致 ERR_FILE_NOT_FOUND。
- **单栏 CSS 宽 = 680（不是 2009sh24 范式的 682）**：门禁同时要求
  `getBoundingClientRect().width===680` 与 `clientWidth===678`
  ⇒ 必须 `width:680px; box-sizing:border-box`（border 1px×2 含在 680 内，clientWidth 才是 678）。
- **单栏取景须按内宽反解**：内宽 606、内高 375.48 ⇒ 取 k=290 px/世界单位
  ⇒ x 跨度 2.090、y 跨度 1.295 ⇒ `VIEW={xmin:-0.300,xmax:1.790,ymin:-0.120,ymax:1.175}`；
  校验 `sy(1.085)≈62px`（HUD 下沿 54px 之下）、`sy(-0.045)≈390px`（底部图例 421px 之上）、
  `W2S(1.06)+8≈438px`（右侧面板宽约 230px）。
- **`rep1` 锚点命中 2 次的坑**：`drawFigures();` 在 `resize()` 内与顶层各出现一次
  ⇒ 改用带前置注释块的完整锚点唯一命中。
- **长标签/短标签分工**：画布只放短符号（`S₁`/`S₂`/`入场弧`/`出场弧`），
  长公式与长结论全部交右侧面板；重叠处一律改**引线标注**（虚线 + 文字放空白）。
- **图例语义一致性**：图例声明的颜色必须与图元实际颜色一致（红＝v₀ ⇒ 轨迹只能是蓝/绿）。
