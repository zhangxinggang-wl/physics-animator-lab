
## 2016·浙江·25 扇形聚焦回旋加速器（三峰区磁场 + 三谷区无场）

产物：
- `2016浙江25_扇形聚焦回旋加速器_教学动画.html`（三栏，480×317 画布）
- `2016浙江25_扇形聚焦回旋加速器_动画演示.html`（单栏，680×449）
- 生成器：`_build/g1.py`+`g2.py`+`g3.py` → `build_2016zj25.py`；抽取器 `_build/extract_zj25.py`

物理链（全部数值自检过）：
- (1) r=mv/(qB)，洛伦兹力恒在速度左侧 ⇒ **逆时针**
- (2) 三段峰弧共转 360° ⇒ θ=120°；切点半径 ρ=√3 r；直线段 √3 r；
      T=(2π+3√3)m/(qB)
- (3) 3×90°+3φ=360° ⇒ φ=30°；六弦等长 2r sin45°=2r′ sin15° ⇒ r′=(1+√3)r
      ⇒ B′=(√3−1)B/2
- 世界几何（r=1）：A 轨道＝峰弧(r=1,120°,圆心距 O 为 1)+直线(√3)；
  B 轨道＝峰弧(r=1,90°,圆心距 O 为 (√6−√2)/2)+谷弧(r=1+√3,30°,圆心距 O 为 √2)，
  切点半径 √2，弦长均 √2 ✔

★ 新踩坑（两条都是"门禁全过但肉眼可见"）：
1. **题图 canvas 的字被无痛缩小 36%**：框架 `drawStaticGraph` 里 `c.width = cv.width`
   把主画布 bitmap(956) 塞进左栏 305px 框；而 `W/H` 是框架按主画布设的全局量。
   正解两步：①按题图自身 CSS 尺寸重建 bitmap（覆盖 drawStaticGraph）；
   ②`ensureView()` 开头把 `W/H` 换成当前画布 bitmap/dpr（否则内容按 480×317 画进
   300×198 ⇒ 底部与右侧被裁）。改完题图字 6.5px → 10px，圆弧不再被切。
2. **单栏抽取脚本对本题三处不适用**：①`</style>` 锚点不唯一（tune-width 是第二个
   style 块）⇒ 改 `rindex`；②脚本把整个 `<div class="wrap">` 替换掉 ⇒ 须补回外层
   否则门禁「列数=1」查到 0；③`max-width:704px` 被内边距吃掉 26px ⇒ 画布 clamp 到
   678 ⇒ 放宽到 1000px 才得到 680/678。另需删 kpToggle/kpDrawer DOM（模板全局浮动元素，
   不在 wrap 内，脚本没删）。

视觉迭代记录（都靠分阶段人工看图发现）：
- 第(3)问曾同时画「旧轨道+新轨道+30 个 ×」⇒ 糊成一团。修法：× 密度用棋盘隔行减半
  （`si>=6 && i%2===0`）、半径收紧 RR−0.20、给角弧与 B′ 位置开 `KEEP` 矩形避让；
  B′ 从圆外 (0,−1.86) 移进谷区 (0,−1.55)；旧轨道改 #dbe2ea 淡显。
- 「90°」标签原在角弧正上方（间隙 0.03 单位，粘在一起）⇒ 角弧 0.26→0.42、标签移到
  (0.52,0.99) 侧上方。
- 弦高亮线型要与直边一致（都实线），否则读者以为是两种量。
- 图例文案/样例必须与当阶段实际绘制一致（si≥6 换成「新平衡轨道（加 B′ 后）」）。

## 2016年4月·浙江·21（加试题）双缝干涉测波长 —— 首个「光学实验仪器」题

产物：`2016浙江4月21_双缝干涉测波长_教学动画.html`（三栏）+ `..._动画演示.html`（单栏 680）
生成器 `_build/build_double_slit.py`、单栏 `_build/extract_dslit_single.py`。
答案 D；l₂=19.40 mm；λ=420 nm。数值链 assert 过：
Δy_红=2.10（5 条暗纹）、Δy_紫=1.26（8 条）、5Δy=25.70−19.40=6.30、λ=0.20e-3×1.26e-3/0.600=420nm。

本题**不用 W2S**（是仪器视场不是物理空间），全部像素原语 + `cvSize()` 取 CSS 像素。

### 新踩坑（5 条，都是"门禁全过、肉眼才发现"）
1. **★ 圆 + 读数框必须整体居中，半径要给框让位**：`r=min((bw-12)/2, …)` 在窄画布
   （三栏 190px）刚好，单栏 680px 时圆胀到 r=138，框被顶出右边缘把 "19.40" 裁掉。
   正解：`r = min((bw-RBOX-20)/2, (bh-rulerH-10)/2)`，`grpW=2r+8+RBOX`，
   `gx = R.x0 + (bw-grpW)/2`，框宽固定 RBOX=58（"19.40" @14.5px 需 ≈46px）。
2. **★ 条纹"白底细暗条" vs "暗底细亮条"**：直接 `a=0.88(1−cos²)` 会画成红底白条，
   与教材/题图观感相反。正解 `fringeA = 0.9(1−I)^1.8` —— 压窄暗纹、放宽亮区，
   暗纹中心位置（(m+½)λ）不变。
3. **★ 双缝缝距必须夸大**：真实 d/L=0.2/600 ⇒ 图上两条光程线张角仅 3°，重合成一条，
   看不出光程差。`ds = max(18, min(27, 0.17×栏宽))` 后张角 ~7°，两条线清晰分开。
4. **★ 游标尺「丙」会被主尺数字压住**：读数扫过 20~21 mm 时主尺 "2" 正好落在尺左端，
   与 "丙" 叠成 "丙2"。正解：`drawRuler(..., tagDy)` 增参，动画传 −4 把「丙」提到
   数字行上方（题图仍用默认 11，因为题图上方有 "乙" 标签）。
5. **窄小元件（滤光片/光源）标签不能跟宽元件对齐**：屏/双缝是横线，标签贴左外侧；
   滤光片/光源是 16px 小方块，标签贴左外侧会隔 70+px 空白 ⇒ 看成"浮着的小方块"。
   正解：这两个标签右对齐到 `xc−11`。

### 阶段文案一致性
滑动过程帧（如 t=620）面板读数是**中间值**（21.00），若横幅/HUD 写死 19.40 会同屏打架
⇒ 阶段标题只写动作（"同向移过 5 个条纹间距"），HUD 写物理依据（"每移过一个条纹间距，
读数就减小 Δy"），具体读数交给读数框。

### 单栏抽取（第二个 style 块 ⇒ rindex）
`</style>` 有 2 个（模板 + 本题 CSS_TUNE）⇒ 通用脚本 assert 直接失败；
`find_wrap` 改用「首个 `<section class="col` + rindex 回溯 `wrap`」防 JS 注释误命中；
补回外层 `<div class="wrap">`；`.col-animation` 左右 padding 归零 + max-width=CV_W+8
才拿到 680/678；kpToggle/kpDrawer 在 body 下须自己 regex 删。
单栏实测：列数=1、cvCssW=680、cvInnerW=678、kpToggle=0，全项 PASS。

## 2017·旧课程理综·25（两球先后穿水平电场）—— 收尾复盘

抽取器 `_build/extract_anim_efield.py`、单栏审计 `_build/audit_anim_efield.js`。
物理：H=1、g=10 ⇒ 下落时间=场中时间=T_F=0.2582（本题关键巧合）；答案 x_M:x_N=3、h=H/3、E=mg/(√2q)。

### 新增踩坑（4 条，全部是「门禁查不出、只能看图」的类型）
1. **图例样例线型必须与画面一致**：图例第 4 项画「灰色虚线 + 运动轨迹」，可画面里
   轨迹是**实线彩色曲线**、虚线是**区域边界** ⇒ 改成「深灰虚线 + 场区边界」才自洽。
2. **`mg` 标签放在受力箭尖上方会被电场点阵行蹭到**：球在 y=1.0（入场瞬间）时箭尖 0.81，
   点阵行在 0.88 ⇒ 标签正好压在该行箭头上。改为「箭尖下方 0.018」即让开。
3. **球名标签若居中放在球正上方，竖直轨迹会从字中间穿过**（N 出射帧最明显，
   白晕只能救一半）。正解＝**沿轨迹横向让开**：M 放右侧左对齐、N 放左侧右对齐，
   y 只抬 0.058（抬到 0.115 会骑在上边界虚线上）。
4. **单栏审计的「面板公式已排版」判据**：本题数据面板的值是纯数字，公式只出现在
   `#panelNote`（当前步骤说明）里 ⇒ `panelContainers` 必须取 `panelData + panelNote` 合计，
   否则 mjx-container=0 误报。
另外：本题 DRAWFRAME 的守卫是 `if (!isFig)`（题图态跳过横幅/HUD/图例），不是
`if (t > 0.002)` ⇒ 单栏下首帧四要素本来就画，**不需要删让位判断**（审计里确认即可）。
