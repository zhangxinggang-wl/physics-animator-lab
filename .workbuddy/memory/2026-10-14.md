### 本次踩到的坑（已沉淀进生成器注释）

1. **`PI` 不是 JS 全局量** —— 注入的 JS 里直接写 `PI` ⇒ `ReferenceError` ⇒
   动画卡死 t=0 + 左栏孪生题图整块空白（正是 MEMORY 里记的「未声明标识符」坑，本次又犯）。
   修法：`PAR.PI` + `const PI = PAR.PI;` 并把**未声明标识符门禁**加进生成器。
   ⚠ 该门禁自身两处误报：① 需排除对象字面量键名（`PAR.MX` 是属性不是标识符）
   ② 需排除模板区声明的量（`VIEW_Q3` 注入在 `const VIEW` 那一段，不在四段注入 JS 里）。
2. **注入 JS 经 Python `%` 格式化时，注释里的裸 `%` 会炸**
   ⇒ `TypeError: not enough arguments for format string`。注释里改用「百分号」中文。
3. **取景必须反解，不能拍脑袋** —— 新增 `fit_view(need_top)`：
   由「像素分层 + 轨迹包络 + 等比例尺」三方约束反解
   `R = (need_top−y_bot)·INNER_H/(TB_TOP−USABLE_TOP)`，`xrange = R/RATIO`。
   ⚠ **可用顶 = max(横幅下沿, HUD 下沿)** —— 首版只取横幅下沿(41px)，
   而 HUD 三行深达 94px ⇒ 整段半圆弧顶画进 HUD 里（t=7 截图可见）。
4. **两阶段取景**（`VIEW` / `VIEW_Q3`）：第(3)问轨迹更高（4.094 vs 2.571），xrange 须更大。
   极板位置改用 `plateTopY()/plateBotY()/xEndNow()` **按当前取景比例**推导，写死必在一阶段失效。
5. **纵向分层要「像素唯一真源」**：HUD/时间条/图例都经 `LAYER` + `pxToWorldY()` 反算世界 y，
   禁止各自按世界坐标定位。踩到的具体重叠：时间条↔图例、尺寸线↔时间条、
   时间条说明↔图例、释放时刻引线↔时间条 —— **凡在 x 轴下方 / 时间条附近写标注必重叠**。
6. **单栏抽取必须整体重算取景**（不是只改 ymax），且要给
   `renderProblem` / `renderSteps` 加**宿主容器整体早退守卫**
   —— 左栏题干、中栏解析被切掉后 `getElementById('problemBody'/'steps')` 为 null，
   逐处判空必漏（首版连续报 textContent / innerHTML 两个错）⇒ 动画卡死 t=0。
   ⚠ **`updatePanel` 不能加守卫**：数据面板在动画栏内，单栏页仍存在，加了数据面板整块不显示。
   ⚠ **只删 kpToggle/kpDrawer 的 DOM，不要动 JS**：模板 `bindDrawer` 自带
   `if (!tg || !dr) return;` 守卫，删赋值行反而让 `tg` 变未声明。
