### 一、题目与解法（已与官方答案逐条核对）

正交场：`E` 沿 −y，`B` 垂直纸面向里，`q>0`，粒子自 O 以 `v₀` 沿 +x 入射。

- 分解为「回旋运动 ⊕ E×B 漂移」：`ω = qB/m`，`T = 2πm/(qB)`，
  漂移速度 `v_d = E×B/B² = E/B`（与 v₀ 无关），回旋半径 `R = m(v₀B−E)/(qB²)`。
- 轨迹（摆线 trochoid）：`x = (s/2π)·θ + A·sinθ`，`y = A(1−cosθ)`，`θ = ωt`，`A = R`。
- (1) 只有电场力做功：`½mv₀² − qEh = ½mv²` ⇒ `v = √(v₀² − 2qEh/m)`。
- (2)Ⅰ 空间周期 `s = v_d·T = 2πmE/(qB²)`（与 v₀ 无关 ⇒ 乙图三曲线在 0、s、2s 同时过零）。
- (2)Ⅱ `y` 为简谐：`y = A(1−cos ωt)`，振幅 `A = m(v₀B−E)/(qB²)`，平衡位置 y=A。

**演示取值**：q=1.6e−19 C，m=1.67e−27 kg，B=0.20 T，E=1.0e4 V/m，v₀=1.0e5 m/s，h=3.0e−3 m
⇒ ω=1.916e7 rad/s，T=3.279e−7 s，v_d=5.0e4 m/s，A=2.609 mm，s=16.395 mm，v(h)=6.520e4 m/s。
**选 v₀ = 2E/B（尖点特例）** ⇒ A = s/(2π)、轨迹单调无环，且与原图甲的尖顶拱形一致。

**⚠ 原图甲是示意图**：其「拱高/拱宽 ≈ 1.29」与真值 `2A/s = 1/π ≈ 0.318` 不符 ⇒ 动画按等比例尺画真实轨迹，
并在解析②的 note 里明写「原图甲为示意图」。

### 二、本轮修掉的 6 个缺陷（都是门禁查不出来、靠人工看图发现的）

1. **取景把内容顶到 HUD 底下 + 底部空一大片**
   `ensureView()` 原来让世界窗口铺满整个画布 ⇒ 顶部内容（y 轴箭头、磁场上排 ×、B 标签）被 HUD 白框压住，
   底部留白 ~74 px。**改成「内容盒 WBOX 映射到绘图带」**：
   新增 `band()`（上沿 = HUD 下沿、下沿 = 图例上沿，且 HUD 高度要乘 `fk()`，否则单栏版 HUD 会盖住图），
   `ensureView()` 用 `scale = min(innerW/bw, bandH/bh)`，纵向把内容中心对到 `band.top + band.h/2`。
   `WBOX` 同步扩到 `{-3.6, 36.4, -7.0, 12.6}`（含标签字高与乙图 s 尺寸线）。

2. **丙图（y–t）整幅画不出来 —— 像素坐标被二次变换**
   `drawYT()` 里 `x0/x1/yb/yt/gx/gy` 都是**像素**，却传进了世界坐标原语
   `seg/wt/polyline/arrowW`（内部都走 `W2S`）⇒ 整幅图飞出画布，只剩 `dimVpx/dimHpx`（真像素空间）还在。
   **修法**：新增像素空间原语 `segPx/arrowPx/polyPx/wtPx/dotPx/wtBoxPx`，`drawYT` 全部改用它们。
   ⇒ **教训：世界坐标原语与像素坐标原语必须成对隔离，混用必然静默失败。**

3. **原点处两条箭头叠成一团**：黑色 v₀ 箭头（初速）与红色瞬时速度箭头同向同起点。
   改成 `AT_START = (st.th < 0.30)` 时只画 v₀，之后只画瞬时速度箭头，交接点几乎无感。

4. **y=h 交点的红圈被轨迹线切碎**：半径 0.42 世界单位只有 4 px，轨迹从圈心穿过 → 读不出是「一个圈」。
   改成先画白底圆盘（`dotW(...,6.0,'#fff')`）挖空，再画 r=6.0 的红圈。

5. **乙图的 h 虚线没隐藏**：h 是甲图的东西，乙图（famShow）不应出现 ⇒ 加 `if (!famShow)`；
   同时乙图的「s」尺寸线被最低那条曲线（k=0.25，最低点 y=−3.91）穿过 ⇒ 尺寸线从 −3.4 下移到 −5.9，
   且乙图里 y 轴不再向下延伸（避免与尺寸线竖直虚线重叠）。

6. **横幅序号与解析栏序号打架**：横幅原为 ①①②③④⑤、解析/HUD 为 ①②③④ ⇒ 同一屏「横幅说③、解析说②」。
   统一成与 STEPS 一致的 ①②③④（一个步骤可以有多条横幅，但序号不变）。

另修：`T` 标签被 x 轴线穿过（`yT` 由 `yb+15fk` 改 `yb+26fk`）；`y = A` 标签贴到曲线上（改用 `wtBoxPx` 白底挖空）；
函数式标注压住第二个峰（由 `yt+16fk` 改 `yt+2`）；甲图底轨由 `#cbd5e1` 加深为 `#94a3b8`（t=0 孪生题图全是底轨，太浅会发虚）；

### 四、经验沉淀（已并入 MEMORY.md 与 skill 的 pitfalls.md）

- **⚠ 取景必须「映射到绘图带」而不是铺满画布**：让世界窗口铺满画布 ⇒ 顶部内容被 HUD 压住、底部留白。
  正解：内容盒 WBOX ↔ 绘图带（HUD 下沿 ~ 图例上沿），`scale = min(内宽/盒宽, 带高/盒高)`。
  绘图带上下沿都要乘 `fk()`（字号缩放系数），否则单栏 680px 版 HUD 变高会盖住图。
- **⚠ 世界坐标原语 vs 像素坐标原语必须隔离**：`seg/wt/polyline/arrowW` 内部走 W2S，
  传像素进去会被二次变换 ⇒ 整幅图静默消失（门禁只查「画布非白像素>0」，照样 PASS！）。
  像素空间另配 `segPx/arrowPx/polyPx/wtPx/dotPx/wtBoxPx`。
- **⚠ 交点/相切点上的小标记会被线切碎** ⇒ 先白底圆盘挖空再画环。
- **⚠ 横幅序号必须与 STEPS/HUD 序号一致**，否则同屏出现两个「③」。
- **⚠ 初速箭头与瞬时速度箭头同起点同方向** ⇒ 用 `AT_START` 阈值二选一显示。
- **⚠ 尺寸线必须落在所有曲线之下**（乙图最低曲线 −3.91 ⇒ 尺寸线 −5.9），否则被穿过且标签被压。
- **⚠ `dimHpx` 的标签在箭头上方**（textBaseline=bottom）⇒ 尺寸线 y 必须比坐标轴低出「标签高 + 6px」，
  否则「T」被轴线穿过。
- **⚠ `shot_stages.js` 的 `/35` 是写死的** ⇒ 按 `SIM.duration` 换算千分数，否则抽到的全是 t≈0 的帧。
- **⚠ 甲图的 h 虚线只属于甲图**，乙图阶段必须隐藏。

## 2026-11-04 追加：《2013·天津·11 圆筒内磁场碰撞》（第 2 份题目，同日）

### 一、物理链（与官方答案逐条核对，差 = 0；独立数值自检 + 探针验证）

**题图几何反编译**（原图 1076×730）：圆心 O≈(920,500)、半径 R_px≈101；
N 板虚线 y≈606（在**圆的下切点**处，即 S = 切点 = O 正下方）；
M 板实线 y≈641、其上方一排「+」；P 点黑点在 (920,641) ⇒ **P 在 O 正下方、S 正下方**；
「d」尺寸线 x≈839；「B」标签在圆内上方。

**核心物理链**（本题的灵魂是「正碰链」）：
1. 粒子自 P 静止释放，板间电场 E 由 M(+) 指向 N(−)（向上），上升 d 至 S：
   qEd = ½mv² ⇒ **E = mv²/(2qd)**。
2. 磁场中洛伦兹力只改方向不做功 ⇒ 匀速圆周运动，r = mv/(qB)，T = 2πm/(qB)。
3. ★**粒子沿半径 SO 射入 ⇒ 轨道圆与筒壁圆正交**（|OO'|² = R²+r² 恒成立）
   ⇒ 在另一交点 A 处轨道切线仍沿 OA ⇒ **每次撞壁都是正碰**，碰后速度沿半径反向，
   新轨迹圆关于该半径对称 ⇒ 接触点 S、A、B… 把圆周**等分**。
4. 官方解法：∠AO'S = π/3，r = R tan(π/3) = √3R ⇒ **R = √3mv/(3qB)**。
   等价自证：同一弦 SA 在筒圆张 120°（2R sin60°）、在轨道圆张 60°（2r sin30°）⇒ r = √3R。
5. 第(3)问：M 板上移 2d/3 ⇒ 板距 d/3 ⇒ U'=U/3 ⇒ v'=v/√3 ⇒ **r' = R**
   ⇒ 每段弧圆心角 90°、接触点四等分 ⇒ 需 4 段弧 ⇒ 中途碰撞 **n = 3**。

**闭式轨迹参数化**（世界单位 = R，O 原点，S=(0,−1)）：
接触点数 K（= 弧段数 = 碰撞数 + 1）：
  Δ = −2π/K，φ_j = −π/2 + j·Δ，ψ_j = −π/2 + (j+1/2)·Δ，
  D = 1/cos(π/K)（|OC_j|），r = tan(π/K)，弧 j 逆时针扫过 π − 2π/K。
  ⇒ K=3：r=√3R、弧角 60°、接触点 −90°/150°/30°；
    K=4：r=R、弧角 90°、接触点 −90°/180°/90°/0°。
**自检脚本**：必须逐点验证「弧起点=接触点 j、弧终点=接触点 j+1、弧上每点 |p|≤1、
末段弧回到 S」——这一步是发现正负号写反的唯一手段。

### 二、本题新踩的坑（已并入 pitfalls.md）

- **⚠ 弧段绘制的 `cur` 索引错位**：画「第 k 段弧」时，已完成弧应是 0..k−1、
  **当前弧是 k（画到进度 u）**。若用 `cur = st.k` 再画 `j < cur` 的一部分，
  会漏画当前弧、重画上一段 ⇒ 轨迹断裂。正确写法分三态：
  `arc` 段 → fullArcs=k、当前弧 k 画到 u；`hit` 段 → fullArcs=k+1；`out` 段 → fullArcs=K。
- **⚠ 接触点字母压在轨迹/粒子上**：A/B/C 字母若沿切向放，必然压住蓝弧与红点。
  正解：**沿径向（由 O 指向该接触点）外推到圆周之外**，字母永不入筒内。
  同理「正碰」标签改沿**切向**外推，与径向的字母错开 90°。
- **⚠ 筒内画等分角标注必然叠字**：4 个「90°」挤在圆心附近、压住 O 标签与轨迹。
  正解：**等分弧括号画在筒壁外侧（半径 1.035R）**，且只标**一个**角度
  （选圆周右下、离 d 尺寸线与 N/M 标签都远的那段间隙）。
- **⚠ 标签的「就近隐藏」阈值不能太宽**：`Math.abs(st.y+1) < 0.42` 会把首帧
  （粒子在 P、y≈−1.37）也一起隐藏掉，S 标签凭空消失。
  阈值须按**标签实际占位**收紧到 0.26，且判定要与 S 标签位置一致。
- **⚠ P 标签别放在 N 板线上方**（原题 P 在 M 板上）：放板线下方才不压 N 板虚线。
- **⚠ 辅助图的局部坐标系要重新推导**：不能照抄「O' 为原点、S=(r,0)」。
  正解：O'=(0,0)、S=(r,0)、A=(r cosφ, r sinφ)、O=(r,1)，
  筒壁圆 = 圆心 O、半径 1（**不是**过 O' 的圆）；两处直角标记（S 与 A）才显出正交。
