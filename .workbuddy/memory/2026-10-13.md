### 本轮踩到并修掉的坑（已写进 MEMORY.md）
1. **`re.sub` 吞反斜杠**（最隐蔽）：`pat.sub(字符串, out)` 会把替换串里的 `\b \d \t \Delta` 当反向引用/转义处理，
   产物里 LaTeX 变成 `big`/`Delta` ⇒ MathJax Math input error。**必须 `lambda m: payload`**。
   `%r` 也不可靠（`'a\Db'` 的 repr 不转义反斜杠）；统一用 `json.dumps(ensure_ascii=False)`。
   已加**产物级硬门禁**：扫 `tex: "..."` 找单反斜杠+字母，命中即 `SystemExit`。
2. **`PATH_OFF` 少一个哨兵**：数组只 push 了每段起点（长度 = 段数），
   最后一段取 `PATH_OFF[i+1]` 为 `undefined` ⇒ `pathIndexOf` 返回 NaN ⇒ 红色已走轨迹末段整段消失。
3. **`ctx.fillText` 用世界坐标**：`(0.80, 0.30)` 被当屏幕像素 ⇒ 文字落到画布左上角成一条裁切残字。必须过 `W2S`。
4. **模板 `clearBg()` 清不干净**：它按 `canvas.width/height`（设备像素）清屏，
   而 `resize` 已 `setTransform(ratio,…)` ⇒ 顶部约 `H/ratio` 条带永远残留上一帧。本题就地改 `clearBgCss()`。
5. **裸 `<` 破坏 HTML**：note 里 `\(z=0<z_0\)` 的裸 `<` 被当标签起始 ⇒ 定界符失配 ⇒ 裸定界符门禁 FAIL。写 `\lt`。
6. **`\mathrm{合}` 中文非法**：`\mathrm` 只收字母，中文要用 `\text{合}`。
7. **note 用 `innerHTML` 插入**，不解析 Markdown ⇒ `**加粗**` 原样显示，须写 `<b>`。
8. **传空串 ≠ 隐藏标签**：`drawParticle(..., '', 0)` 会掉进 `else` 分支照画；要传 `null` 并在函数内判空。
9. **`merror` 判据要认准**：MathJax 正常渲染也会产出 assistive-MML 里的 `<merror>` 元素，
   但只有「公式真的报错」时 SVG 宽度才是异常窄的 16ex；`mjx-container.mjx-error` 才是可靠判据。

## 2021·河北卷 14（平行栅极板 + 磁场 + 粒子靶）教学动画

产物：`2026-10-13_河北2021栅板粒子靶_教学动画.html`（2.3 MB）
生成器：`_build/build_hebei2021_grid_target.py`
截图脚本：`_build/scripts_shot_stages.js`（**按物理阶段抽样**，补 shot_zoom 只有 t=0 的短板）

### 物理核心（世界单位取 r₀ = mv₀/(qB) = 1，故 v = qBr/m、v₁ = r₁）

装置：下极板 y=0（正）、上极板 y=D（负），板间只有电场 E（向上），
**极板外才有磁场 B**。O=(0,0)、C=(0,D)、P=(L₀,D)；挡板 OM 过原点、
与正极板成 37° ⇒ 直线方程 **3x + 4y = 0**，法线 (3,4)。

**本题最关键、也最容易错的一点**：
粒子每穿一次板间，上去加速到 v₁、下来减速**恰好回到 v₀**
（½mv₁²−½mv₀² = qU，而下降段电场力做功 −qU，两者抵消）
⇒ **下方磁场半径恒为 r₀ = mv₀/(qB)，与电压 U 完全无关**；
而上方半径 r₁ = mv₁/(qB) 随电压增大。两者此消彼长，第(2)(3)问全靠这一点。

- (1) 命中 P ⇒ 2r₁ = L₀ ⇒ r₁ = L₀/2 ⇒ U₀ = B²L₀²q/(8m) − mv₀²/(2q)
- (2) 下方圆心 c = 2r₁ − r₀，与 3x+4y=0 相切 ⇒ 3c/5 = r₀ ⇒ **r₁ = 4r₀/3**
  ⇒ U_min = ½mv₀²[(4/3)²−1]/q = **7mv₀²/(18q)**（不含 L₀、不含 B）
- (3) 落点递推 x_k = 2k(r₁−r₀) + 2r₀ ⇒ r₁ = r₀ + (x−2r₀)/(2k)；
  存活条件由**第一轮**（最严苛，后续轮圆心右移离挡板越来越远）给出 r₁ ≥ 4r₀/3
  ⇒ k ≤ 3(x−2r₀)/(2r₀) ⇒ 取整得 **CH = (2n/3+2)mv₀/(qB)、CS = (2n/3+8/3)mv₀/(qB)**。
  取 n=2 时 CH = 10/3 r₀、CS = 4 r₀，**恰是 U=U_min 时第 2、3 次落点**，几何自洽。

### 本题新增的可复用经验

- **未声明标识符 ⇒ 每帧 ReferenceError**：症状极隐蔽 —— 页面能加载、
  `syntax_check` 三段全 OK，但 `distinctFrames=1`（动画卡死 t=0）**且左栏孪生题图整块空白**
  （题图 = drawSceneBody(0)，同一处报错）。已在生成器加**未声明标识符门禁**：
  剥注释/双引号/单引号/模板字符串后扫大写常量，与 PAR/GEO/函数名比对。
  ⚠ 扫描范围**只能取注入的四段 JS**，扫整个 2.3MB 产物会被 CSS 色值、
  LaTeX 宏、中文散文里的 CH/CP/OM 淹没。
- **TDZ 同款坑**：判据常量（如 `NEAR_TAN`）若声明在首次使用**之后**，
  同样是每帧 ReferenceError。派生判据一律在使用点之前声明。

  ⇒ `Identifier 'BANNERS' has already been declared`；
  且生成器拼数组要用 `','.join`，用 `'\n'.join` 会丢掉元素逗号。
- **相切点是全图最挤的地方**：相切点同时压着挡板、角弧、M 点、圆弧、粒子与 v/+q 标签。
  唯一可靠解法是**引线标注**（文字挪到空旷区 + 细点线连回）+ 相切区隐藏粒子标签 +
  阶段性隐藏 37°。
