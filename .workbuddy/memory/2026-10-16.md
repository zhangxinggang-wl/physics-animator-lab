## 新题：2004·全国Ⅳ·24 圆形磁场区域内带电粒子

产物：`2026-10-16_2004全国IV24_圆形磁场区域_教学动画.html`（2.29 MB 单文件）
生成器：`_build/2026-10-16_circular_field/build_circular_field.py`
探针脚本：`_build/2026-10-16_circular_field/probe_r_label.py`（r 标签安全区暴力搜索）

### 物理推导（关键：区分「轨道半径 r」与「磁场区域半径 R」）
长度单位取 L（世界坐标即「以 L 为单位」）。粒子从 O 沿 +x 出发，磁场 ⊗ 向里，
洛伦兹力沿 +y ⇒ 轨道圆心 C 在 O 正上方，`OC = r`，故 C、O、P 三点共线（在 y 轴上）。

粒子沿弧转 120° 后在 Q 点（磁场区域边界上，`OQ = R`）出射，出射方向沿切线 QP，
半径 CQ ⊥ 切线 ⇒ 直角三角形 CQP。∠CPQ = 30°（即题给「速度方向与 y 轴成 30°」），
`CP = OP − OC = L − r`：

    sin30° = CQ/CP = r/(L−r) = 1/2   ⇒  r = L/3

三角形 OCQ 中 OC = CQ = r、∠OCQ = 120°，余弦定理：

    OQ² = r² + r² − 2r²cos120° = 3r²  ⇒  R = OQ = √3·r = (√3/3)L  ✔ 与题给答案一致

    B = mv/(qr) = 3mv/(qL)

**生成器内置 5 条几何断言**（|OQ|=R、CQ=r、|QP|=√3r、CQ·QP=0、∠CPQ=30°），
改任何几何常量后断言不过就 SystemExit —— 比看图早一步。

### 取景（等比例尺反解）
`VIEW = xmin −1.634 / xmax 1.634 / ymin −0.72 / ymax 1.26`，yrange/xrange = 0.6058
（三栏实测内宽 486×321）。顶部余量同时容下【过程横幅 sy 8~37】【P 点 v 矢量】【30° 角标】。

### 本题特例：顶部只放 processBanner，不放 HUD
P 点在 y=1 → sy≈55，一旦加 HUD（sy≥39）就会把 P 点与 30° 角标整块遮住。
阶段信息由横幅 + HTML 数据面板承载。

### 4 阶段时间轴（14 s）
① 0–2.5 题设初态（粒子停 O，v 沿 +x）
② 2.5–6.61 圆弧 O→Q（120°，弧长 0.698）
③ 6.61–10.01 出射后直线 Q→P（长 0.577，与 y 轴成 30°）
④ 10.01–14.0 几何关系：CQ 高亮 + Q 点直角标记 + 三条结论分置三个高度带

### 门禁结果
syntax 三段 OK / audit 17 项全 PASS / nosig ALL PASS / 14 项 FOUND + 4 项反向探针 GONE。

### 人工看图抓到的 6 处缺陷（自动化门禁全部漏掉）
1. **粒子速度矢量冲出画布顶部**并压住过程横幅（只在末帧 t≥12 暴露）
   → 按阶段缩短：`(st.stage === 'geo') ? 0.13 : 0.20`
2. **`Q 出射点` 与 `R = √3L/3` 引线标注叠字**（都在右侧同一高度带）
   → 结论文字分置 y≈0.86 / 0.55 / 0.24 三个带，引线起点各取不同点
3. **中文标注用斜体 serif → 伪斜体**
   → `hasCJK()` 判断，中文走 sans-serif 非斜体，纯字母仍 serif 斜体
4. **30° 标签紧贴横幅下沿** + `r` 引线穿过 y 轴标签
   → 30° 下移到 (−0.225, 1.048)、y 轴标签移到 y=−0.30 空白段
5. **R 尺寸线标签压在箭线上** → `off` 12→18
6. **`r` 引线标注被粒子轨迹扫过时压住**（阶段②③）
   → 暴力搜索安全区；但**按「离锚点近」排序的第一候选贴住 x 轴（裕度 4.5px）**，
     必须改按裕度降序（得 54px）；且该点仍与 Q 的引线交叉
     ⇒ 最终改为**按阶段显示**：阶段①④出现（粒子不扫场），②③隐藏

## 追加：同页 n 可切换（n=2 ↔ n=3）

用户选择「同一页面加 n 切换」而非另出独立文件。做法与要点：

**架构改造（生成器 `build_dual_field.py`）**
- 几何从 Python 算死的常量改为 JS 运行时 `buildForN(n)` 重建：
  `let PAR/SEGS/TAU/ARC_TOTAL/KEY/T/FULL_PATH/PATH_OFF/BANNERS/T_B2_START`。
- **关键物理洞察**：`n·d = n·2(r₂−r₁) = 2r₁` **恒为 2，与 n 无关** ⇒
  n=3 的轨迹（r₂=4/3、d=2/3、3d=2）**完全落在 n=2 的取景范围内**，
  VIEW / 等比例尺 / 尺寸线位置 / FIELD_AVOID / 结论卡片**全部沿用，无需重算**。
- 运动段总时长固定 16.60 s（`perUnit = MOTION_SEC/ARC_TOTAL`）⇒ 切换 n 不改 `SIM.duration`。
- 阶段恒 6 个：①受力 ②段1 ③段2 ④段3+4（一个回旋）⑤段5..末段 ⑥结论。
  阶段⑤文案按 `n` 生成：`再走 (n−1) 个「回旋」+ 末尾半圆`。
- 回旋点标注改为遍历 `KEY.gy`（O₁…O_n，y=−k·d）：n=3 有 3 个点，n=2 有 2 个。
- 结论卡片 / 读数面板 / O 下标全部按 `PAR.n` 动态生成。

**踩到的三个作用域坑（已回写 pitfalls §8.9）**
1. `__SETUP__` 是 `function setup(){}` 的**函数体** ⇒ 切换函数写在里面页面和
   Playwright 都拿不到（`applyN is not defined`）⇒ 必须放 GLOBALS 区。
2. `buildForN(N_LIST[0])` 必须放 GLOBALS 区**顶层末尾**，不能等 `setup()`——
   模板启动时 `resize()` 内部就会 `render()`，那时几何还没建。
3. `SEG_T` 被 `buildForN` 赋值 ⇒ `let` 必须声明在 `buildForN` 之前（TDZ）。

**新增测试 `test_n_switch.js`（29 项，两版都 ALL PASS）**
覆盖：两 n 的 r₂/d/B₂:B₁/nd/段数/末点归零/段间无缝/阶段数/按钮高亮、
n=3 全程 7 个时刻画布非白、零报错、切回 n=2 正常。
