## 2014·天津·12 同步加速器（教学动画）

### 一、物理（已核对官方三处解析：enjoyphysics / bodocs / 21cnjy）

- 题图几何（像素级实测原图）：左侧大片 ×（垂直纸面向里的磁场）；右侧 **N 在上、M 在下**
  两块带小孔的平行金属板，板缝居中；虚线圆轨迹半径 R，**圆的最右端恰在板缝处**；
  粒子 q 标在最左点、速度 v 向下。圆心画黑点，R 标注为圆心→左下方的半径箭头。
- (1) 第1周：qU=½mv₁² ⇒ v₁=√(2qU/m)；qv₁B₁=mv₁²/R ⇒ **B₁=(1/R)√(2mU/q)**。
  **要害**：R 被题设锁死，v 随加速增大 ⇒ B 必须同步增大（"同步加速器"之名由来）。
- (2) 第n周：nqU=½mvₙ² ⇒ vₙ=√(2nqU/m)；Tₙ=2πR/vₙ（随 n 减小）；
  一周只过板间一次 ⇒ Wₙ=qU；**P̄ₙ=qU/Tₙ=(qU/(2πR))√(2nqU/m)=(qU/(πR))√(nqU/(2m))**。
- (3) 题眼：**电场只在 A 过板间时存在**（过 N 板后两板电荷立即归零），
  故 B 仅在**与 A 同时**进入电场时才被加速。
  同场中 Tₙ=2πm/(qBₙ)、T'=2πm/(kqBₙ)=Tₙ/k ⇒ **A 绕 1 周，B 绕 k 周**。
  第 n 次加速后 vₙ'=√(2nkqU/m)=√k·vₙ；由 Tₙvₙ=2πR、T'vₙ'=2πR' ⇒ **R'=R/√k（与 n 无关，定值）**。
  几何：A、B 从同一小孔同向出发 ⇒ **两圆在板缝处内切**，B 的圆半径更小 ⇒ **选 A 图**。
  （选项 B 是三个同心小圆、C 是相交、D 是两圆相交，均不符。）

### 二、几何构造（世界坐标）

- 世界单位即 R：A 圆心 (−1,0)、半径 1，**过板缝点 (0,0)**；切向 orbTan(θ)=(−sinθ,cosθ)。
- B 圆：圆心 (−R/√k,0)、半径 R/√k，同样过 (0,0) ⇒ 与 A 圆在板缝处**内切**（切线均竖直）。
  公式 orbBPt(r,θ)=(−r+r·cosθ, r·sinθ) —— 用「半径 r、圆心在 (−r,0)」保证过原点。
- **相位对齐是物理核心**：A 的参数 θA=2π·u，B 的 θB=2π·(K·u)（u=A 的绕行周数）。
  u 为整数 ⇒ A 过板缝，K·u 亦为整数 ⇒ **B 同时过板缝**（这正是"同时被加速"的几何根源）。
- 方向核对：θ=π（最左点）切向朝下 ⇒ 与原题图「粒子在最左、v 向下」一致（逆时针）。

## 2015·天津·12 多层电磁场（教学动画）

### 一、物理（已核对 enjoyphysics / 21cnjy 两处官方解析 + 独立数值自检）

- 装置：每层 = 宽 d 的匀强**电场区**（E 水平向右）+ 宽 d 的匀强**磁场区**（B 垂直纸面向里），
  层与层紧密相邻；粒子从第1层电场左边界由静止释放。
- **(1)** 进第2层磁场时经**两次**电场加速 ⇒ ½mv₂²=2qEd ⇒ **v₂=2√(qEd/m)**；
  r₂=mv₂/(qB) = **(2/B)√(mEd/q)**。⇒ 第 n 层：vₙ=√(2nqEd/m)，rₙ=√(2nmEd/q)/B。
- **(2) 关键几何**：粒子在第 n 层磁场内走圆弧，圆心在入射点正上方，
  圆弧的水平跨度恰为磁场区宽度 d ⇒ **d = rₙ(sinθₙ − sinφₙ)**（φₙ=入射角，θₙ=出射角）。
  电场只沿水平 ⇒ 电场区内**竖直速度分量不变** ⇒ vₙsinφₙ = vₙ₋₁sinθₙ₋₁ ⇒
  **rₙsinφₙ = rₙ₋₁sinθₙ₋₁**。两式相减 ⇒ **{rₙsinθₙ} 是公差为 d 的等差数列** ⇒ **rₙsinθₙ = nd**
  ⇒ **sinθₙ = B√(nqd/(2mE))**（官方答案一致）。
  ★ 这是本题的题眼：等差数列公差 = 层宽 d。
- **(3)** 临界：水平位移最大值为 rₙ(1−sinφₙ)（速度竖直时取到），恰好不能穿出 ⇒ 该值 = d
  ⇒ **sinθₙ = 1（θₙ=π/2）**。换比荷 q'/m' 更大 ⇒ sinθₙ' = B√(nq'd/(2m'E)) > 1
  ⇒ θₙ' 不存在 ⇒ **比荷较大的粒子穿不出右边界**（官方答案）。
- 归一化演示参数：m=q=E=d=1，B=1/√2 ⇒ sinθₙ=√(n/4)，n=1..4 对应 30°,45°,60°,90°（n=4 恰临界）。

### 二、踩坑（新增 7 条，本题实测）

1. **★ 圆弧的世界角↔屏幕角映射极易写反**：世界点 P(a)=C+R(sin a, −cos a)（y 向上），
   屏幕极角 = π/2 − a ⇒ `ctx.arc` 的起止角与 anticlockwise 标志一旦写反，
   圆弧就画到**圆的对侧**（表现为「右上角多出一段红弧」）。
   **正解：干脆别用 ctx.arc —— 按世界坐标采样折线再走 W2S**（`arcW` 内 48 点采样），
   与物理轨迹逐点一致，零换算风险。同理角弧也用世界采样（顶点+R(cos t,sin t)）。
2. **`ensureView` 的纵向必须与 W2S 的 px/世界单位一致**：
   W2S 用 (H−2PAD)/(ymax−ymin) 作比例，而 scale 是按 band 算的 ⇒
   **ymax−ymin 必须 = (H−2PAD)/sPx**，否则内容会铺到整个可绘区、钻到 HUD 文字后面。
   且要按「高度受限 / 宽度受限」分别把**内容盒**对到**绘图带**（顶对齐或居中），
   否则层名「第1层」会被 HUD 第二行压住（层名要画在框上方 ⇒ 取景上沿须预留）。
3. **圆心可能落在取景框外**（第2、3层圆心远在上方）：画「指向画外圆心」的半径线
   会像乱线 ⇒ 圆心不在绘图带内时整段跳过（`drawArcGeom` 加可见性判断）。
4. **`buildAll()` 必须在 GLOBALS 顶层调用**，不能只放 setup()：框架启动顺序是
   resize()→…→setup()→render()，而 resize() 内部就会 render() ⇒ 首帧 stateAt 读到空数组直接抛
   TypeError，**画布全白 + 门禁 FAIL**（本项目 2024海南14 同款坑）。
5. **note/basis 走 innerHTML**：`<b>` 是合法标签，但裸 `>` 会破坏结构 ⇒ 转义为 `&gt;`；
   ★ 只能用「按标签切分再替换文本部分」的方式，**不能整体 replace('>','&gt;')**，
   否则 `</b>` 变成 `</b&gt;` 把闭合标签也毁掉。**title 走 textContent，绝不可转义**（会显示字面量）。
6. **表格/文字放在世界坐标里画**（不要用像素空间）：像素空间表格与等比取景不同步，
   单栏 680px 下会压到图形上。世界坐标表格随取景同比缩放，永不重叠。
7. **单栏 680px 必重看图**：三栏 480px 下勉强不叠的标签，680px 放大 1.4 倍后
   A/B/φ/θ 四个标签会互相压字 ⇒ 用 `opt.down`/`opt.up` 把角标推到不同高度带。

## 二、物理链（与官方答案逐条对齐，已数值自检）

- 加速 qU₀ = ½mv²；磁场 qvB = mv²/R ⇒ **r² = 2mU₀/(qB²)**（⇒ m = qB²r²/(2U₀)）
- 离子自 O **竖直向下**进入磁场（B 向里），洛伦兹力指向 +x ⇒ 圆心在 O 右侧 r 处、
  轨迹为**下半圆**，**落点距 O 恰为直径 2r**
- (1) 落在 P ⇒ 2r = OP = 3L/2 ⇒ r = 3L/4 ⇒ **m = 9qB²L²/(32U₀)**
- (2) 换电压 U：落点 x = 2r' = (3L/2)√(U/U₀)；要落在 QN=[5L/3, 2L]
  ⇒ √(U/U₀) ∈ [10/9, 4/3] ⇒ **100U₀/81 ≤ U ≤ 16U₀/9**
- (3) MQ=[L,5L/3] 内离子要全被检出：落点映射 x = λx₀（λ=√(U/U₀)）是**比例映射**，
  每次调压最多搬走**等比 6/5** 的一段 ⇒ (6/5)ⁿ ≥ 5/3 ⇒ n ≥ lg(5/3)/lg(6/5) ≈ 2.81 ⇒ **n = 3**
  可行构造：λ₁=5/3、λ₂=25/18、λ₃=125/108，三段 [L,6L/5]、[6L/5,36L/25]、[36L/25,5L/3]
  连续无缝，每段映射后都**完整落在 QN 内**

## 三、★ 本次踩到的新坑

1. **★ 半圆的「真实时长」≠「几何角」** —— 最隐蔽的一类物理 bug。
   归一化后 m=9/32 ⇒ 半圆真实时长 th = πm/(qB) = 0.884 s（**弧度值 0.884**），
   但半圆的几何角是 **π = 3.14 弧度**。写成 `theta = PI + th*u` ⇒ 离子只走完 50° 就停，
   画面上表现为「离子永远停在弧的左上段」，而 **所有门禁全 PASS**（画布非白像素由弧线贡献）。
   正解：`theta = PI + PI*u`，而 `th` 只用于「真实时间 → 屏幕时间」的换算。
   ⇒ **凡是「角度 = f(时长)」的动画，必须分清「几何量」与「时间量」两个 π 来源。**
2. **扫描参数时，屏幕时间分配要按真实时间比例**，不要随手给 0.74/0.20：
   加速:半圆真实比例 ≈ 1:5 ⇒ 屏幕应给 17% : 71%，否则离子长时间停在加速区、扫描叙事被稀释。
3. **窄条上的两个标签（MQ 宽 2/3 L、QN 宽 1/3 L）并排必叠字**：
   解法不是缩字号，而是**分置两个高度带** + 一条**向外偏移**出条形区。
4. **同一页多段并列 ⇒ 序号用单符号（①②③）放块内部**，不要写「第1次」——
   块宽仅 40~48 px，三个汉字标签必然叠字；单符号 15 px 绰绰有余。
5. **下标「₀」必须与主字符分开画，且偏移量由 `measureText` 量出**：
   写死 +7px 会随字号漂移（本次 U₀ 的 0 一度跑到 U 的左下方）。
6. **数值探针的判据也会写错**：「点是否在圆上」应比较 **|P−圆心| 与 R 之差**，
   直接比较 |P−圆心| 会得到「误差 = R」的假 FAIL。
7. **同页「原落点 / 映射后落点」用上下双标尺**，中间夹刻度尺；
   引导虚线只走在两排之间的空白带，且**斜段穿过的水平位置要算清楚**（本次实测交点 x=1.79~1.95，
   恰在标签范围 0.35~1.65 之外 ⇒ 不冲突，但仍须逐次验算）。
