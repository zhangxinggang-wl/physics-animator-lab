## 任务：第四题《超声波测车速（位移传感器·汽车 D 与仪器 C）》教学动画

题源：同一张教材照片**右栏**（第一章 运动的描述，【例 4】，题干跨栏：左栏起句 + 右栏续写）。原题紧邻
「4. 速度变化快慢的描述——加速度 / 第 1 课时 加速度的概念及计算」标题，故为「第四题」。
**题意**：汽车 D 向右匀速运动，不动的仪器 C 在某时刻发射短暂超声波脉冲；经过 0.2 s 接收到反射波；
再经过 0.025 s 发射第二个脉冲，发出后经 0.25 s 再次收到反射波。声速 340 m/s，结果三位有效数字。

**⚠️ 与「红外线+超声波」例题的关键区别（本项目新增经验）**：本题只有超声波一种信号，且是**脉冲往返测距**，
总时间 $t$ 含**去 + 回**，故单程距离 $= v\cdot t/2$（**不是** $v\cdot t$）；汽车「接收到脉冲」的时刻
$=$ 发射时刻 $+ t/2$。这是本题唯一的、也是最大的易错点。

**答案（经严格推导 + 反向核对）**：
- (1) $x_1 = v t_1/2 = 340\times0.2/2 = 34.0$ m
- (2) $\Delta t = t_1/2 + t + t_2/2 = 0.100+0.025+0.125 = 0.250$ s（与课本「总结提升」公式一致）
- (3) $x_2 = v t_2/2 = 42.5$ m，$\Delta x = 8.5$ m，$v_D = \Delta x/\Delta t = 34.0$ m/s $= 122$ km/h

**⚠️ 用户上传的手写答案 (3) 写的是 162 km/h，与推导不符**（162 对应 45 m/s，无法自洽）。已向用户确认
**采用 122 km/h**，并在解析里点明 $\Delta x$ 与 $\Delta t$ 必须配对。

产出：`2026-09-29_超声波测车速_教学动画.html`（2.20 MB，单文件自包含，**6 步解析 / 3 问分组**）。

### ⚠️ 本次抓到并修复的真实缺陷（3× 人工看图，自动化门禁完全查不出）

**症状**：t=2.149 / 2.700（脉冲②去程与回程）时，紫色波前弧**横穿 $\Delta x$ 尺寸箭头、压住 `P`/`Δx` 文字**，
弧下端切过车轮与橙色反射闪光点。

**根因**：`drawFront()` 的弧顶点高度 $= US\_Y + r\sin(\text{half})$，其中 $US\_Y=0.205$、`half=20°`。
脉冲②去程 $r_{max}=1.687$ 世界单位 ⇒ 顶点 $y=0.205+0.342\times1.687=\mathbf{0.782}$，
**越过 $\Delta x$ 线（0.73）与 $x_2$ 线（0.90）**。三栏版审计只取了 frac 0.632（t=2.149）等 8 个时刻，
`Δx` 被压那一段**恰好落在抽样间隙**，故漏检；本次按「覆盖每个阶段起始处」加密到 8 个 frac 才抓到。

**修法（双保险）**：
```js
const half = 10 * Math.PI / 180;                                   // 20° → 10°（顶点最高 0.498 < 0.56）
const yTop = Math.max(BAND_B1*H, W2S(0, Y_DIM1 - 0.02)[1]);        // 硬裁剪在最下尺寸线之下
```
**通用判据**：任何以 $(x_0,y_0)$ 为心、张角 $\pm\theta$、最大半径 $r_{max}$ 的圆弧，
顶点 $y_0+r_{max}\sin\theta$ 必须 < **最下方那条尺寸线的 $y$**。
本缺陷是「定向锥角长斜线」坑的**第三种形态**（第一、二种见位移传感器题），已一并写入 `MEMORY.md`。
