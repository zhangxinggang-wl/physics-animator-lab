### 单栏抽取（本题特有，补充通用规范）

- **canvas 有 1px×2 边框** ⇒ `clientWidth = CSS宽 − 2`。门禁硬编码 clientWidth=680，
  故 **CSS 宽须写 682**，否则差 2px 直接 FAIL（`单栏：画布 CSS 宽 680 → 678`）。
- 单栏 VIEW 须**整体重算**（含 ymin）：画布 clientWidth 680 ⇒ H=448.8、内宽 608；
  本题 `ymin -1.36/ymax 1.28` → 单栏 **`ymin -1.150 / ymax 1.490`**（yrange 仍锁 2.64）。
  反解法：装置纵向占 `1.50/yrange×(H−2PAD)` px，在「HUD 下沿 ~ 图例上沿」可用带内居中。
- `kpToggle` / `kpDrawer` DOM 位于 `<body>` 下、**`.wrap` 之外**，
  抽取脚本原版没删它们 ⇒ 必须按 `<aside ...>…</aside>` 配平单独删（**JS 侧不动**）。
- 「详细解析 / 分步解析」两词会残留在 HTML/JS **注释**里，探针要用精确串
  （`>详细解析</h2>` / title 全文），别用裸词否则永远 MISSING。

### 新踩的坑：指数衰减的「已停止」判据

- `coastAt` 里 `stopped: frac >= 0.999` 是**错的**：动画末段定格 frac 只到 0.917，
  判据永远不成立 ⇒「恰好静止」标记与"停在场内"两族的收尾全部失效（静默失败，探针查不出）。
  改 `stopped: frac >= 0.90`，并把该阈值写进生成器探针防回归。
- **框内右上角是稀缺位**：「磁场 B ⊗」与「恰好静止」抢同一处。
  最终分带：`RAIL_Y+0.055`=角标 e、`RAIL_Y−0.105`=恰好静止、`RAIL_Y−0.105`左对齐=磁场 B ⊗。

### 本题取的版面方案（可复用：装置 + 图表面板同屏）

- 世界坐标**只承载导轨装置**（x∈[-0.95,1.10]，占画布左 ~49%）；
  右侧 v–x 面板用**纯像素坐标**画在 `px = W*0.52` 起，两者不重叠。
  ⇒ 这类「装置 + 曲线面板同屏」的题，别把曲线塞进世界坐标。
- 等比例：`xmin=-1.10 xmax=3.30`（xr=4.40）⇒ `ymin=-1.36 ymax=1.28`（yr=2.64=4.40×0.60）。
- 竖向三段分带（占 H 比例）：横幅 0~0.09 / **HUD 0.098~0.217** / 装置 0.265~0.747 / 图例 0.90~0.97。

### 本轮踩到并修掉的缺陷（写生成器时须直接规避）

1. **HUD 行数上限 = 2**。3 行时 HUD 盒下沿会压住装置顶缘（窄画布 397px 下差 3~10px）。
   行数是硬约束，不是美观问题 —— 窄画布下 2 行才有 19~25px 正间隙。
2. **`processBanner` 模板不自动调用**，横幅必须自己 `drawBanner`；
   横幅+图例**常驻绘制**（否则 `首帧 banner/legend 非空` 门禁 FAIL），
   只有信息盒与 v–x 面板放 `if (t>0.002)` 让位判断。
3. **装置内标注必须按「水平带」分层**，同一 y 带放两条必叠字：
   `y=RAIL_Y+0.055` 只放角标、`+0.20` 放状态文字、`+0.34` 放 f、`+0.17` 放 v、`y=0` 放 M/N。
4. **角标 c/d/e/f 四角必须同 y 且 `plate` 一致**，否则白底差异让视觉错位（误判为「f 比 e 低」）。
5. **物体出界后标注要撤**：棒出 ef 后 M/N 会越框压右侧面板 ⇒ 出场后改标「出磁场后匀速」；
   安培力 f 必须判 `inField` 才画；速度矢量方向要随阶段反转并**限幅在 ef 内**。
6. **像素坐标面板内的三处叠字**：面板标题靠左上（避 ef 虚线）、ef 标签在轴上方 15px、
   x 轴标题另起一行在刻度下方 14px（不能与刻度数字同行）。
7. **位移轨迹带必须贴导轨内侧**（`RAIL_Y-0.035`）；浮在装置顶缘之上会变成一条无来由的灰条。
8. **tex 公式卡超长会在 1280 宽度溢出**（4 条超长 tex ⇒ `texOverflow=3`），
   详细推导放 note，tex 只留结论式。

### 本轮新踩的坑（都写进了 pitfalls 性质的经验）

1. **`drawTopHud` 必须支持「右对齐到世界坐标」**：文案长度随 t 变化（如 `t = n·(πm/qB) = …`
   越来越长），固定左起 x 必被右边界裁掉。做法是加 `xRight` 参数，先 `measureText`
   量总像素宽再除以全局 `scale` 换回世界宽，`x = xRight - total`。
2. **顶部同一条水平带只能承载一类文字**：`y=1.16` 已被居中结论
   （`r₂:r₁=√2:1`、`t=n·(πm/qB)=πBR²/(2U)`）占用，HUD 只能挪到 `y=0.92`。
3. **图例必须用【像素】定位钉在画布底部**（`py = H-14-(nRow-1-r)*17`），
   不能用 `W2S(0, -0.965)`。原因：`audit_page.js` 按画布高度固定切 15% 做 legend 区门禁，
   世界坐标会随各阶段 VIEW 不同漂出该区 ⇒ `首帧 legend 非空 → 0` FAIL。
4. **单栏抽取后必须按新内宽重算 VIEW 纵比**（否则 `W2S` 描的圆变椭圆）：
   单栏内宽 678 ⇒ `yrange/xrange = (0.66×678−72)/(678−72) = 0.6196`；
   主视图与 `VIEW_CHART` 两套 VIEW 都要按各自 xrange 重算 ymin/ymax（保持中心不变）。
5. **单栏容器 `max-width` 要 +26 而非 +24**：`.col` 有 `padding:12px` + `border:1px`，
   画布 CSS 680 要求容器 706 才不被压缩。
6. **单栏抽完后 `<canvas class="fig-canvas">` 字面串仍残留在一条旧注释里** ⇒ 探针假 FOUND。
   探针搜串前要么删注释、要么把探针写成带 `<canvas ` 前缀的完整串。
7. **`resize()` 内也有一次 `drawFigures()`**，只注释启动处那一次不够，两处都要处理。

### 图表阶段的分栏纪律

抛物线必须 `Math.min(…, B_T1)` 夹在轴内：一旦 `b2x(Bmax) > B_AX1`，曲线就会插进右侧说明区。
说明区长句一律从画布上删掉、只留图例，画布上只保留 ①② 两个小序号。
`b2x(B*)` 与刻度 `0.8` 只差 0.013，`B*` 标签必须左移 0.10 右对齐错开。

### 追加：粒子源 A 从圆心右移到 x=+0.133（用户嫌图形不美观）

`p_0 = 0` 改成 `p_0 = 0.15`（归一化后源点落在 x=+0.1326），并把缩放基准从
"max(|cx|+r)=1"改为"第 N 个半圆最左点 = −1"，两条约束在此等价，
`reach` 仍严格 = 1，出射点仍在左端出口，几何自洽未被破坏。

- 扫描结论：d ≤ 0.25 安全（reach=1.0）；d = 0.30 时 reach=1.038 会出盒 ⇒ 上限约 0.28。

  `var SOURCE_X = __SOURCE_X__;` 并在 `main()` 加 `.replace("__SOURCE_X__", repr(SOURCE_X))`，
  否则 JS 报 `ReferenceError: SOURCE_X is not defined`（画布仍白，因 updatePanel 有 try/catch）。
