**踩坑与修正**
1. **`canvas{width:100%}` 必须改定宽**：原 `.wrap` 是三栏 `1/2/1.3` 的 flex，只剩一栏时会被拉满整页宽度，`resize()` 按 `cv.clientWidth` 重算 → 画布整体放大、观感发虚。改为固定 680px（保持 0.65625 原比例）后，1280/1366/1600/1920 四宽度下 `cvCssW` 恒为 678，稳定。
2. **Python 字符串格式化里的 `%` 要写成 `%%`**：追加的 CSS 含 `max-width:100%`，直接 `%` 格式化报 `unsupported format character ';'`；改用 `.replace("__MAXW__", ...)` 占位解决。
3. **顺手修了完整版的一处真实叠字**：放大视图中旋转的 `v = ωr` 标签采用固定偏移 `+(4,+4)`，当 a 点转到左上方（约 t=0.42）时会与左侧固定说明文字「放大视图 / a 点绕环心匀速转动」叠在一起。修法两条并用：① 固定说明文字下先铺 `rgba(255,255,255,.94)` 白底矩形让位；② 标签偏移按矢量朝向取符号外推（`dx>=0?7:-7`、`dy>=0?13:-6`）。改完已重建完整版，`anim_only_canvas_mid.png` 确认不再叠字。
