## 物理推导（已与官方答案逐位核对，差 = 0.00e+00）
- **第(1)问**：v₀ 入射，正电荷在 × 区受洛伦兹力**向上**偏转；出口在 O 正上方 d/2
  ⇒ 轨迹为半径 d/4 的半圆 ⇒ R₀=d/4 ⇒ **B = 4mv₀/(qd)**。
- **第(2)问**：v=5v₀ ⇒ R=5d/4。四段圆弧各扫 **53°**（sin53°=0.8、cos53°=0.6）
  + 中间 2d 水平匀速直线：
  L = 4·(5d/4)·(53π/180) + 2d = (53π/36 + 2)d
  ⇒ **t = (53π+72)d/(180v₀)**。
  逐点轨迹：O(0,0)→(d,d/2)→(2d,d)→水平→(5d,d/2)→(6d,0)=O′（终点精确落在 O′）。
- **第(3)问**：中间两磁场各向内平移 s（②右移 s、③左移 s）：
  新增两段 5s/3 斜直线、中间直线段缩为 2d−2s ⇒ **ΔL = 4s/3**，Δt = ΔL/(5v₀) = 4s/(15v₀)。
  **约束**：轨迹最高点 d+4s/3 ≤ 2d（磁场上边界）⇒ s ≤ 3d/4
  ⇒ **Δt_max = d/(5v₀)**（此时轨迹恰好擦过区域上边界，中间直线段长 d/2）。

## 本次踩坑（新增，均已修）
1. **note 里裸 `<` 被浏览器当标签起始**：`\(R<d\)` 把整段公式截断 ⇒ 页面出现残缺 `\(R` 文本、
   触发「无裸定界符」门禁 FAIL。⇒ 一律写 `\lt`；**已在生成器加「note 裸尖括号门禁」**
   （扫 title/note/basis 三个字段）。
2. **世界单位字号当 px 用 ⇒ 全部标注不可见**：`ctx.font = size + 'px'` 里 size=0.15（世界单位）
   ⇒ 文字只有 0.15 px。⇒ 世界坐标文字必须 `size * scale` 换算成 CSS 像素（本项目此前一直用 px 定值，
   本题首次改用世界单位定字号 —— 换算后单栏/三栏自动同比例缩放）。
3. **圆弧参数化角未归一化 ⇒ 扫出 413° 的假整圆**：区域④ 起始角 `atan2(-0.6,-0.8)` 返回 −143.13°
   （第三象限），直接用 `a1-a0` 得扫角 270°−(−143.13°)=413° ⇒ 场景右侧多出一个巨大红圈。
   ⇒ 起始角必须**归一化到 [0,2π)**（`atan2(...) + 2π`）。
4. **ctx.arc 的 anticlockwise 参数与 W2S 的 y 翻转耦合**：世界角 a 对应屏幕角 −a；
   世界逆时针（a1>a0）⇒ 屏幕角递减 ⇒ 必须 `anticlockwise=true`。
   写反时圆心角标记会多绕 360°−Δθ（同样表现为场景里出现假大圆）。
5. **顶部横幅与「最高点」标注抢同一条空带**：最高点会升到 y=2d（磁场上边界），
   而视野上边界只有 2.55d、横幅占 8~37px ⇒ 标注放在上方/右方必被压住。
   ⇒ 文字固定放在磁场上边界**之上的窄带**（该带无任何点阵），用竖直引线从最高点连上去。
6. **特写裁剪脚本的 clip 换算**：page.screenshot 的 clip 用**页面 CSS 像素**，
   而 W2S 返回画布内 CSS 像素 ⇒ 需 `box.x + c.x`；dpr>1 时截图本身是设备像素
   ⇒ **用 canvas.drawImage + toDataURL 裁剪像素**最稳（`_build/_crop3.js`）。
