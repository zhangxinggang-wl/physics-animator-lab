**物理链条（独立推导，与官方答案逐条一致）**
设无量纲时间 τ = 物理时间/t0，水平速度 v0 = l/t0（板长 l 恰走 t0）。
- (1) 「恰好经极板边缘」⇒ 竖直位移 = l/2 ⇒ ½at₀² = l/2 ⇒ a = l/t₀²；
  a = qU0/(ml) ⇒ **U0 = ml²/(qt₀²)**。出射 v_x=v0、v_y=−v0 ⇒ β=−45°，转 270°，t_B = 3πm/(2qB)。
- (2) t0/2 进入：受场仅 t0/2（v_y = −v0/2），其后 U=0 走直线 ⇒ v = (√5/2)(l/t0)
  ⇒ **R = √5ml/(2qBt0)**；β=−26.57°，转 233.13°。
- (3) 通解 v_y = (τ_in − 1)v0 ⇒ tanβ = τ_in − 1；圆心角 **Δφ = π − 2β**
  （粒子从 x=0 射入、在圆上第一次回到 x=0 离开）。
  τ_in = 2（2t0 时刻进入）时 β=+45° 最大 ⇒ Δφ_min = 90° = T/4
  ⇒ **t_min = πm/(2qB)**。

**动画结构**：三族粒子（A/B/C，对应 τ_in = 0 / 0.5 / 2）共用 `arcOf(tin)` 统一参数化，

## 本次踩到的新坑（已补入 pitfalls 待归档）

1. **反斜杠门禁的写法**：门禁必须作用在 `r'''…'''` **原始源码**上。
   旧写法对 `re.sub` 后的**值**做检查，此时 `\\` 已被 r-string 折叠成单反斜杠，
   会把完全正确的 LaTeX 全部误判；改正则又掩盖了真 bug（`\sqrt{5}\,l` 少写一斜杠，
   在 JS 里 `\s` 被当转义符静默吞字符）。
   → 最终改为**手工扫描**（逐字符走，双反斜杠跳过，单反斜杠+字母报错），可靠。

2. **窄面板绝不做左右两栏**：三栏视口下面板仅约 145 px，
   「转角」与「t_B」做成左右两列会互撞（`270.0°` 压 `t_B=4.712`）。
   → 窄面板一律单列；标题按实测宽度裁剪降级（`t_B ∝ 圆心角 Δφ` → `t_B ∝ Δφ`）。

3. **HUD 每行必须短**：一行写 30+ 字符时字号被压到 8 px 以下仍溢出画布右缘。
   → HUD 只放「本段一句话结论」，详细推导全部放中栏解析；字号按实测最宽行反解。

4. **面板内条形与文字必须分两行**：画在同一基线上时条形被文字压住。

5. **圆心附近的标签预算**：弧半径只有 0.24 世界单位时，
   圆心一带最多容下「一个角弧 + 一个角度数字」；
   再放 O′ / R / v / 族号 四个标签必然挤成一团（无论怎么调偏移）。
   → **改为圆心角弧标注**，半径 R 的数值只交数据面板，画布上不画 R 标签。

6. **`ctx.arc` 吃的是像素不是世界单位**：角弧半径必须显式乘
   `(W − 2·PAD)/(xmax − xmin)` 转成 CSS 像素，否则 dpr=2 下画成 2 倍大的弧。
   且世界极角 θ → 屏幕极角是 `θ − 90°`（屏幕 y 轴向下）。

7. **粒子旁边的族号标签绝不能固定方位**：固定放下方会与圆心 O′ 叠；
   固定放左后方会压粒子源方框（板内 t≈0 时粒子恰在 x=−1 紧邻源框）。
   → 沿速度方向前移，再沿法向偏 0.085（法向符号按速度指向选，保证翻到弧外侧）。

8. **P/Q 角标不能挂板左端**：那里是板间距离竖直尺寸线所在，必叠。
   → 挂板线内侧右端（x = PL_X1 − 0.035，右对齐）。

9. **粒子源方框周围三方争位**：上方 v₀ 箭头、下方板长尺寸线、右侧板间距尺寸线。
   → 「粒子源」标签放方框**左侧**（取景内的纯空白带），v₀ 放正上方，尺寸线在窄缝内。

10. **板内电场箭头 E 不能放板内**（抛物线恰好扫过整个板间），
    也不能放 Q 板正下方（板长尺寸线带）→ 放在尺寸线再下方 y≈−0.82~−0.92。

11. **t=0 是左栏题图（孪生帧）**：必须只画装置，画布上任何弧/粒子/轨迹/面板都不能出现，
    否则题图会多出原题没有的图元。用 `const bare = (t <= 0.002)` 统一守卫。

12. **单栏抽取的两处必查**：
    - 切片 `s[ws:we]` **含 `<div class="wrap">` 开标签**，替换时必须把它写回去，
      否则 `.wrap > section.col` 选择器失配，audit 报「列数=0」。
    - 门禁量 `getBoundingClientRect().width`（含边框）与 `clientWidth`（不含），
      要 680/678 ⇒ canvas 必须 `box-sizing:border-box` 且 `.col-animation` 左右无 padding。
