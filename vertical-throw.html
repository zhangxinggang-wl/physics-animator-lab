3两种解法：同一时刻，两种思路

全程法（整体法）一个公式管到底

思路：把「上升 + 下落」看成同一个匀变速直线运动。全程加速度恒为 a = −g，只列一次方程。

v = v₀ − g t
h = v₀ t − ½ g t²
v² − v₀² = −2 g h

符号规则（必须先定正方向）：取竖直向上为正。v₀ 向上为正值；v > 0 表示向上运动、v < 0 表示向下运动；h > 0 在抛出点上方、h < 0 在抛出点下方。

此刻（0.00 s）用全程法：
v = v₀ − g t = 20.0 − 10.0×0.00= 20.00 m/s
h = v₀t − ½gt² = 20.0×0.00 − 5.0×0.00²= 0.00 m
⚠ 全程法最容易错的地方：把「位移 h」当成「离地高度」。公式里的 h 是相对抛出点的位移，落到抛出点下方时 h 为负值（例如求从楼顶抛出落到地面，应令 h = −h₀）。
分段法拆成上升、下落两段

思路：把运动拆成两段分别处理，最高点是分界点。

① 上升段（末速度为 0 的匀减速）：

t₁ = v₀ / g     H = v₀² / (2g)

② 最高点（速度为零的瞬间）：

v = 0  ，  a = −g（仍为 g，向下）

③ 下落段（初速度为 0 的自由落体，从最高点往下算）：

h↓ = ½ g (t − t₁)²     v↓ = g (t − t₁)

对称性（分段法的捷径）：上升与下落经过同一位置时速率相等、方向相反；上升到最高点用时 = 从最高点落回抛出点用时 = v₀/g。

此刻（0.00 s）用分段法：上升中
上升段用时 t₁ = v₀/g= 2.00 s
最大高度 H = v₀²/(2g)= 20.00 m
已上升时间= 0.00 s
上升高度 h↑ = v₀t − ½gt²= 0.00 m
当前位移 h = H − h↓= 0.00 m
⚠ 分段法最容易错的地方：认为最高点「速度为 0，加速度也为 0」。实际上最高点加速度仍是 g 竖直向下，否则小球就会停在空中不动了。

4同一问题对比：求落地时间 t₃ 与落地速度 v₃

全程法求解一步到位

取向上为正，落地时位移 h = −h₀，代入 h = v₀t − ½gt²：

−h₀ = v₀ t − ½ g t²
t₃ = ( v₀ + √(v₀² + 2 g h₀) ) / g
v₃ = v₀ − g t₃ = −√(v₀² + 2 g h₀)
t₃ = (20.0 + √(400.0 + 0.0)) / 10.0= 4.00 s
v₃ = −√(400.0 + 0.0)= −20.00 m/s

✔ 全程法不需要找最高点、不需要判断落到哪一段，特别适合抛出点与落地点不在同一水平面（如楼顶抛出落到地面）的问题。

分段法求解分三段累加

先算上升，再从最高点自由落体到地面：

t₁ = v₀ / g  ，  H = v₀² / (2g)
下落总高度 = H + h₀  →  t₂ = √( 2(H + h₀) / g )
t₃ = t₁ + t₂  ，  v₃ = −g t₂
t₁ = 20.0/10.0，H = 20.00 mt₁ = 2.00 s
t₂ = √(2×(20.00+0.0)/10.0)= 2.00 s
t₃ = t₁ + t₂= 4.00 s
v₃ = −g t₂= −20.00 m/s

✔ 分段法步骤多但每一步都是熟悉的模型（匀减速到零 + 自由落体），适合求最高点、上升/下落分段时间和分段路程。

两种方法结果完全一致：t₃ = 4.00 s，v₃ = −20.00 m/s。 一般规律：求「最高点、分段时间、分段路程」用分段法更直观；求「某时刻状态、落地时刻、落到抛出点下方」用全程法更省事。

5五个必须记住的要点

  • 只受重力，a 恒为 g 竖直向下——这是竖直上抛能被全程法处理的根本前提，上升、下降、最高点都一样。
  • 最高点 v = 0，但 a = g ≠ 0。速度为零不等于受力平衡。
  • 时间对称：t上 = t下 = v₀/g；速度对称：同一高度处上升与下落速率相等、方向相反。全程总时间（落回抛出点）为 2v₀/g。
  • 位移 ≠ 路程：落回抛出点时位移为 0，路程为 2H；用全程法算出来的 v、h 都带方向（正负号）。
  • 先定正方向再代公式。取向上为正时 a = −g；若取向下为正，则 v₀ 取负、a = +g，结果一致。

6小测验（g 取 10 m/s²）

1. 以 30 m/s 的初速度竖直向上抛出一小球，小球上升的最大高度和所用时间分别是？
答案 A。分段法/全程法都行：t₁ = v₀/g = 30/10 = 3 s；H = v₀²/(2g) = 900/20 = 45 m。（也可用 v² − v₀² = −2gh，最高点 v = 0 得 h = 45 m。）
2. 小球到达最高点的瞬间，它的速度和加速度是？
答案 B。最高点只是速度瞬时为零，小球始终只受重力，加速度恒为 g 竖直向下。若加速度也为 0，小球就会悬停在空中。
3. 以 20 m/s 竖直上抛，抛出后 2.5 s 小球的速度为？（取向上为正）
答案 B。全程法一步：v = v₀ − gt = 20 − 10×2.5 = −5 m/s，负号表示方向向下。此时小球已越过最高点（t₁ = 2 s）正在下落 0.5 s。
4. 从距地面 20 m 的平台上以 15 m/s 竖直上抛一小石子，落地时速度大小为？
答案 C。全程法：落地时位移 h = −20 m，由 v² − v₀² = −2gh 得 v² = 15² + 2×10×20 = 625，|v| = 25 m/s（方向向下）。
分段法验算：H = 15²/20 = 11.25 m，从最高点下落 11.25 + 20 = 31.25 m，v = √(2×10×31.25) = 25 m/s，✔ 一致。
