## 2. 核心公式速查（均用国际单位制 SI）

### 2.1 几何光学
- 反射定律：入射角 = 反射角（均相对法线）
- 折射定律（斯涅尔）：`n_1 \sin\theta_1 = n_2 \sin\theta_2`
- 折射率：`n = \dfrac{c}{v} \ge 1`（真空 `n=1`）
- 全反射（光密→光疏）：临界角 `\sin\theta_c = \dfrac{n_2}{n_1}`（`n_1 > n_2`）
- 光程：`L_n = n\, l`（用于等光程/干涉）
- 球面镜成像：`\dfrac{1}{f} = \dfrac{1}{u} + \dfrac{1}{v}`，`f = \dfrac{R}{2}`
- 薄透镜成像：`\dfrac{1}{f} = \dfrac{1}{u} + \dfrac{1}{v}`（或 `\frac{1}{f} = \frac{1}{d_o} + \frac{1}{d_i}`）
- 放大率：`m = \left|\dfrac{v}{u}\right| = \dfrac{h'}{h}`
- 透镜制造者公式：`\dfrac{1}{f} = (n-1)\left(\dfrac{1}{R_1} - \dfrac{1}{R_2}\right)`

### 2.2 物理光学
- 双缝干涉条纹间距：`\Delta x = \dfrac{\lambda L}{d}`
- 薄膜干涉（垂直入射，反射光）：
  - 暗纹：`2 n d = k\lambda`（存在半波损失时）
  - 亮纹：`2 n d = \left(k+\tfrac{1}{2}\right)\lambda`
- 单缝衍射暗纹：`a \sin\theta = k\lambda`（`k=\pm1,\pm2,\dots`）
- 偏振（选）：马吕斯定律 `I = I_0 \cos^2\alpha`

## 3. 符号与坐标约定（强制统一）

1. 角度 `\theta` 一律相对**法线**起算（反射/折射定律均如此）。
2. 采用实物、实像、实焦点为正的符号约定（或高斯符号约定），并在解析中明确说明所用约定。
3. 透镜/面镜：物距 `u`（物在镜前为正）、像距 `v`（实像为正、虚像为负）、焦距 `f`（凸透镜/凹面镜为正）。
4. 折射率 `n` 无量纲且 `n\ge 1`；相对折射率 `n_{21}=n_2/n_1`。
5. 波长 `\lambda` 注意介质中 `\lambda_n = \lambda_0 / n`；干涉计算用光程差而非几何路程差。
6. 单位长度统一（如 `mm`、`cm` 换算为 `m`），尤其 `\Delta x = \lambda L/d` 各量单位一致。

## 5. 解析正确性自检清单（每题必做，不可跳过）

1. **物理依据**：每步标注定律（如「由斯涅尔定律」「由薄透镜公式」）。
2. **量纲一致**：`1/f`、`1/u`、`1/v` 量纲一致（长度倒数）。
3. **符号约定**：实物/实像/焦距正负、角度参考线全程一致并声明。
4. **定律适用条件**：近轴光线？薄透镜近似？垂直入射？
5. **极限/特殊情形**：`u→∞`（平行光，`v=f`）、`u=f`（不成像）、`u<f`（虚像放大）。
6. **数值合理性**：`n\ge1`、视深 `<` 实深、放大率数量级合理。
7. **结论闭环**：回到题目所问（求像距/焦距/放大率/临界角/条纹间距）。

若任一项无法满足且无法当场核实，必须标注「⚠️ 该步骤待核实」。

### 通用强制条款（公式符号 · 与 mechanics_reference.md §7 / SKILL.md 同源）

> 以下四类写法适用于 `given` / `note` / `basis` / `readouts` 名称 / `tex` / 每问结论式 **所有字段**，不限于 `tex`：

- **单位（强制正体 upright）**：物理量单位必须正体、**禁止斜体**。两种合规写法：① **首选——单位作为纯文本写在公式环境外**（天然正体、源码干净），如 `$m_A=0.4$ kg`、`$v_0=2$ m/s`；② **单位必须嵌在数学式内时**（分式、复合量等无法外提），用 `\mathrm{}` 强制正体，如 `1.2\,\mathrm{m/s}`、`0.20\,\mathrm{m}`、`a=9.8\,\mathrm{m/s²}`。禁止把单位裸写在公式环境内却不包裹（如 `m/s`、`kg` 直接放进 `$...$` 会渲染成斜体，正是「单位用了斜体」的根因）；禁止嵌套 `\mathrm{\mathrm{kg}}`。（参考资料公式示例为通用 LaTeX，仅作知识点对照。）
- **角度/度**：`\^{\circ}`，如 `60\^{\circ}`、`\theta=60\^{\circ}`。**禁止** Unicode `°`、禁止 `^o`/`^0`、禁止 `度` 字（如 `60度`）。
- **变化量（Δ）**：大写 `\Delta`，如 `\Delta E`、`\Delta s`、`\Delta t`。**禁止** Unicode `△`。
- **根号**：`\sqrt{被开方数}`，如 `\sqrt{v_x^{2}+v_y^{2}}`。**禁止** Unicode `√`、禁止 `sqrt()`。

> **渲染与查看（防误判）**：公式由内置 MathJax 3 运行时渲染，**必须用支持 JavaScript 的浏览器打开**（双击 `.html` 或 WorkBuddy 预览面板）。本技能已强制「单位正体」：生成稿单位一律正体——公式外纯文本（天然正体）或公式内 `\mathrm{}`（强制正体），任何查看环境都不会出现斜体单位；若仍看到斜体单位，是旧文件请重新生成。数学符号（`\Delta`、`\sqrt{}`、`^{\circ}`、`\theta`）须保留 LaTeX 命令，在 JS 浏览器正常渲染，在非 JS 查看器以源码出现属正常查看方式问题，并非生成缺陷。

### 角度符号与矢量标注强制规范（ANGLE_SNAP / GREEK_VARIABLE / VECTOR_ARROW）

> 与 SKILL.md「## 角度符号与矢量标注强制规范」同源、同等强制，本手册仅作光学领域化提示。

1. **希腊角度符号强制（禁止中文名）**：光学角度（入射角 $\theta_1$、折射角 $\theta_2$、临界角 $\theta_c$、马吕斯角 $\alpha$）一律用符号，**禁止写成「西塔/阿尔法」等中文名**，也禁止 Unicode 近似；LaTeX 命令 `\theta \alpha \beta \phi \delta`。**时变角度须写 $\theta(t)$/$\phi(t)$**。
2. **[ANGLE_SNAP]**：重绘/动画中接近 30°/37°/45°/53°/60° 的角度必须精确吸附为对应特殊角（如 $36.8^\circ\to37^\circ$），避免出现不利于手算的非整数角；生成器由 `snap_special(deg)` 自动完成。
3. **[GREEK_VARIABLE]**：若动画涉及旋转偏振片、扫掠光路等时变角度，须用 $\theta(t)$/$\phi(t)$ 表示；动画区右上方加**实时角度显示器**（° 与 rad 同显），画布角度弧标签用 Unicode 字形 `θ`（不是 `\theta` 源码）。
4. **[VECTOR_ARROW]**：带角度的光线与法线、电场矢量等，箭头旁须显式标注角度值或符号，箭头长度正比于标量大小（如光强矢量按 `cos²α` 归一化长度）。

## 8. 典型题型正解库（保证解析正确）

生成解析前，须对照下列「标准解题范式」与「正解示例」逐条自检，确保符号、公式、数值、单位均无误。

### 8.1 光学标准解题范式
1. 几何光学先画光路图，**入射角、折射角一律相对法线量取**（不是与界面的夹角）。
2. 折射定律：$n_1\sin\theta_1=n_2\sin\theta_2$；折射率 $n=\dfrac{c}{v}$。
3. 全反射必须同时满足两个条件：① 光由**光密介质**射向**光疏介质**；② 入射角 $i\ge C$。
4. 波动光学：先判断光程差，再判定明暗；注意半波损失。
5. 透镜成像用 $\dfrac{1}{f}=\dfrac{1}{u}+\dfrac{1}{v}$，须先约定符号法则并保持全程统一。

### 8.2 正解示例
**例1 折射与全反射**
- 相对折射率：
$$ n_{21}=\dfrac{n_2}{n_1}=\dfrac{\sin\theta_1}{\sin\theta_2}\tag{1}$$
- 由介质射向空气（或真空）时临界角：$\sin C=\dfrac{1}{n}$。如 $n=\sqrt2$，则 
$$ C=45^\circ\tag{2}$$
- 易错：全反射漏判「光密→光疏」方向；把临界角公式写成 $\sin C=n$。

**例2 双缝干涉**
- 条纹间距：$\Delta x=\dfrac{L}{d}\lambda$（$L$ 为缝到屏距离，$d$ 为双缝间距）
- 第 $n$ 级明纹位置：$x_n=n\dfrac{L\lambda}{d}$（$n=0$ 为中央明纹）
- 暗纹位置：
$$ x=(2n+1)\dfrac{L\lambda}{2d}\tag{3}$$
- 易错：条纹间距与波长成正比、与双缝间距成反比，两者记反；$L$ 与 $d$ 颠倒。

**例3 薄膜干涉（垂直入射，折射率 $n$，厚度 $d$）**
- 光程差：$\Delta=2nd$，若存在一次半波损失则附加 
$$ \dfrac{\lambda}{2}\tag{4}$$
- 增透膜最小厚度：$d=\dfrac{\lambda}{4n}$（两束反射光均发生或均不发生半波损失时取此值）
- 易错：忽略反射时的半波损失；把膜中波长 $\lambda/n$ 当成真空波长使用。

**例4 薄透镜成像**
- $\dfrac{1}{f}=\dfrac{1}{u}+\dfrac{1}{v}$，放大率 
$$ m=\dfrac{|v|}{u}\tag{5}$$
- 采用实物 $u>0$ 的约定时：实像 $v>0$，虚像 $v<0$；凸透镜 $f>0$，凹透镜 
$$ f<0\tag{6}$$
- 易错：符号法则中途更换；把放大率写成 $v/u$ 而漏掉绝对值。

生成文件须通过：① 左栏题图完整（含光轴、焦点、物像箭头等全部要素）；② 右栏动画几何与题图 1:1；③ 镜/透镜类型、F/C 位置、特殊光线方向正确；④ 虚像用虚线、实像用实线；⑤ 抽取内联 JS 通过 `node --check`、浏览器控制台无报错。

## 10. 通用强制条款（线条图形重绘 · 动画与解析严格对应 · 清晰真实）

本技能最新要求，适用于**本册涉及的全部题型**，生成解析与动画前必须逐条满足：

1. **文字 OCR 入文件（图片题强制）**：若题目以图片上传，先用 OCR（本地 `_build/ocr/run_ocr.py` 或 `yescan-ocr-universal` 技能 / Read 视觉转录）把题干文字**逐字**识别进 `PROBLEM`（title/given/asks/options），遵守「题干原文一致性」；选择题还须把 A/B/C/D 四项完整录入 `PROBLEM.options`（四项**单行横排优先、单行放不下则四行纵向排列**渲染；详见技能 SKILL.md「选择题选项录入（强制）」）；OCR 易错字符（`l↔1`、`O↔0`、`α↔a`、`×↔x` 等）须人工复核订正，禁止把错识字当原题。
2. **线条图形 1:1 重绘（强制）**：题图为线条图形（实/虚线、几何形状、字母标注）时，**按照原线条图形重新绘制成完全相同的线条图形**——优先用本册 §9 的 `FIG.*` 图元（或自定义 `ctx`）1:1 重绘；几何、线型、比例、角度、标注、填充 7 维度与原图一致；零臆造（原图没有的辅助线/法线/网格一律不画）。详见 `figures_redraw_spec.md` §6。
3. **公式排版规范（强制）**：本题所有公式（含题目原文与解析、含每问结论式）一律标准 LaTeX（见本册 §7 与 SKILL.md「公式排版规范」），禁 `/` 分数、`sqrt()`、`v0`、`sin()` 等代码风格。
4. **动画与解析严格对应·清晰真实（强制）**：动画是解析的**忠实可视化**——`STEPS` 每一步 `t0~t1` 对应动画该步状态；用同一 `stateAt(t)` 同时驱动画面与数据面板；位移/速度/受力由**解析同一套公式与参数**实时计算，真实比例与数量级、绝不夸张扭曲；关键状态（最高点/碰撞/脱离/换路）高亮或 `FIG.processBanner` 明示，清晰可懂。
5. **解析禁用微积分（强制）**：写解析一律**不得使用微积分**（`\int`、`d/dt`、`\dot{x}`、微分方程），必须用**高中物理方法**：折射 / 成像用斯涅尔定律、薄透镜公式与几何光路（相似三角形），光程 / 条纹用几何关系与 ` \Delta x = L\lambda/d`，光强用叠加与振幅合成，**绝不用积分或微分方程**。`note` 允许「几何关系 / 叠加 / 平均值」等高中表述，但 `tex` **不得出现 `\int`**；校验：Playwright 检查页面文本不含 `∫` 或 `\int`。

6. **知识点分行显示·不覆盖解析（强制）**：`PROBLEM.knowledgePoints` 引用的每条知识点均**独立成卡、逐行排列（分行显示）**渲染——每个知识点占一行纵向堆叠，绝不挤成一行横排或逗号连写；卡片**只出现在左栏「试题原题」下方**（模板 `#kpInlineCards`），**绝不放入或覆盖中间「详细解析」栏**；相关知识点较多时仍保持逐行堆叠、左栏自然延伸，与中间解析板块无任何重叠遮挡。校验：Playwright 检查所有 `.kp-card` 均位于 `.col-problem` 内、`.col-analysis` 内不含任何 `.kp-card` 子元素。


8. **动画物理引擎 · 矢量可视化 · 公式零错误（强制）**：动画每一帧必须由**物理方程逐帧数值积分**得出（如 $x=x_0+v_0t+\tfrac12at^2$、简谐 $x=A\cos(\omega t+\phi)$、圆周 $x=R\cos(\omega t+\phi_0)$、竖直圆周用能量守恒 $v(\theta)=\sqrt{v_0^{2}+2gR(\cos\theta_0-\cos\theta)}$），**严禁用线性插值（Lerp）模拟物理运动**（匀速直线除外）；动力学场景须绘制受力分析（重力/弹力/摩擦力/向心力）与速度/加速度矢量箭头，箭头长度按比例缩放反映大小；所有矢量（速度/加速度/力）用带箭头线段表示，大小近零时自动淡出消失避免杂乱；抛体/圆周/振动开启「轨迹追踪」用浅灰虚线绘历史路径；画布建立合适坐标系（原点居中或左下、边缘显示坐标轴/刻度）。公式渲染**零错误**：所有 LaTeX 合法、无 `Math input error`；校验：Playwright 检查 `mjx-container.mjx-error` 数量为 0 且页面文本不含 `Math input error`。
