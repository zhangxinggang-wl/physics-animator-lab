## 2. 核心方法速查

### 2.1 量纲分析
- 基本量纲：长度 `[L]`、质量 `[M]`、时间 `[T]`、电流 `[I]`、温度 `[\Theta]`
- 速度 `[v]=[L][T]^{-1}`，加速度 `[a]=[L][T]^{-2}`，力 `[F]=[M][L][T]^{-2}`
- **量纲齐次原则**：等式各项量纲必须相同（检验推导是否错误的最快手段）
- 比例关系：若 `x \propto a^m b^n`，可用量纲配平指数（如单摆 `T\propto \sqrt{L/g}`）

### 2.2 矢量与坐标
- 合成/分解：正交分解最稳妥，`\vec{A}=\vec{B}+\vec{C}`
- 点积：`\vec{a}\cdot\vec{b}=ab\cos\theta`（投影、功）
- 叉积大小：`|\vec{a}\times\vec{b}|=ab\sin\theta`（力矩、洛伦兹力方向）
- 始终先声明坐标系（原点、正方向、角度起算）

### 2.3 误差与有效数字
- 绝对误差 `\Delta x`、相对误差 `\dfrac{\Delta x}{x}`
- 有效数字：运算结果位数向最不精确量看齐；中间过程多保留 1~2 位防截断误差
- 数量级 sanity check 是每题必做

### 2.4 单位制与换算
- SI 七基本量，导出量由定义/定律得到
- 常用换算：`1\,\mathrm{km/h} = \dfrac{1}{3.6}\,\mathrm{m/s}`，`1\,\mathrm{cm}=10^{-2}\,\mathrm{m}`，`1\,\mu C=10^{-6}\,\mathrm{C}`
- **所有量代入公式前先统一为 SI**
- **单位符号规范（强制）**：电阻单位写字面 `Ω`（禁止 `\Omega` 命令 / `Ohm` 单词）；面积/体积写 `m²`/`m³`/`cm²`（禁止 `m^2`/`m2`/`m^3` 代码式写法，尤其不能把 `^2`/`^3` 留在公式环境之外的裸文本里，会显示为 `m^2`）。其它单位（kg、m/s、J、N、T、C、V、A 等）一律强制正体（公式外纯文本天然正体，公式内用 `\mathrm{}` 强制正体）。详见 `figures_redraw_spec.md` §0.2 与 SKILL.md 第 7 条。

### 2.5 守恒思想
- 能量守恒、动量守恒、角动量守恒、电荷守恒——先判断系统与控制量、明确「守恒条件」
- 无法全程守恒时改用定理（动能定理、动量定理）或分段处理

### 2.6 近似与建模
- 小角近似：`\theta\ll1` 时 `\sin\theta\approx\theta`、`\tan\theta\approx\theta`（弧度）
- 模型假设（质点、刚体、理想气体、匀强场、忽略空气阻力）必须显式声明，并在结论中说明其影响

### 2.7 图解与图像法
- v-t 图：斜率=加速度，面积=位移
- p-V 图：面积=功
- 用图像求交点、面积、斜率，常比纯代数更直观

### 2.8 微积分工具
- 导数 `dx/dt` = 瞬时变化率（速度、加速度、电流 `I=dq/dt`）
- 积分 = 累积：`x=\int v\,dt`、`W=\int F\,dx`、`q=\int I\,dt`

## 3. 符号与约定（强制统一）

1. 角度默认用**弧度**参与微积分/小角近似；用度时需显式标注 `^\circ`。
2. 矢量用粗体或箭头 `\vec{v}`；标量不加箭头。
3. 微分/积分变量（如 `dx`、`dt`）书写规范，积分上下限对应物理过程的起止。
4. 任何近似（小角、忽略摩擦）必须写明并评估对结论的影响范围。

## 4. 易错点清单

- [ ] 等式两侧量纲不一致却未发现（应先做量纲检查）。
- [ ] 矢量当标量直接加减，漏掉方向/分量。
- [ ] 有效数字保留过多（假精度）或过少（丢失信息）。
- [ ] 单位未统一 SI 就代入公式。
- [ ] 在不满足条件下套用守恒（如有外力时误用动量守恒）。
- [ ] 小角近似在非小角场景滥用。
- [ ] 度数与弧度混淆（如 `\sin 30` 误当 30 弧度）。

## 7. 原理物理专属 LaTeX 符号规范

- 矢量：`\vec{v}`、`\vec{F}`；点积 `\cdot`、叉积 `\times`
- 微分/偏导：`dx`、`\dfrac{d}{dt}`、`\partial`
- 积分：`\int`、`\oint`
- 近似：`\approx`、`\sim`
- 量纲记号：`[L]`、`[M]`、`[T]`
- 通用规则（分数/根号/上下标/希腊字母）见 `mechanics_reference.md` 第 7 节。
- **单位（强制正体 upright）**：物理量单位必须正体、**禁止斜体**。两种合规写法：① **首选——单位作为纯文本写在公式环境外**（天然正体、源码干净），如 `$m_A=0.4$ kg`、`$v_0=2$ m/s`；② **单位必须嵌在数学式内时**（分式、复合量等无法外提），用 `\mathrm{}` 强制正体，如 `1.2\,\mathrm{m/s}`、`0.20\,\mathrm{m}`、`a=9.8\,\mathrm{m/s²}`。禁止把单位裸写在公式环境内却不包裹（如 `m/s`、`kg` 直接放进 `$...$` 会渲染成斜体，正是「单位用了斜体」的根因）；禁止嵌套 `\mathrm{\mathrm{kg}}`。（参考资料公式示例为通用 LaTeX，仅作知识点对照。）
- **角度/度**：`\^{\circ}`，如 `60\^{\circ}`。**禁止** Unicode `°`、`度` 字、`^o`。
- **变化量（Δ）**：`\Delta`，如 `\Delta E`、`\Delta s`。**禁止** Unicode `△`。
- **根号**：`\sqrt{...}`，如 `\sqrt{2gh}`。**禁止** Unicode `√`、`sqrt()`。
- 上述规则适用于 `given`/`note`/`basis`/`readouts`/`tex`/结论式 **所有字段**。

### 角度符号与矢量标注强制规范（ANGLE_SNAP / GREEK_VARIABLE / VECTOR_ARROW）

> 与 SKILL.md「## 角度符号与矢量标注强制规范」同源、同等强制，本手册仅作原理物理领域化提示。

1. **希腊角度符号强制（禁止中文名）**：物理常用角度一律用符号——$\theta$（西塔）、$\alpha$（阿尔法）、$\beta$（贝塔）、$\phi$（斐）、$\delta$（德尔塔），**禁止写成「西塔/阿尔法/贝塔/斐/德尔塔」等中文名**，也禁止 Unicode 近似；LaTeX 命令 `\theta \alpha \beta \phi \delta`。**时变角度须写 $\theta(t)$/$\phi(t)$**。
2. **[ANGLE_SNAP]**：矢量分解、平行四边形定则等重绘/动画中接近 30°/37°/45°/53°/60° 的角度必须精确吸附为对应特殊角（如 $36.8^\circ\to37^\circ$），避免出现不利于手算的非整数角；生成器由 `snap_special(deg)` 自动完成。
3. **[GREEK_VARIABLE]**：若动画涉及旋转的矢量合成、转动参考系等时变角度，须用 $\theta(t)$/$\phi(t)$ 表示；动画区右上方加**实时角度显示器**（° 与 rad 同显），画布角度弧标签用 Unicode 字形 `θ`（不是 `\theta` 源码）。
4. **[VECTOR_ARROW]**：所有矢量（力/速度/加速度/合矢量）箭头旁须显式标注角度值或符号，箭头长度正比于标量大小；矢量合成用 `FIG.forceParallelogram` 时同样满足。

## 8. 典型题型正解库（保证解析正确）

生成解析前，须对照下列「标准解题范式」与「正解示例」逐条自检，确保符号、公式、数值、单位均无误。

### 8.1 通用方法范式（跨板块通用）
1. **量纲分析**：任何结果先做量纲检验。$[v]=LT^{-1}$、$[a]=LT^{-2}$、$[F]=MLT^{-2}$、$[W]=[E]=ML^{2}T^{-2}$、$[p]=ML^{-1}T^{-2}$。
2. **图像法**：先明确「斜率是什么、面积是什么」，再读数。
   | 图像 | 斜率 | 面积 |
   |---|---|---|
   | $v$–$t$ | 加速度 $a$ | 位移 $x$ |
   | $x$–$t$ | 速度 $v$ | 无常用意义 |
   | $F$–$x$ | 劲度系数 $k$ | 功 $W$ |
   | $p$–$V$ | 无常用意义 | 气体做功 $W'$ |
   | $i$–$t$ | 无常用意义 | 电荷量 $q$ |
   | $\Phi$–$t$ | 感应电动势 $\mathcal{E}$ | 无常用意义 |
   | $U$–$I$ | 电阻 $R$（或 $-r$） | 功率相关 |
3. **极限/特殊值法**：令某参数取 $0$ 或 $\infty$，看结果是否符合物理直觉。
4. **微元法**：变力做功、非匀变速过程用 $W=\int F\,dx$ 或分段求和。
5. **矢量分解**：正交分解后各分量独立处理，合成用平行四边形（或三角形）法则。
6. **数量级估算**：分子尺度 $\sim10^{-10}\,\mathrm{m}$、地球半径 $6.4\times10^{6}\,\mathrm{m}$、光速 $3.0\times10^{8}\,\mathrm{m/s}$、重力加速度 $9.8\,\mathrm{m/s²}$。

### 8.2 高频错误对照表（生成解析时逐条排查）
| 易错点 | 错误做法 | 正确做法 |
|---|---|---|
| 矢量/标量混淆 | 把动量当标量、把磁通量当矢量 | 动量、冲量、电场强度是**矢量**；功、能量、磁通量是**标量** |
| 平均速度/平均速率 | 直接用 $\dfrac{v_1+v_2}{2}$ | 平均速度 $=\dfrac{\text{位移}}{\text{时间}}$；仅匀变速时等于 $\dfrac{v_1+v_2}{2}$ |
| 图像斜率与面积 | 张冠李戴 | 先写量纲：斜率的量纲是「纵轴/横轴」，面积是「纵轴×横轴」 |
| 单位换算 | 混用 cm、g、km/h | 一律先化为 SI：m、kg、s |
| 矢量方向 | 只算大小不写方向 | 求矢量必须同时给出大小与方向 |
| 结果合理性 | 算出子弹速度 $10^{8}\,\mathrm{m/s}$ | 与数量级基准对照，超限必是计算错误 |

### 8.3 量纲分析示例
**例**：单摆周期 $T$ 可能与摆球质量 $m$、摆长 $L$、重力加速度 $g$ 有关，设 $T\propto m^{a}L^{b}g^{c}$。
- 量纲：$[T]=T$，$[m]=M$，$[L]=L$，
$$ [g]=LT^{-2}\tag{1}$$
- 得 $M^{a}L^{b+c}T^{-2c}=T^{1}$，即 $a=0$、$b+c=0$、
$$ -2c=1\tag{2}$$
- 解得 $a=0$、$b=\tfrac{1}{2}$、$c=-\tfrac{1}{2}$，故 $T\propto\sqrt{\dfrac{L}{g}}$，与质量无关（比例系数 $2\pi$ 需由动力学推导确定）。

- 原理物理题（如「守恒 + 临界 + 过程拆分」）往往多过程：动画过程数必须等于题设过程数，不得合并或多余。
- 按 `t` 在 `SIM.duration` 内分段，用 `FIG.processBanner(...)` 显示过程名；切换时刻与解析转折点（碰撞、脱离、换路等）严格一致；切换连续无跳变。

### 9.4 质量门禁
生成文件须通过：① 左栏题图完整；② 右栏动画几何全部来自 `FIG.*`/自定义 1:1；③ 矢量方向、受力分析各力正确；④ 多过程过程数 = 题设且横幅命名一致；⑤ 抽取内联 JS 通过 `node --check`、浏览器控制台无报错。

## 10. 通用强制条款（线条图形重绘 · 动画与解析严格对应 · 清晰真实）

本技能最新要求，适用于**本册涉及的全部题型**，生成解析与动画前必须逐条满足：

1. **文字 OCR 入文件（图片题强制）**：若题目以图片上传，先用 OCR（本地 `_build/ocr/run_ocr.py` 或 `yescan-ocr-universal` 技能 / Read 视觉转录）把题干文字**逐字**识别进 `PROBLEM`（title/given/asks/options），遵守「题干原文一致性」；选择题还须把 A/B/C/D 四项完整录入 `PROBLEM.options`（四项**单行横排优先、单行放不下则四行纵向排列**渲染；详见技能 SKILL.md「选择题选项录入（强制）」）；OCR 易错字符（`l↔1`、`O↔0`、`α↔a`、`×↔x` 等）须人工复核订正，禁止把错识字当原题。
2. **线条图形 1:1 重绘（强制）**：题图为线条图形（实/虚线、几何形状、字母标注）时，**按照原线条图形重新绘制成完全相同的线条图形**——优先用本册 §9 的 `FIG.*` 图元（或自定义 `ctx`）1:1 重绘；几何、线型、比例、角度、标注、填充 7 维度与原图一致；零臆造（原图没有的辅助线/法线/网格一律不画）。详见 `figures_redraw_spec.md` §6。
3. **公式排版规范（强制）**：本题所有公式（含题目原文与解析、含每问结论式）一律标准 LaTeX（见本册 §7 与 SKILL.md「公式排版规范」），禁 `/` 分数、`sqrt()`、`v0`、`sin()` 等代码风格。
4. **动画与解析严格对应·清晰真实（强制）**：动画是解析的**忠实可视化**——`STEPS` 每一步 `t0~t1` 对应动画该步状态；用同一 `stateAt(t)` 同时驱动画面与数据面板；位移/速度/受力由**解析同一套公式与参数**实时计算，真实比例与数量级、绝不夸张扭曲；关键状态（最高点/碰撞/脱离/换路）高亮或 `FIG.processBanner` 明示，清晰可懂。
5. **解析禁用微积分（强制）**：写解析一律**不得使用微积分**（`\int`、`d/dt`、`\dot{x}`、微分方程），必须用**高中物理方法**：电荷量用 `q=It` 或平均电流 `\bar{I}=(I_1+I_2)/2`；焦耳热用 `Q=I^2Rt` 或 `I^2` 的时间平均 `(I_1^2+I_1I_2+I_2^2)/3`；速度/位移用运动学公式、动量定理 `m\Delta v=BLq`、能量守恒、图像斜率与面积；变力做功用动能定理 / 能量守恒 / 图像面积，**绝不解微分方程**。`note` 允许「图像面积 / 平均值 / 抛物线弓形」等高中表述，但 `tex` **不得出现 `\int`**；校验：Playwright 检查页面文本不含 `∫` 或 `\int`。

6. **知识点分行显示·不覆盖解析（强制）**：`PROBLEM.knowledgePoints` 引用的每条知识点均**独立成卡、逐行排列（分行显示）**渲染——每个知识点占一行纵向堆叠，绝不挤成一行横排或逗号连写；卡片**只出现在左栏「试题原题」下方**（模板 `#kpInlineCards`），**绝不放入或覆盖中间「详细解析」栏**；相关知识点较多时仍保持逐行堆叠、左栏自然延伸，与中间解析板块无任何重叠遮挡。校验：Playwright 检查所有 `.kp-card` 均位于 `.col-problem` 内、`.col-analysis` 内不含任何 `.kp-card` 子元素。


8. **动画物理引擎 · 矢量可视化 · 公式零错误（强制）**：动画每一帧必须由**物理方程逐帧数值积分**得出（如 $x=x_0+v_0t+\tfrac12at^2$、简谐 $x=A\cos(\omega t+\phi)$、圆周 $x=R\cos(\omega t+\phi_0)$、竖直圆周用能量守恒 $v(\theta)=\sqrt{v_0^{2}+2gR(\cos\theta_0-\cos\theta)}$），**严禁用线性插值（Lerp）模拟物理运动**（匀速直线除外）；动力学场景须绘制受力分析（重力/弹力/摩擦力/向心力）与速度/加速度矢量箭头，箭头长度按比例缩放反映大小；所有矢量（速度/加速度/力）用带箭头线段表示，大小近零时自动淡出消失避免杂乱；抛体/圆周/振动开启「轨迹追踪」用浅灰虚线绘历史路径；画布建立合适坐标系（原点居中或左下、边缘显示坐标轴/刻度）。公式渲染**零错误**：所有 LaTeX 合法、无 `Math input error`；校验：Playwright 检查 `mjx-container.mjx-error` 数量为 0 且页面文本不含 `Math input error`。
