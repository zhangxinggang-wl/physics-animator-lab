## 2. 核心公式速查（均用国际单位制 SI）

### 2.1 气体与内能
- 理想气体状态方程：`p V = \nu R T = \dfrac{m}{M} R T`，`R \approx 8.31\,\mathrm{J/(mol\cdot K)}`
- 压强微观：`p = \dfrac{1}{3} n m \overline{v^2}`（`n` 为分子数密度；`\overline{v^2}` 为速率方均值）
- 物质的量：`，\nu = \dfrac{N}{N_A} = \dfrac{m}{M}`
- 理想气体内能：`U = \dfrac{i}{2} \nu R T`（`i` 为自由度：单原子 3、双原子 5、多原子 6）

### 2.2 气体实验定律（质量不变）
- 玻意耳（等温）：`p V = \text{const}`
- 查理（等压，`V\propto T`）：`\dfrac{V}{T} = \text{const}`
- 盖-吕萨克（等容，`p\propto T`）：`\dfrac{p}{T} = \text{const}`
- 注意：`T` 必须为**热力学温度（K）**，`T = t + 273.15`

### 2.3 热力学第一定律
- 表达式（采用「外界对系统做功为正」约定）：`\Delta U = Q + W`
  - 系统吸热 `Q>0`，放热 `Q<0`；外界对系统做功 `W>0`，系统对外做功 `W<0`
- 准静态过程体积功：`W = -\int p\, dV`（系统对外做功为 `\int p\,dV`；符号随约定）
- 等温（理想气体）：`\Delta U = 0`；等容：`W = 0`；绝热：`Q = 0`

### 2.4 热机与循环
- 循环净功：`W_\text{net} = \oint p\, dV`（= 闭合 p-V 曲线所围面积，顺时针为正）
- 热机效率：`\eta = \dfrac{W_\text{net}}{Q_\text{吸}} = 1 - \dfrac{Q_\text{放}}{Q_\text{吸}}`
- 卡诺效率：`\eta_\text{卡诺} = 1 - \dfrac{T_\text{冷}}{T_\text{热}}`（`T` 用热力学温度）

### 2.5 相变与传热（选）
- 潜热：`Q = \lambda m`（`\lambda` 为熔化/汽化潜热）
- 热传导（傅里叶）：`\dfrac{Q}{t} = k A \dfrac{\Delta T}{d}`

## 3. 符号与坐标约定（强制统一）

1. 温度一律用**热力学温度** `T`（单位 K）参与公式计算；摄氏度 `t` 仅用于表述。
2. 功的符号约定二选一并显式声明：
   - 约定 A（本手册采用）：`\Delta U = Q + W`，`W` = 外界对系统做功；
   - 约定 B：`\Delta U = Q - W'`，`W'` = 系统对外做功。
   两种约定结果一致，但全程不得混用。
3. 内能 `U` 是状态量，只与初末态有关；`Q、W` 是过程量。
4. p-V 图中曲线下面积代表体积功；顺时针循环为热机（对外做功），逆时针为制冷。

## 4. 易错点清单（生成解析时逐项排查）

- [ ] 温度未换算成 K 直接代入公式（`T = t + 273`）。
- [ ] 混淆查理/盖-吕萨克：等压是 `V/T` 不变、等容是 `p/T` 不变。
- [ ] 功的符号约定前后不一致，导致 `\Delta U` 符号错。
- [ ] 误认为等温过程 `Q=0`（实际等温 `Q = W`，热量全部转化为功/反之）。
- [ ] 把循环净功当成某一段的功；净功 = 闭合 p-V 曲线面积。
- [ ] 效率超过卡诺极限 `\eta_\text{卡诺}`。
- [ ] 用错 `i`（自由度）算内能；实际气体/相变过程内能公式不同。
- [ ] 单位未统一为 SI（如 `L` 未换算为 `m³`、`cm²` 未换算为 `m²`）。

## 5. 解析正确性自检清单（每题必做，不可跳过）

1. **物理依据**：每步标注所用定律（如「由热力学第一定律」「由玻意耳定律」）。
2. **量纲一致**：`pV` 量纲 = 能量；`R T` 量纲 = 能量。
3. **符号约定**：功的约定、温度单位全程一致并声明。
4. **定律适用条件**：理想气体假设成立？过程是否准静态？
5. **极限/特殊情形**：`T→0`、体积趋于 0 等是否合理。
6. **数值合理性**：常温常压附近 `R`、`p_0\approx 1.0\times10^5\,\mathrm{Pa}`、效率 `<1` 且不超过卡诺。
7. **结论闭环**：回到题目所问（求压强/温度/功/效率/内能变化）。

若任一项无法满足且无法当场核实，必须标注「⚠️ 该步骤待核实」。

### 通用强制条款（公式符号 · 与 mechanics_reference.md §7 / SKILL.md 同源）

> 以下四类写法适用于 `given` / `note` / `basis` / `readouts` 名称 / `tex` / 每问结论式 **所有字段**，不限于 `tex`：

- **单位（强制正体 upright）**：物理量单位必须正体、**禁止斜体**。两种合规写法：① **首选——单位作为纯文本写在公式环境外**（天然正体、源码干净），如 `$m_A=0.4$ kg`、`$v_0=2$ m/s`；② **单位必须嵌在数学式内时**（分式、复合量等无法外提），用 `\mathrm{}` 强制正体，如 `1.2\,\mathrm{m/s}`、`0.20\,\mathrm{m}`、`a=9.8\,\mathrm{m/s²}`。禁止把单位裸写在公式环境内却不包裹（如 `m/s`、`kg` 直接放进 `$...$` 会渲染成斜体，正是「单位用了斜体」的根因）；禁止嵌套 `\mathrm{\mathrm{kg}}`。（参考资料公式示例为通用 LaTeX，仅作知识点对照。）
- **角度/度**：`\^{\circ}`，如 `60\^{\circ}`、`\theta=60\^{\circ}`。**禁止** Unicode `°`、禁止 `^o`/`^0`、禁止 `度` 字（如 `60度`）。
- **变化量（Δ）**：大写 `\Delta`，如 `\Delta E`、`\Delta s`、`\Delta t`。**禁止** Unicode `△`。
- **根号**：`\sqrt{被开方数}`，如 `\sqrt{v_x^{2}+v_y^{2}}`。**禁止** Unicode `√`、禁止 `sqrt()`。

> **渲染与查看（防误判）**：公式由内置 MathJax 3 运行时渲染，**必须用支持 JavaScript 的浏览器打开**（双击 `.html` 或 WorkBuddy 预览面板）。本技能已强制「单位正体」：生成稿单位一律正体——公式外纯文本（天然正体）或公式内 `\mathrm{}`（强制正体），任何查看环境都不会出现斜体单位；若仍看到斜体单位，是旧文件请重新生成。数学符号（`\Delta`、`\sqrt{}`、`^{\circ}`、`\theta`）须保留 LaTeX 命令，在 JS 浏览器正常渲染，在非 JS 查看器以源码出现属正常查看方式问题，并非生成缺陷。

## 8. 典型题型正解库（保证解析正确）

生成解析前，须对照下列「标准解题范式」与「正解示例」逐条自检，确保符号、公式、数值、单位均无误。

### 8.1 热学标准解题范式
1. 确定研究对象（一定质量理想气体）与过程类型（等温 / 等压 / 等容 / 绝热）。
2. 状态量用 $p$、$V$、$T$，**温度 $T$ 必须用热力学温度（K）**，$T=t+273.15$。
3. 过程量用 $W$、$Q$，状态量变化用 $\Delta U$。
4. 热力学第一定律：$\Delta U=W+Q$，其中 $W$ 为**外界对气体**做的功，$Q$ 为气体吸收的热量。
   若改用「气体对外做功」$W'$，则 $\Delta U=Q-W'$。二者不可混用。
5. 气体做功：$W'=\int p\,dV$，等压过程 $W'=p\Delta V$，即 $p$–$V$ 图过程线下的面积。
6. 理想气体内能只与温度有关：$\Delta U=\tfrac{i}{2}\nu R\Delta T$（单原子 $i=3$，刚性双原子 $i=5$）。

### 8.2 正解示例
**例1 理想气体状态方程**
- $\dfrac{p_1V_1}{T_1}=\dfrac{p_2V_2}{T_2}$，或 
$$ pV=\nu RT\tag{1}$$
- 易错：摄氏温度未换算为热力学温度；气体质量变化（漏气/充气）时不能直接用状态方程，须按物质的量分段处理。

**例2 四类基本过程（气体物质的量 $\nu$ 一定）**
- 等容：$W'=0$，
$$ Q=\Delta U=\nu C_V\Delta T\tag{2}$$
- 等压：$W'=p\Delta V$，
$$ Q=\Delta U+p\Delta V=\nu C_p\Delta T\tag{3}$$
- 等温：$\Delta U=0$，
$$ Q=W'=\nu RT\ln\dfrac{V_2}{V_1}\tag{4}$$
- 绝热：$Q=0$，$\Delta U=W$（外界对气体做的功全部转化为内能）

**例3 热机效率**
- 
$$ \eta=\dfrac{W_{\text{净}}}{Q_{\text{吸}}}=\dfrac{Q_{\text{吸}}-|Q_{\text{放}}|}{Q_{\text{吸}}}=1-\dfrac{|Q_{\text{放}}|}{Q_{\text{吸}}}\tag{5}$$
- 卡诺效率：$\eta_{\text{卡诺}}=1-\dfrac{T_{\text{低}}}{T_{\text{高}}}$（温度为热力学温度）
- 易错：分子是**净功**而非吸收的热量；效率不可能达到 $100\%$。

**例4 气缸—活塞模型**
- 水平放置、活塞面积 $S$：封闭气体压强 
$$ p=p_0\tag{6}$$
- 竖直放置、活塞质量 $m$：$p=p_0+\dfrac{mg}{S}$（活塞重力压向气体）或 $p=p_0-\dfrac{mg}{S}$（活塞被吊起）
- 加速上升的系统：对活塞用牛顿第二定律反推气体压强。
- 易错：漏掉大气压 $p_0$；把活塞重力方向判断反了；未对活塞（而非气体）列动力学方程。

| U 形管 / 液柱平衡 | 自定义 `ctx` + `FIG.vec` 标压强差 | 两侧液面高度差与压强平衡关系正确 |

### 9.3 多过程动画（过程数 = 题设过程数，强制）
- 热力学过程（如等容升温→等温膨胀→等压压缩）往往是多过程：动画过程数必须等于题设，用 `FIG.processBanner(...)` 显示当前过程名；切换时刻与状态转折点一致。

### 9.4 质量门禁
生成文件须通过：① 左栏题图完整；② 右栏动画几何与题图 1:1；③ p-V 曲线类型、气缸活塞位置、分子碰撞点正确；④ 多过程过程数 = 题设；⑤ 抽取内联 JS 通过 `node --check`、浏览器控制台无报错。

## 10. 通用强制条款（线条图形重绘 · 动画与解析严格对应 · 清晰真实）

本技能最新要求，适用于**本册涉及的全部题型**，生成解析与动画前必须逐条满足：

1. **文字 OCR 入文件（图片题强制）**：若题目以图片上传，先用 OCR（本地 `_build/ocr/run_ocr.py` 或 `yescan-ocr-universal` 技能 / Read 视觉转录）把题干文字**逐字**识别进 `PROBLEM`（title/given/asks/options），遵守「题干原文一致性」；选择题还须把 A/B/C/D 四项完整录入 `PROBLEM.options`（四项**单行横排优先、单行放不下则四行纵向排列**渲染；详见技能 SKILL.md「选择题选项录入（强制）」）；OCR 易错字符（`l↔1`、`O↔0`、`α↔a`、`×↔x` 等）须人工复核订正，禁止把错识字当原题。
2. **线条图形 1:1 重绘（强制）**：题图为线条图形（实/虚线、几何形状、字母标注）时，**按照原线条图形重新绘制成完全相同的线条图形**——优先用本册 §9 的 `FIG.*` 图元（或自定义 `ctx`）1:1 重绘；几何、线型、比例、角度、标注、填充 7 维度与原图一致；零臆造（原图没有的辅助线/法线/网格一律不画）。详见 `figures_redraw_spec.md` §6。
3. **公式排版规范（强制）**：本题所有公式（含题目原文与解析、含每问结论式）一律标准 LaTeX（见本册 §7 与 SKILL.md「公式排版规范」），禁 `/` 分数、`sqrt()`、`v0`、`sin()` 等代码风格。
4. **动画与解析严格对应·清晰真实（强制）**：动画是解析的**忠实可视化**——`STEPS` 每一步 `t0~t1` 对应动画该步状态；用同一 `stateAt(t)` 同时驱动画面与数据面板；位移/速度/受力由**解析同一套公式与参数**实时计算，真实比例与数量级、绝不夸张扭曲；关键状态（最高点/碰撞/脱离/换路）高亮或 `FIG.processBanner` 明示，清晰可懂。
5. **解析禁用微积分（强制）**：写解析一律**不得使用微积分**（`\int`、`d/dt`、`\dot{x}`、微分方程），必须用**高中物理方法**：气体做功 / 变力做功看 **p–V 图像面积**或用 `W=p\Delta V`（等压）、热力学第一定律，不用 `W=\int p\,dV`；过程量用状态方程与图像面积求。`note` 允许「图像面积 / 平均值 / 分段求和」等高中表述，但 `tex` **不得出现 `\int`**；校验：Playwright 检查页面文本不含 `∫` 或 `\int`。

6. **知识点分行显示·不覆盖解析（强制）**：`PROBLEM.knowledgePoints` 引用的每条知识点均**独立成卡、逐行排列（分行显示）**渲染——每个知识点占一行纵向堆叠，绝不挤成一行横排或逗号连写；卡片**只出现在左栏「试题原题」下方**（模板 `#kpInlineCards`），**绝不放入或覆盖中间「详细解析」栏**；相关知识点较多时仍保持逐行堆叠、左栏自然延伸，与中间解析板块无任何重叠遮挡。校验：Playwright 检查所有 `.kp-card` 均位于 `.col-problem` 内、`.col-analysis` 内不含任何 `.kp-card` 子元素。


8. **动画物理引擎 · 矢量可视化 · 公式零错误（强制）**：动画每一帧必须由**物理方程逐帧数值积分**得出（如 $x=x_0+v_0t+\tfrac12at^2$、简谐 $x=A\cos(\omega t+\phi)$、圆周 $x=R\cos(\omega t+\phi_0)$、竖直圆周用能量守恒 $v(\theta)=\sqrt{v_0^{2}+2gR(\cos\theta_0-\cos\theta)}$），**严禁用线性插值（Lerp）模拟物理运动**（匀速直线除外）；动力学场景须绘制受力分析（重力/弹力/摩擦力/向心力）与速度/加速度矢量箭头，箭头长度按比例缩放反映大小；所有矢量（速度/加速度/力）用带箭头线段表示，大小近零时自动淡出消失避免杂乱；抛体/圆周/振动开启「轨迹追踪」用浅灰虚线绘历史路径；画布建立合适坐标系（原点居中或左下、边缘显示坐标轴/刻度）。公式渲染**零错误**：所有 LaTeX 合法、无 `Math input error`；校验：Playwright 检查 `mjx-container.mjx-error` 数量为 0 且页面文本不含 `Math input error`。
