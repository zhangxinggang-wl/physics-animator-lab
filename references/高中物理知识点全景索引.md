## 一、力学 mech

### 1.1 运动学

#### mech-kinematics-uniform-motion（匀速直线运动）
- **公式**：\(x = x_0 + v t\)，\(v = \Delta x / \Delta t\)（恒量）
- **适用条件**：合外力为零（牛顿第一定律），或合外力始终与速度共线且平衡。
- **易错点**：
  1. 把「匀速直线运动的速度等于平均速度」当作所有运动的通式——只对匀速成立；
  2. 在追及相遇题里未明确参考系；
  3. 单位未统一（如 km/h 直接代入 m）。
- **难度**：基础
- **延展**：
  - 横向 → `princ-relative-motion`（相对运动：v_AB = v_A − v_B）
  - 纵向（竞赛）→ 一维非匀速仍可写 \(x(t) = x_0 + \int v\,dt\)

#### mech-kinematics-uniform-accel（匀变速直线运动）
- **公式**：
  - \(v = v_0 + a t\)
  - \(x = v_0 t + \tfrac{1}{2} a t^2\)
  - \(v^2 - v_0^2 = 2 a x\)
  - \(\bar{v} = \tfrac{v_0 + v}{2} = \dfrac{x}{t}\)（仅匀变速）
- **适用条件**：加速度 \(a\) 大小、方向均恒定；直线运动。
- **易错点**：
  1. 中时速度 \(\bar{v} = \tfrac{v_0+v}{2}\) 与中点速度 \(\sqrt{v_0 v}\) 混淆（仅匀变速时中时速度等于平均速度，中点速度仅在几何平均成立）；
  2. 把位移 \(x\) 当作路程 \(s\)（往返运动中 \(x \neq s\)）；
  3. \(a\) 代入时漏掉方向（应为带符号量）。
- **难度**：基础
- **延展**：
  - 横向 → `princ-graphical-analysis`（v-t 图斜率 = a，面积 = Δx）
  - 纵向（强基）→ 微元法：\(\Delta v = a(t)\,\Delta t\)，配合微分方程

#### mech-kinematics-free-fall（自由落体）
- **公式**：\(h = \tfrac{1}{2} g t^2\)，\(v = g t\)，\(v^2 = 2 g h\)；\(g \approx 9.8\,\mathrm{m/s²}\)（常取 9.8 或 10，须注明）
- **适用条件**：初速为零；不计空气阻力。
- **易错点**：
  1. 把 \(g\) 的方向当变量（其实恒向下为正方向时 \(a = +g\)）；
  2. 高度 h 与位移混淆（落回到起点时位移 = 0，路程 ≠ 0）。
- **难度**：基础
- **延展**：
  - 横向 → `mech-kinematics-projection-vertical`（竖直上抛）
  - 纵向（竞赛）→ 变加速下落的数值解（空气阻力正比 v²）

#### mech-kinematics-projection-vertical（竖直上抛）
- **公式**：
  - 上抛到最高点时间：\(t = v_0 / g\)
  - 最大高度：\(H = v_0^2 / (2 g)\)
  - 对称性：下落回到原点时速度大小 = \(v_0\)，方向反向。
- **适用条件**：不计空气阻力；初速竖直向上。
- **易错点**：
  1. 「先上升再下落」当作两段独立过程分别列方程（直接取竖直向上为正方向，全程 \(a = -g\) 即可）；
  2. 上升与下落时间不等的非对称问题（如初速非竖直的斜抛）。
- **难度**：基础
- **延展**：
  - 纵向（强基）→ 含空气阻力的非对称轨迹

#### mech-kinematics-projection-horizontal（平抛运动）
- **公式**（以抛出点为原点、水平向右为 \(x\)、竖直向下为 \(y\)）：
  - \(x = v_0 t\)，\(y = \tfrac{1}{2} g t^2\)
  - 速度分量：\(v_x = v_0\)，\(v_y = g t\)
  - 合速度：\(v = \sqrt{v_0^2 + (g t)^2}\)，\(\tan\theta = v_y / v_x\)
  - 轨迹方程：\(y = \dfrac{g}{2 v_0^2}\,x^2\)（抛物线）
- **适用条件**：不计空气阻力；初速水平。
- **易错点**：
  1. 把合速度 \(v\) 当水平分量；
  2. 飞行时间由**竖直方向**决定：\(t = \sqrt{2 h / g}\)（与水平初速无关）；
  3. 落地点的水平距离 \(x = v_0 \sqrt{2 h / g}\)。
- **难度**：基础
- **延展**：
  - 纵向（强基）→ 斜面上平抛、斜面平抛落点圆锥曲线证明

#### mech-kinematics-projection-inclined（斜抛运动）
- **公式**（以抛出点为原点、仰角 \(\theta\)、\(x\) 水平、\(y\) 竖直向上）：
  - \(x = v_0 \cos\theta \cdot t\)
  - \(y = v_0 \sin\theta \cdot t - \tfrac{1}{2} g t^2\)
  - 射高 \(H = \dfrac{v_0^2 \sin^2\theta}{2 g}\)
  - 射程 \(R = \dfrac{v_0^2 \sin 2\theta}{g}\)
  - 飞行时间 \(T = \dfrac{2 v_0 \sin\theta}{g}\)
- **适用条件**：不计空气阻力；初速与水平方向夹角 \(\theta\)。
- **易错点**：
  1. \(\sin 2\theta\) 取值范围 \([0,1]\)，最大射程对应 \(\theta = 45^\circ\)；
  2. 当落地点高度 ≠ 抛出点高度时，\(R\) 公式需另行推导；
  3. \(\tan\) 函数的角度定义要统一（与水平面夹角 vs 与斜面夹角）。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 斜面斜抛、阻力正比 v、轨迹几何性质

#### mech-kinematics-pursuit（追及相遇问题）
- **公式**：列方程 \(x_A(t) = x_B(t)\)，解出相遇时间；速度相等为**追上但不相撞**的临界。
- **适用条件**：一维；初位置、初速度、加速度已知。
- **易错点**：
  1. 同时同地出发 vs 同地不同时 vs 同时不同地三类情形要分清；
  2. 二次方程时间解有两个（先后），需判断是否物理合理；
  3. 「恰好不相撞」条件是 \(v_A = v_B\) 且 \(x_A \le x_B\)（不是 \(\Delta x = 0\)）。
- **难度**：基础
- **延展**：
  - 纵向（强基）→ 运动图像（x-t, v-t）的解法

### 1.2 相互作用

#### mech-force-gravity（重力）
- **公式**：\(G = m g\)，\(g \approx 9.8\,\mathrm{m/s²}\)
- **适用条件**：地球表面附近；不涉及高速/强引力场。
- **易错点**：
  1. 与万有引力混淆（\(G \neq F_{\text{引}}\)，区别在 \(g\) 是否随高度变化）；
  2. 失重状态下重力依然存在（只是视重为 0）。
- **难度**：基础
- **延展**：
  - 横向 → `modern-gravity-general-relativity`（等效原理）

#### mech-force-spring（弹簧弹力 / 弹性力）
- **公式**（胡克定律）：\(F = -k \Delta x\)（\(k\) 为劲度系数，\(\Delta x\) 为形变量）
- **适用条件**：弹性限度内；弹簧自然长度处 \(F = 0\)。
- **易错点**：
  1. 弹簧连接体分析时方向判定错误；
  2. 多弹簧串联/并联的等效 \(k\)：串联 \(1/k = \sum 1/k_i\)，并联 \(k = \sum k_i\)。
- **难度**：基础
- **延展**：
  - 横向 → `mech-energy-spring-potential`（弹性势能）
  - 纵向（强基）→ 弹簧振子周期 \(T = 2\pi\sqrt{m/k}\)

#### mech-force-friction-static-dynamic（摩擦力：静摩擦与动摩擦）
- **公式**：
  - 静摩擦：\(0 \le f \le f_{\max} = \mu_s N\)
  - 动摩擦：\(f = \mu_k N\)
- **适用条件**：
  - 静摩擦：相对静止但有相对运动趋势；先假设静摩擦再验算 \(f \le \mu_s N\)；
  - 动摩擦：相对滑动；方向与相对速度反向。
- **易错点**：
  1. 「静摩擦 = \(\mu_s N\)」是错误通式（最大静摩擦才是）；
  2. 压力 \(N\) 不一定等于重力（如斜面、加速系统）；
  3. 把摩擦力方向当「运动方向」——应该是相对运动（趋势）的反向。
- **难度**：基础
- **延展**：
  - 横向 → `mech-force-inclined-equilibrium`（斜面问题）
  - 纵向（竞赛）→ 摩擦角、临界自锁、传动带问题

#### mech-force-vector-decomposition（力的合成与分解）
- **公式**：平行四边形法则；正交分解：\(F_x = F\cos\alpha\)，\(F_y = F\sin\alpha\)
- **适用条件**：平面共点力。
- **易错点**：
  1. 三角形法则与平行四边形法则混用（两者本质相同，但顺序不同）；
  2. 分量与分力的关系——分力是等效替代，合力的求法；
  3. 单位向量法（高考向量考法）。
- **难度**：基础
- **延展**：
  - 纵向（强基）→ 拉密定理（sin 法则）、三力汇交的几何法

#### mech-force-equilibrium（共点力平衡）
- **公式**：\(\sum \vec{F} = \vec{0}\)，等价于 \(F_x = 0\)，\(F_y = 0\)
- **适用条件**：物体静止或匀速直线运动（牛顿第一定律）。
- **易错点**：
  1. 三力平衡时，三力可构成首尾相接的封闭三角形（几何法）；
  2. 多力平衡时优先用正交分解；
  3. 临界问题——先假设临界状态，再求其它。
- **难度**：基础
- **延展**：
  - 横向 → `mech-force-inclined-equilibrium`
  - 纵向（强基）→ 摩擦角与自锁条件

#### mech-force-moment-balance（力矩平衡）
- **公式**：\(\sum M_O = 0\)（对任一点 \(O\) 取矩）
- **适用条件**：刚体转动平衡（合力矩为零）。
- **易错点**：
  1. 力臂是「垂直距离」而非「沿杆距离」；
  2. 多个力的力矩要带符号（顺时针/逆时针方向）；
  3. 杠杆原理只是力矩平衡的特殊形式。
- **难度**：高考
- **延展**：
  - 横向 → `princ-vector-moment`（矢量叉积）

### 1.3 牛顿定律

#### mech-newton-first-law（牛顿第一定律：惯性定律）
- **公式**：\(\sum \vec{F} = \vec{0} \Rightarrow\) 静止或匀速直线运动
- **适用条件**：惯性参考系。
- **易错点**：
  1. 「力是维持运动的原因」是亚里士多德的错误观点——力是改变运动状态的原因；
  2. 「物体不受力就一定静止」错——也可匀速直线运动。
- **难度**：基础
- **延展**：
  - 横向 → `mech-relative-non-inertial-frame`（非惯性系）

#### mech-newton-second-law（牛顿第二定律）
- **公式**：\(\sum \vec{F} = m \vec{a}\)（矢量式，须按坐标轴分解）
- **适用条件**：惯性系；质量 \(m\) 恒定；低速宏观物体。
- **易错点**：
  1. 加速度方向 = 合力方向（不是速度方向）；
  2. 瞬时性——某一刻的 \(\sum F\) 决定该时刻的 \(a\)；
  3. \(\sum F\) 中**已包括重力、弹力、摩擦力**，不要再额外加「推力」。
- **难度**：基础
- **延展**：
  - 纵向（强基）→ 变质量问题（火箭方程）

#### mech-newton-third-law（牛顿第三定律）
- **公式**：\(\vec{F}_{12} = -\vec{F}_{21}\)（作用力与反作用力等大反向共线）
- **适用条件**：所有力（牛顿力学范围内）。
- **易错点**：
  1. 「一对作用力与反作用力」≠「一对平衡力」——前者作用在两个物体上，后者作用在同一物体上；
  2. 不存在「先作用后反作用」——同时产生同时消失。
- **难度**：基础
- **延展**：无特殊延展。

#### mech-newton-apparent-weight（超重与失重）
- **公式**：视重 \(N = m(g \pm a)\)（向上加速取 \(+\)，向下取 \(-\)）
- **适用条件**：物体在竖直方向有加速度的参考系中。
- **易错点**：
  1. 失重不是重力消失——重力仍然存在，只是支持力（视重）变小；
  2. 完全失重（\(N = 0\)）时，加速度 = \(g\)，但重力仍作用。
- **难度**：基础
- **延展**：
  - 横向 → `modern-gravity-general-relativity`（等效原理）

#### mech-newton-connected-body（连接体问题）
- **公式**：
  - 整体法：\(a = \dfrac{\sum F_{\text{外}}}{m_{\text{总}}}\)（加速度相同的连接体）
  - 隔离法：对单个物体写 \(\sum F = m a\)
- **适用条件**：绳/杆/弹簧轻质不可伸长，加速度相同。
- **易错点**：
  1. 绳和杆的区别：绳只能拉，杆可拉可压；
  2. 弹簧弹力**不能突变**，绳张力可以（绳刚性的理想模型）。
- **难度**：高考
- **延展**：
  - 纵向（竞赛）→ 滑轮组效率、变质量连接体

#### mech-newton-critical-problem（牛顿定律的临界问题）
- **公式**：先假设临界状态（如静摩擦 = \(\mu_s N\)），求该状态下的力/速度/位置；与实际条件比较。
- **适用条件**：题目中出现「恰好」「刚好」「最大」「最小」。
- **易错点**：
  1. 临界点往往对应**加速度的突变**或**静/动摩擦的转换**；
  2. 临界条件前后受力分析要分别进行。
- **难度**：高考
- **延展**：
  - 横向 → `mech-circular-vertical-loop`（竖直圆周最高点临界）

### 1.4 曲线运动

#### mech-circular-horizontal（水平圆周运动）
- **公式**：\(F_{\text{向}} = \dfrac{m v^2}{r} = m \omega^2 r = m \left(\dfrac{2\pi}{T}\right)^2 r\)
- **适用条件**：匀速圆周；半径 \(r\)、周期 \(T\) 恒定。
- **易错点**：
  1. 向心力是**合力**在径向的分量，不是「额外的力」；
  2. 周期 \(T\)、频率 \(f\)、角速度 \(\omega\)、线速度 \(v\) 的关系 \(v = \omega r = 2\pi f r\)；
  3. 离心运动是 \(F_{\text{向}} < m v^2 / r\) 时物体远离圆心。
- **难度**：基础
- **延展**：
  - 横向 → `mech-circular-vertical-loop`，`mech-conical-pendulum`

#### mech-circular-vertical-loop（竖直圆周运动）
- **公式**（绳模型）：最高点临界 \(v_{\min} = \sqrt{g r}\)
  - 杆模型：最高点 \(v\) 可为 0（杆可支撑）。
- **适用条件**：物体在竖直平面内做圆周运动；重力做功。
- **易错点**：
  1. 绳模型与杆模型在最高点的受力不同（绳只能拉，杆可推可拉）；
  2. 用能量守恒 \(E_k + E_p = \text{const}\)（轻绳/轻杆轻阻力时）；
  3. 在任意位置向心力 = 合力沿径向分量。
- **难度**：高考
- **延展**：
  - 纵向（竞赛）→ 水流星、锥摆临界、离心轨道

#### mech-conical-pendulum（圆锥摆）
- **公式**：\(\omega = \sqrt{\dfrac{g}{L \cos\theta}}\)，\(T = 2\pi\sqrt{\dfrac{L \cos\theta}{g}}\)
- **适用条件**：小球在水平面内做匀速圆周，绳与竖直方向夹角 \(\theta\) 恒定。
- **易错点**：
  1. 绳张力的水平分量提供向心力，竖直分量平衡重力；
  2. 转速越高 \(\theta\) 越大。
- **难度**：高考
- **延展**：
  - 横向 → `em-cyclotron`（类似几何，回旋加速器）

#### mech-curved-decomposition（曲线运动的合成与分解）
- **公式**：\(\vec{v} = \vec{v}_1 + \vec{v}_2\)，\(\vec{a} = \vec{a}_1 + \vec{a}_2\)（矢量合成）
- **适用条件**：合运动可分解为两个方向独立的分运动。
- **易错点**：
  1. 合速度大小 \(v = \sqrt{v_1^2 + v_2^2 + 2 v_1 v_2 \cos\alpha}\)；
  2. 切向加速度改变速度大小，法向加速度改变方向。
- **难度**：基础
- **延展**：
  - 纵向（强基）→ 速度合成定理（牵连 + 相对 = 绝对）

### 1.5 万有引力

#### mech-gravity-kepler（开普勒三定律）
- **公式**：
  - 第一：椭圆轨道，太阳在焦点；
  - 第二：行星与太阳连线在相等时间内扫过相等面积；
  - 第三：\(T^2 / a^3 = \text{const}\)（\(a\) 为半长轴）。
- **适用条件**：太阳系内（万有引力平方反比）。
- **易错点**：
  1. 「圆轨道是椭圆轨道的特例」；
  2. 周期 \(T\) 与质量无关（开普勒第三定律对双星系统不适用——需用两体的相对运动）。
- **难度**：高考
- **延展**：
  - 横向 → `mech-gravity-law`（万有引力定律）
  - 纵向（强基）→ 平方反比有心力的一般轨道方程

#### mech-gravity-law（万有引力定律）
- **公式**：\(F = G \dfrac{m_1 m_2}{r^2}\)，\(G \approx 6.67 \times 10^{-11}\,\mathrm{N \cdot m²/kg²}\)
- **适用条件**：质点；球体距离 \(r\) 取球心距离（均匀球壳外）。
- **易错点**：
  1. 球内引力按「内部质量集中于球心」折算；
  2. 卫星轨道处 \(g = \dfrac{GM}{r^2}\)，不等于地面 \(g\)。
- **难度**：基础
- **延展**：
  - 横向 → `modern-gravity-general-relativity`

#### mech-gravity-satellite（卫星运动）
- **公式**：\(\dfrac{GMm}{r^2} = \dfrac{m v^2}{r} = m \omega^2 r = m \left(\dfrac{4\pi^2}{T^2}\right) r\)
  - 速度：\(v = \sqrt{GM/r}\)
  - 周期：\(T = 2\pi\sqrt{r^3/(GM)}\)
  - 高度越高，速度越小、周期越大。
- **适用条件**：匀速圆轨道。
- **易错点**：
  1. 「卫星越高越慢」对，但对**发射速度**相反（要更大）；
  2. 同步卫星：周期 24h，固定高度约 36000 km（赤道上空）；
  3. 第一、二、三宇宙速度分别是地面附近的最大轨道速度、脱离速度、飞出太阳系速度。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 椭圆轨道开普勒方程、霍曼转移轨道

#### mech-gravity-binary-star（双星问题）
- **公式**：两者绕共同质心做圆周，\(\dfrac{G m_1 m_2}{L^2} = m_1 \omega^2 r_1 = m_2 \omega^2 r_2\)，\(L = r_1 + r_2\)
  - 总质量：\(m_1 + m_2 = \dfrac{4\pi^2 L^3}{G T^2}\)
- **适用条件**：两体互相绕转（孤立系统）。
- **易错点**：
  1. 双星的周期相同，角速度相同，但半径不一定相同；
  2. 质心位于两者之间，按质量反比分布。
- **难度**：高考
- **延展**：
  - 纵向（竞赛）→ 三体问题、拉格朗日点

### 1.6 功与能

#### mech-energy-work（功）
- **公式**：\(W = F s \cos\alpha\)（恒力）
- **适用条件**：恒力；位移沿力作用点的位移。
- **易错点**：
  1. 摩擦力做功：\(W_f = -f s\)（与路径反向）；
  2. 重力做功：\(W_G = m g h\)（只与高度差有关，与路径无关）；
  3. 功是标量但有正负（看力与位移夹角）。
- **难度**：基础
- **延展**：
  - 纵向（强基）→ 变力做功 \(W = \int \vec{F} \cdot d\vec{s}\)

#### mech-energy-power（功率）
- **公式**：\(P = W/t = F v \cos\alpha\)（瞬时功率）；额定功率 vs 实际功率
- **适用条件**：力 \(F\) 与速度 \(v\) 同时存在。
- **易错点**：
  1. 机车启动问题：恒定功率启动 vs 恒定牵引力启动，两种模型不同；
  2. \(P = F v\) 中 \(F\) 是合力（除牵引力外其它力的合力）。
- **难度**：高考
- **延展**：
  - 横向 → `em-power-circuit`（电功率）

#### mech-energy-kinetic（动能）
- **公式**：\(E_k = \tfrac{1}{2} m v^2\)（标量，恒正）
- **适用条件**：低速宏观物体。
- **易错点**：
  1. 动能是标量（无方向），动量是矢量（有方向）；
  2. 动能定理用合外力的功（不是某一力的功）。
- **难度**：基础
- **延展**：
  - 纵向（强基）→ 相对论动能 \(E_k = (\gamma - 1) m c^2\)

#### mech-energy-potential-gravity（重力势能）
- **公式**：\(E_p = m g h\)（零势能面自取）
- **适用条件**：地球表面附近；保守力。
- **易错点**：
  1. 零势能面可任取，但**全过程要一致**；
  2. 重力做功与重力势能变化：\(W_G = -\Delta E_p\)。
- **难度**：基础
- **延展**：
  - 横向 → `mech-energy-spring-potential`

#### mech-energy-spring-potential（弹性势能）
- **公式**：\(E_p = \tfrac{1}{2} k x^2\)（\(x\) 为形变量）
- **适用条件**：弹性限度内；自然长度处 \(E_p = 0\)。
- **易错点**：
  1. 弹簧被拉伸或压缩时都有 \(E_p\)（只与形变量大小有关）；
  2. 弹簧弹力做功与弹性势能变化：\(W_{\text{弹}} = -\Delta E_p\)。
- **难度**：基础
- **延展**：
  - 横向 → `wave-shm-spring`（弹簧振子周期公式来源）

#### mech-energy-work-energy-theorem（动能定理）
- **公式**：\(\sum W = \Delta E_k = \tfrac{1}{2} m v^2 - \tfrac{1}{2} m v_0^2\)
- **适用条件**：合外力做的总功。
- **易错点**：
  1. 定理中的「合外力做的功」= 各个外力做功的代数和（含正负）；
  2. 适用于**单个物体**或**可视为整体的物体系**；
  3. 不要求恒力或匀变速（变力也成立）。
- **难度**：基础
- **延展**：
  - 纵向（强基）→ 质点系动能定理（含内力做功）

#### mech-energy-conservation-mechanical（机械能守恒定律）
- **公式**：\(E_{k1} + E_{p1} = E_{k2} + E_{p2}\)
- **适用条件**：只有重力或弹簧弹力做功，**其它力不做功或做功之和为零**。
- **易错点**：
  1. 摩擦力做功 → 机械能减少（转化为内能）；
  2. 空气阻力、绳子张力等外力做功也要纳入考虑；
  3. 在某个参考系中守恒的，不一定在其它参考系守恒。
- **难度**：基础
- **延展**：
  - 横向 → `mech-energy-work-energy-theorem`（更广义的能量守恒）
  - 纵向（强基）→ 拉格朗日方程中的机械能

#### mech-energy-functional-relationship（功能原理）
- **公式**：\(W_{\text{非重非弹}} = \Delta E_{\text{机械能}}\)
- **适用条件**：除重力和弹簧弹力外的其它力做功之和。
- **易错点**：
  1. 与动能定理的区别：动能定理用合外力的功（重力、弹力都包括），功能原理用除重/弹外其它力的功；
  2. 应用时先选定系统（机械能 = 动能 + 重力势能 + 弹性势能）。
- **难度**：高考
- **延展**：无特殊延展。

### 1.7 动量

#### mech-momentum-definition（动量）
- **公式**：\(\vec{p} = m \vec{v}\)（矢量，方向与速度同）
- **适用条件**：经典力学。
- **易错点**：
  1. 动量是矢量（不能只看大小）；
  2. 动量与动能都是描述运动的物理量，但前者是矢量后者是标量。
- **难度**：基础
- **延展**：
  - 纵向（强基）→ 相对论动量 \(\vec{p} = \gamma m \vec{v}\)

#### mech-momentum-impulse（冲量与动量定理）
- **公式**：\(\vec{I} = \vec{F} \Delta t\)（恒力）；\(\vec{I} = \int \vec{F}\,dt\)（变力）
  - 动量定理：\(\vec{I} = \Delta \vec{p} = m \vec{v} - m \vec{v}_0\)
- **适用条件**：单个物体或物体系。
- **易错点**：
  1. 冲量是矢量（\(\vec{F}\) 与 \(\Delta t\) 同方向）；
  2. 适用于变力（用平均力代替）；
  3. 矢量方程，要按坐标轴分解。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 角动量定理

#### mech-momentum-conservation（动量守恒定律）
- **公式**：\(m_1 \vec{v}_1 + m_2 \vec{v}_2 = m_1 \vec{v}_1' + m_2 \vec{v}_2'\)（系统合外力为零）
- **适用条件**：系统不受外力或合外力为零；或某方向合外力为零则该方向动量守恒。
- **易错点**：
  1. 「内力不能改变系统总动量」——内力可使动量在系统内部分配；
  2. 速度必须相对于同一惯性参考系；
  3. 「动量近似守恒」条件：内力 << 外力 或 作用时间极短（如碰撞）。
- **难度**：基础
- **延展**：
  - 纵向（强基）→ 角动量守恒

#### mech-momentum-collision-1d（一维碰撞）
- **公式**：
  - 完全弹性碰撞：\(v_1' = \dfrac{m_1 - m_2}{m_1+m_2} v_1 + \dfrac{2 m_2}{m_1+m_2} v_2\)，\(v_2'\) 类似；
  - 完全非弹性碰撞：\(v' = \dfrac{m_1 v_1 + m_2 v_2}{m_1+m_2}\)
- **适用条件**：一维；碰撞时间极短（外力冲量可忽略）。
- **易错点**：
  1. 弹性碰撞中动量守恒 + 动能守恒；非弹性碰撞只动量守恒；
  2. 碰后速度要带回原式验算合理性；
  3. 弹簧轻质不可伸长 ≠ 弹性碰撞（只是理想化模型）。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 二维碰撞、质心系分析

#### mech-momentum-recoil-explosion（反冲与爆炸）
- **公式**：爆炸前总动量 = 爆炸后总动量
- **适用条件**：内力 >> 外力的瞬时过程。
- **易错点**：
  1. 化学能 → 机械能，故总动能增加；
  2. 速度方向沿连线但反向（动量守恒）。
- **难度**：高考
- **延展**：
  - 横向 → `mech-momentum-conservation`
  - 纵向（竞赛）→ 多体反冲、火箭推进

## 二、机械振动与机械波 wave

### 2.1 简谐运动

#### wave-shm-definition（简谐运动的定义）
- **公式**：\(F = -k x\)（回复力与位移反向且大小成正比）
  - 运动学定义：\(a = -\omega^2 x\)
- **适用条件**：弹性回复力（弹簧振子）或等效回复力（单摆小角度）。
- **易错点**：
  1. 不是所有振动都是简谐（受迫振动、阻尼振动一般非简谐）；
  2. 单摆的小角度近似：\(\sin\theta \approx \theta\)，大角度含高阶修正。
- **难度**：基础
- **延展**：
  - 纵向（强基）→ 非线性振动、杜芬振子

#### wave-shm-spring（弹簧振子）
- **公式**：
  - 周期：\(T = 2\pi\sqrt{m/k}\)
  - 频率：\(f = \dfrac{1}{2\pi}\sqrt{k/m}\)
  - 振动方程：\(x(t) = A \cos(\omega t + \varphi)\)
- **适用条件**：水平光滑面上弹簧振子；弹簧质量忽略。
- **易错点**：
  1. 竖直弹簧振子的等效 \(k\) 不变，只是平衡位置下移；
  2. 双振子（弹簧连接两物体）的等效折合质量。
- **难度**：高考
- **延展**：
  - 纵向（竞赛）→ 耦合振子、简正模式

#### wave-shm-pendulum（单摆）
- **公式**：\(T = 2\pi\sqrt{L/g}\)（小角度近似）
- **适用条件**：单摆（轻绳+小球）；\(\theta \le 5^\circ\) 近似成立。
- **易错点**：
  1. 周期与摆球质量、振幅无关（小角度时）；
  2. 复摆周期 \(T = 2\pi\sqrt{I/(mgd)}\)（绕固定轴）。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 大角度单摆的非谐修正

#### wave-shm-equation-and-graph（振动方程与振动图像）
- **公式**：
  - 振动方程：\(x(t) = A \cos(\omega t + \varphi)\)
  - 三要素：振幅 \(A\)、角频率 \(\omega\)、初相位 \(\varphi\)
- **适用条件**：简谐运动。
- **易错点**：
  1. 从 x-t 图像读周期、振幅、初相位；
  2. 速度相位超前位移 \(\pi/2\)，加速度与位移反相；
  3. 简谐运动不是匀速运动（速度随时间变化）。
- **难度**：高考
- **延展**：无特殊延展。

#### wave-shm-energy（简谐运动的能量）
- **公式**：
  - 动能：\(E_k = \tfrac{1}{2} k A^2 \sin^2(\omega t + \varphi)\)
  - 势能：\(E_p = \tfrac{1}{2} k A^2 \cos^2(\omega t + \varphi)\)
  - 总能：\(E = \tfrac{1}{2} k A^2\)（守恒）
- **适用条件**：弹簧振子。
- **易错点**：
  1. 最大位移处 \(E_k = 0\)，\(E_p = E\)（最大）；
  2. 平衡位置处 \(E_k = E\)，\(E_p = 0\)；
  3. 能量在 \(E_k\) 与 \(E_p\) 之间周期性转换。
- **难度**：高考
- **延展**：无特殊延展。

### 2.2 阻尼振动、受迫振动与共振

#### wave-damping（阻尼振动）
- **公式**：\(x(t) = A_0 e^{-\beta t} \cos(\omega t + \varphi)\)（\(\beta\) 为阻尼系数）
- **适用条件**：欠阻尼（弱阻尼）。
- **易错点**：
  1. 阻尼振动频率略小于无阻尼固有频率；
  2. 强阻尼（过阻尼）不振荡，直接趋近平衡；
  3. 临界阻尼是回到平衡最快的非振荡情形。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ RLC 电路中的电磁振荡

#### wave-forced-and-resonance（受迫振动与共振）
- **公式**：稳态振幅 \(A = \dfrac{F_0/m}{\sqrt{(\omega_0^2 - \omega^2)^2 + (2\beta\omega)^2}}\)
  - 共振：驱动力频率 \(\omega\) = 固有频率 \(\omega_0\) 时振幅最大。
- **适用条件**：周期性驱动力。
- **易错点**：
  1. 共振时驱动力频率与固有频率**相同**（不是相差整数倍）；
  2. 共振是能量输入最快的状态，但不一定振幅最大（受阻尼影响）。
- **难度**：高考
- **延展**：
  - 横向 → `em-ac-circuit-resonance`（电磁共振）

### 2.3 机械波

#### wave-mechanical-basics（机械波的产生与传播）
- **公式**：\(v = \lambda f = \lambda / T\)
  - 横波：质点振动方向 ⊥ 波传播方向（如绳波）；
  - 纵波：质点振动方向 ‖ 波传播方向（如声波）。
- **适用条件**：机械波需要介质。
- **易错点**：
  1. 质点只在平衡位置附近振动，不随波迁移；
  2. 波速由介质决定（如声速在空气中 \(340\,\mathrm{m/s}\)）；
  3. 频率由波源决定，与介质无关。
- **难度**：基础
- **延展**：
  - 横向 → `em-em-wave`（电磁波无需介质）

#### wave-transverse-equation（简谐波的波方程）
- **公式**：
  - 沿 \(x\) 正方向传播：\(y(x, t) = A \cos\!\left(\omega t - k x + \varphi\right)\)
  - 沿 \(x\) 负方向传播：\(y(x, t) = A \cos\!\left(\omega t + k x + \varphi\right)\)
  - \(k = 2\pi/\lambda\) 为波数。
- **适用条件**：一维简谐波。
- **易错点**：
  1. 波形沿传播方向「平移」——右行波向前（+x）移；
  2. 质点起振方向由波源决定；
  3. 反射时的半波损失：固定端反射有半波损失，自由端无。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 三维平面波、球面波

#### wave-superposition-and-interference（波的叠加与干涉）
- **公式**：
  - 干涉条件：同频率、振动方向相同、相位差恒定（相干波）；
  - 波程差 \(\Delta r\)：加强条件 \(\Delta r = n\lambda\)，减弱条件 \(\Delta r = (n + 1/2)\lambda\)。
- **适用条件**：两列相干波。
- **易错点**：
  1. 相位差与波程差的关系：\(\Delta\varphi = 2\pi \Delta r / \lambda\)；
  2. 反相波源（如半波损失）需在 \(\Delta r\) 中扣除；
  3. 干涉条纹间距 \(\Delta y = \lambda L / d\)（双缝）。
- **难度**：高考
- **延展**：
  - 横向 → `optics-double-slit-interference`

#### wave-standing（驻波）
- **公式**：\(y(x, t) = 2 A \cos(k x) \cos(\omega t)\)（两列反向传播的等幅波叠加）
  - 节点位置：\(x = (n + 1/2)\lambda/2\)；腹点位置：\(x = n\lambda/2\)
- **适用条件**：两列同频反向传播的波。
- **易错点**：
  1. 驻波不是行波——能量不传输，只在节点与腹点间振荡；
  2. 弦/管振动模式：两端固定 → 节点；两端开放 → 节点；一端开放一端固定 → 半波损失。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 简正模式、弦振动的简正频率

#### wave-doppler（多普勒效应）
- **公式**：观测频率 \(f' = \dfrac{v \pm v_{\text{观}}}{v \mp v_{\text{源}}} f\)
  - \(v\) 为波速；\(v_{\text{观}}\)、\(v_{\text{源}}\) 分别为观测者、源相对介质的速度。
- **适用条件**：波源或观测者相对介质运动。
- **易错点**：
  1. 符号规律：观察者向源运动 → \(+\)；源向观察者运动 → \(-\)（分母）；
  2. 红移/蓝移的本质是频率变化；
  3. 电磁波的多普勒需用相对论修正。
- **难度**：高考
- **延展**：
  - 横向 → `modern-relativity-doppler`（光的多普勒效应）

## 三、电磁学 em

### 3.1 静电场

#### em-coulomb（库仑定律）
- **公式**：\(F = k \dfrac{q_1 q_2}{r^2} = \dfrac{1}{4\pi\varepsilon_0} \dfrac{q_1 q_2}{r^2}\)
  - \(k \approx 9.0 \times 10^9\,\mathrm{N \cdot m²/C²}\)，\(\varepsilon_0 \approx 8.85 \times 10^{-12}\,\mathrm{C²/(N \cdot m²)}\)
- **适用条件**：真空中；点电荷；静止或低速。
- **易错点**：
  1. 同种电荷斥力、异种电荷引力；
  2. 「真空中 \(k\)」与「介质中 \(k/\varepsilon_r\)」区别；
  3. 均匀带电球壳外：\(F\) 等效于电荷集中于球心；球壳内：\(F = 0\)。
- **难度**：基础
- **延展**：无特殊延展。

#### em-electric-field（电场强度）
- **公式**：\(\vec{E} = \vec{F}/q_0\)（定义式）；\(\vec{E} = k \dfrac{Q}{r^2}\hat{r}\)（点电荷）
- **适用条件**：试探电荷 \(q_0\) 不影响场分布。
- **易错点**：
  1. \(\vec{E}\) 是矢量，叠加按平行四边形法则；
  2. 匀强电场：\(E\) 大小方向处处相同（平行板电容器内部）。
- **难度**：基础
- **延展**：
  - 横向 → `em-field-superposition`

#### em-field-lines-and-equipotential（电场线与等势面）
- **公式**：电场线 ⊥ 等势面；沿电场线方向电势降低。
- **适用条件**：任何电场。
- **易错点**：
  1. 电场线不相交、不闭合（始于正电荷/无穷远，止于负电荷/无穷远）；
  2. 电场线密的地方电场强；
  3. 等势面间距小 → 电场强。
- **难度**：高考
- **延展**：无特殊延展。

#### em-potential-and-volt（电势与电势差）
- **公式**：
  - 定义：\(U_P = \dfrac{E_p}{q}\)（单位 V = J/C）
  - 电势差：\(U_{AB} = U_A - U_B = \dfrac{W_{AB}}{q}\)（电场力做的功）
- **适用条件**：静电场。
- **易错点**：
  1. 电势是标量（可正可负，零势点任选）；
  2. 沿电场线方向电势降低；
  3. 电势差与电场力做功关系：\(W_{AB} = q U_{AB}\)（电场力做的功）。
- **难度**：基础
- **延展**：
  - 横向 → `em-capacitor-energy`

#### em-field-superposition（电场叠加原理）
- **公式**：\(\vec{E} = \sum_i \vec{E}_i\)（矢量叠加）
- **适用条件**：多个点电荷或带电体共同产生的电场。
- **易错点**：
  1. 对称性可简化计算（等量异种电荷中垂面、电偶极子等）；
  2. 均匀带电球壳外等效于点电荷（球心处）。
- **难度**：基础
- **延展**：无特殊延展。

#### em-capacitor（电容器）
- **公式**：
  - 电容定义：\(C = Q/U\)
  - 平行板电容器：\(C = \dfrac{\varepsilon_r \varepsilon_0 S}{d}\)
  - 储能：\(E = \tfrac{1}{2} C U^2 = \tfrac{1}{2} Q U = \dfrac{Q^2}{2C}\)
- **适用条件**：电容器。
- **易错点**：
  1. 电容 \(C\) 由电容器本身决定（几何 + 介质），与 \(Q\)、\(U\) 无关；
  2. 串联：\(1/C = \sum 1/C_i\)（电压分配与电容反比）；
  3. 并联：\(C = \sum C_i\)（电荷相加）；
  4. 含介质的电容器，等效介电常数变化。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 圆柱形/球形电容器

### 3.2 恒定电流

#### em-ohm-law（欧姆定律）
- **公式**：
  - 部分电路：\(U = I R\)
  - 闭合电路：\(\varepsilon = U_{\text{端}} + I r\)（\(\varepsilon\) 为电动势，\(r\) 为内阻）
- **适用条件**：金属导体、电解液；不适用半导体/气体。
- **易错点**：
  1. 部分电路欧姆定律只对一段电阻成立（不含电动势）；
  2. 闭合电路欧姆定律中的 \(\varepsilon\) 是电源电动势；
  3. 端电压 \(U_{\text{端}} = \varepsilon - I r\)（电流大时端电压减小）。
- **难度**：基础
- **延展**：
  - 纵向（竞赛）→ 非线性电阻伏安特性

#### em-resistance-series-parallel（电阻串并联）
- **公式**：
  - 串联：\(R = \sum R_i\)，电压分配与电阻成正比；
  - 并联：\(1/R = \sum 1/R_i\)，电流分配与电阻成反比。
- **适用条件**：线性电阻。
- **易错点**：
  1. 并联等效电阻总小于任一支路电阻；
  2. 复杂网络优先用基尔霍夫定律；
  3. 短接一根导线时该电阻为零。
- **难度**：基础
- **延展**：
  - 纵向（强基）→ 桥式电路、电位差计

#### em-power-and-heat（电功、电功率与焦耳定律）
- **公式**：
  - 电功：\(W = U I t = I^2 R t = \dfrac{U^2}{R} t\)
  - 电功率：\(P = U I = I^2 R = U^2/R\)
  - 焦耳热：\(Q = I^2 R t\)（纯电阻电路中 \(W = Q\)）
- **适用条件**：恒定电流。
- **易错点**：
  1. 「\(P = U^2/R\)」和「\(P = I^2 R\)」在 \(U\) 或 \(I\) 固定时使用；
  2. 非纯电阻电路（电动机、电解槽）：\(W > Q\)，多余部分转化为机械能/化学能；
  3. 额定功率 vs 实际功率（电压高时实际功率可能超过额定）。
- **难度**：高考
- **延展**：
  - 横向 → `em-ac-power`（交流电功率因数）

#### em-kirchhoff（基尔霍夫定律）
- **公式**：
  - 节点定律：\(\sum I_{\text{入}} = \sum I_{\text{出}}\)（电荷守恒）
  - 回路定律：\(\sum \varepsilon = \sum I R\)（沿回路绕一圈电压降之和 = 电动势之和）
- **适用条件**：任何直流电路。
- **易错点**：
  1. 选取回路方向，电压降与电流方向一致时取正；
  2. 电动势方向由电源正极指向负极（沿外电路）。
- **难度**：高考
- **延展**：无特殊延展。

### 3.3 磁场

#### em-magnetic-field（磁场与磁感应强度）
- **公式**：\(\vec{B}\)（矢量，单位 T = \mathrm{\mathrm{N/(A·m)}}）
- **适用条件**：永磁体、电流、运动电荷均可产生磁场。
- **易错点**：
  1. 磁感线是闭合曲线（与电场线不同）；
  2. 地磁场方向：地理北极附近为地磁南极（磁场线从地理南极进入地球）。
- **难度**：基础
- **延展**：
  - 横向 → `em-ampere-force`

#### em-ampere-force（安培力）
- **公式**：\(\vec{F} = I \vec{L} \times \vec{B}\)（\(F = B I L \sin\theta\)）
- **适用条件**：电流在磁场中。
- **易错点**：
  1. 方向用左手定则；
  2. 当 \(\vec{I} \parallel \vec{B}\) 时 \(F = 0\)；
  3. 线圈在磁场中的力矩 \(M = N I S B \sin\theta\)（电磁铁原理）。
- **难度**：高考
- **延展**：
  - 横向 → `em-motor`（直流电动机原理）

#### em-lorentz-force（洛伦兹力）
- **公式**：\(\vec{F} = q \vec{v} \times \vec{B}\)（\(F = q v B \sin\theta\)）
- **适用条件**：运动电荷在磁场中。
- **易错点**：
  1. 始终垂直于速度方向（不做功，只改变方向）；
  2. 正电荷 vs 负电荷方向相反（左手/右手定则差异）；
  3. 与电场力的区别：电场力可改变动能，洛伦兹力不能。
- **难度**：高考
- **延展**：
  - 横向 → `em-cyclotron`

#### em-cyclotron（带电粒子在磁场中的圆周运动）
- **公式**：
  - 半径：\(r = \dfrac{m v}{q B}\)
  - 周期：\(T = \dfrac{2\pi m}{q B}\)（与速度无关）
  - 回旋频率：\(f = \dfrac{q B}{2\pi m}\)
- **适用条件**：匀强磁场；速度 ⊥ 磁场。
- **易错点**：
  1. 半径与速度成正比，周期与速度无关；
  2. 当速度有平行分量时做螺旋运动（螺距 \(h = v_\parallel T\)）；
  3. 微观过程动画需放慢时间轴，但空间几何由真实公式驱动。
- **难度**：高考
- **延展**：
  - 横向 → `em-mass-spectrometer`、`em-cyclotron-accelerator`

#### em-mass-spectrometer（质谱仪）
- **公式**：先经速度选择器选 \(v = E/B_1\)，再在磁场中半径 \(r = mv/(qB_2)\)，得 \(m/q = r B_2 / v\)
- **适用条件**：同位素分析。
- **易错点**：电场与磁场方向、电荷正负影响筛选。
- **难度**：高考
- **延展**：无特殊延展。

#### em-cyclotron-accelerator（回旋加速器）
- **公式**：最大动能 \(E_{k\max} = \dfrac{q^2 B^2 R^2}{2m}\)（\(R\) 为 D 形盒半径）
- **适用条件**：非相对论速度范围。
- **易错点**：
  1. 高能区需用同步加速器（相对论修正）；
  2. 交流电频率需等于回旋频率。
- **难度**：高考
- **延展**：
  - 纵向（竞赛）→ 同步辐射、电子感应加速器

### 3.4 电磁感应

#### em-faraday-law（法拉第电磁感应定律）
- **公式**：\(\varepsilon = -\dfrac{\mathrm{d}\Phi}{\mathrm{d}t}\)（\(\Phi = \vec{B} \cdot \vec{S}\) 为磁通量）
- **适用条件**：任何磁通量变化。
- **易错点**：
  1. 负号体现楞次定律（感应电流方向阻碍变化）；
  2. 磁通量变化原因：\(B\) 变化、\(S\) 变化、\(\theta\) 变化；
  3. 导体切割磁感线：\(\varepsilon = B L v \sin\theta\)（与法拉第定律等价）。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 感生电动势与动生电动势的微观解释

#### em-lenz-law（楞次定律）
- **公式**：感应电流的方向总是使其产生的磁场**阻碍**引起它的磁通量变化。
- **适用条件**：电磁感应。
- **易错点**：
  1. 「阻碍」≠「阻止」——磁通量仍变化，只是被「减缓」；
  2. 「来拒去留」「增反减同」等口诀适用条件。
- **难度**：高考
- **延展**：
  - 横向 → `princ-energy-conservation`（楞次定律本质是能量守恒）

#### em-self-inductance（自感）
- **公式**：
  - 自感电动势：\(\varepsilon_L = -L \dfrac{\mathrm{d}I}{\mathrm{d}t}\)
  - 自感磁能：\(E = \tfrac{1}{2} L I^2\)
- **适用条件**：线圈电流变化。
- **易错点**：
  1. 自感系数 \(L\) 由线圈几何决定（匝数、面积、铁芯）；
  2. 自感电动势「阻碍」电流变化——电流增大时反向，电流减小时同向。
- **难度**：高考
- **延展**：无特殊延展。

### 3.5 交变电流

#### em-ac-basics（正弦交流电）
- **公式**：
  - 瞬时值：\(e = E_m \sin(\omega t)\)，\(i = I_m \sin(\omega t)\)，\(u = U_m \sin(\omega t)\)
  - 有效值：\(E = \dfrac{E_m}{\sqrt{2}}\)，\(I = \dfrac{I_m}{\sqrt{2}}\)，\(U = \dfrac{U_m}{\sqrt{2}}\)
- **适用条件**：正弦交变电流。
- **易错点**：
  1. 有效值定义：等效直流热效应的电流值；
  2. 交流电压表/电流表读数为有效值；
  3. 峰值与有效值差 \(\sqrt{2}\) 倍仅对正弦成立。
- **难度**：高考
- **延展**：无特殊延展。

#### em-transformer（变压器）
- **公式**：\(\dfrac{U_1}{U_2} = \dfrac{n_1}{n_2} = \dfrac{I_2}{I_1}\)（理想变压器）
- **适用条件**：理想变压器（无损耗、磁通全部耦合）。
- **易错点**：
  1. 原副线圈功率相等：\(U_1 I_1 = U_2 I_2\)（理想）；
  2. 高压线圈匝数多（升压），电流小；
  3. 实际变压器有铜损、铁损。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 自耦变压器、三相变压器

#### em-ac-circuit-resonance（LC 振荡电路与电磁共振）
- **公式**：
  - 周期：\(T = 2\pi\sqrt{L C}\)
  - 频率：\(f = \dfrac{1}{2\pi\sqrt{L C}}\)
- **适用条件**：LC 振荡电路。
- **易错点**：
  1. 振荡本质：电场能与磁场能相互转换；
  2. 类比弹簧振子。
- **难度**：高考
- **延展**：
  - 横向 → `wave-forced-and-resonance`（共振类比）

### 3.6 电磁波

#### em-em-wave（电磁波的产生与传播）
- **公式**：\(c = \lambda f\)（真空光速 \(c \approx 3.0 \times 10^8\,\mathrm{m/s}\)）
- **适用条件**：电磁波无需介质，可在真空中传播。
- **易错点**：
  1. \(\vec{E}\) 与 \(\vec{B}\) 相互垂直，且都垂直于传播方向；
  2. 电磁波是横波；
  3. 麦克斯韦方程组预言电磁波存在。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 麦克斯韦方程组的微分形式

#### em-em-spectrum（电磁波谱）
- **公式**：从长波到短波：无线电波 → 微波 → 红外线 → 可见光 → 紫外线 → X 射线 → γ 射线
- **适用条件**：全电磁波谱。
- **易错点**：
  1. 波长越短，频率越高，能量越大；
  2. 不同波段产生机理不同（如 X 射线由原子内层电子跃迁）。
- **难度**：高考
- **延展**：
  - 纵向（竞赛）→ 黑体辐射、普朗克公式

## 四、热学 thermo

### 4.1 分子动理论

#### thermo-molecule-basics（分子动理论基本观点）
- **公式**：物体由大量分子组成；分子永不停息做无规则热运动；分子间存在相互作用的引力和斥力。
- **适用条件**：宏观物体。
- **易错点**：
  1. 分子直径数量级 \(\sim 10^{-10}\,\mathrm{m}\)；
  2. 分子间距与物质状态（固液气）有关。
- **难度**：基础
- **延展**：无特殊延展。

#### thermo-brownian-motion（布朗运动）
- **公式**：悬浮微粒的无规则运动，反映液体分子的无规则运动。
- **适用条件**：液体中悬浮微粒足够小（直径 \(\le 10^{-6}\,\mathrm{m}\)）。
- **易错点**：
  1. 布朗运动不是分子运动，是分子撞击微粒的结果；
  2. 温度越高，布朗运动越剧烈。
- **难度**：基础
- **延展**：
  - 横向 → `princ-statistical-method`（统计规律）

#### thermo-temperature-and-ke（温度与分子平均动能）
- **公式**：温度 \(T\) 是分子平均动能的标志：\(\bar{E}_k = \dfrac{3}{2} k_B T\)（\(k_B \approx 1.38 \times 10^{-23}\,\mathrm{J/K}\)）
- **适用条件**：理想气体。
- **易错点**：
  1. 温度是宏观量，反映大量分子无规则运动的剧烈程度；
  2. 单个分子无「温度」可言（统计量）。
- **难度**：基础
- **延展**：
  - 纵向（强基）→ 麦克斯韦速度分布律

#### thermo-molecule-interaction（分子间作用力与势能）
- **公式**：分子间同时存在引力与斥力；合力 = 引力 + 斥力
  - 引力随距离增大而减小；斥力减小更快。
- **适用条件**：分子间距约 \(r_0 \approx 10^{-10}\,\mathrm{m}\)（平衡位置）。
- **易错点**：
  1. \(r < r_0\)：斥力 > 引力，合力为斥力；
  2. \(r > r_0\)：引力 > 斥力，合力为引力；
  3. \(r \gg r_0\)：作用力可忽略。
- **难度**：基础
- **延展**：无特殊延展。

### 4.2 气体

#### thermo-ideal-gas（理想气体状态方程）
- **公式**：\(p V = n R T\)（\(n\) 为摩尔数，\(R \approx 8.31\,\mathrm{J/(mol \cdot K)}\)）
  - 等价形式：\(\dfrac{p_1 V_1}{T_1} = \dfrac{p_2 V_2}{T_2}\)
- **适用条件**：理想气体（高温低压近似）。
- **易错点**：
  1. 温度必须用绝对温度（K），不是摄氏度；
  2. 压强单位须统一（如 Pa、atm 互换：1 atm = 1.013×10⁵ Pa）；
  3. 实际气体在临界点附近误差大。
- **难度**：基础
- **延展**：
  - 纵向（强基）→ 范德瓦尔斯方程（实际气体）

#### thermo-gas-laws（气体实验定律）
- **公式**：
  - 玻意耳定律（等温）：\(p_1 V_1 = p_2 V_2\)
  - 查理定律（等容）：\(\dfrac{p_1}{T_1} = \dfrac{p_2}{T_2}\)
  - 盖-吕萨克定律（等压）：\(\dfrac{V_1}{T_1} = \dfrac{V_2}{T_2}\)
- **适用条件**：理想气体；气体质量不变。
- **易错点**：
  1. 三定律都要求**气体质量不变**；
  2. 温度必须用绝对温标。
- **难度**：基础
- **延展**：
  - 横向 → `thermo-ideal-gas`

### 4.3 固体、液体与相变

#### thermo-solid-crystal（晶体与非晶体）
- **公式**：晶体有固定熔点（如金属、食盐）；非晶体无（如玻璃、沥青）。
- **适用条件**：固体分类。
- **易错点**：
  1. 单晶体 vs 多晶体：多晶体无规则外形但有熔点；
  2. 非晶体不稳定，会自发向晶体转化（玻璃的老化）。
- **难度**：基础
- **延展**：
  - 纵向（强基）→ 晶体结构（布拉菲格子）

#### thermo-liquid-surface（液体表面张力）
- **公式**：\(F = \sigma L\)（\(\sigma\) 为表面张力系数，\(L\) 为边界长度）
- **适用条件**：液体表面层。
- **易错点**：
  1. 表面张力方向沿液面切线，使液面收缩；
  2. 浸润与不浸润取决于分子间作用力。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 毛细现象、表面活性剂

#### thermo-phase-change（相变：熔化、汽化、升华）
- **公式**：
  - 熔化热 \(\lambda\)：\(Q = \lambda m\)
  - 汽化热 \(L\)：\(Q = L m\)
  - 潜热：温度不变时吸收/放出的热量。
- **适用条件**：相变过程。
- **易错点**：
  1. 相变过程中温度保持不变；
  2. 同种物质不同压强下熔点/沸点不同。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 三相图（水的相图）

### 4.4 热力学定律

#### thermo-internal-energy（内能）
- **公式**：内能 \(U\) = 所有分子动能 + 所有分子势能
  - 理想气体内能 = 分子动能之和（与体积无关，只与温度有关）：\(U = n C_V T\)
- **适用条件**：宏观物体。
- **易错点**：
  1. 内能是状态量（只与状态有关，与过程无关）；
  2. 理想气体内能只与温度有关（因为无分子势能）；
  3. 改变内能的两种方式：做功、热传递。
- **难度**：基础
- **延展**：
  - 横向 → `thermo-first-law`

#### thermo-first-law（热力学第一定律）
- **公式**：\(\Delta U = Q + W\)（外界对系统做功为正，吸热为正）
  - 等价形式：\(Q = \Delta U - W\)（外界对系统做功 \(W\)；或 \(Q = \Delta U + W'\)（系统对外做功 \(W'\)））
- **适用条件**：任何热力学过程。
- **易错点**：
  1. 符号约定：吸热 \(Q > 0\)，系统对外做功 \(W' > 0\)，外界对系统做功 \(W > 0\)；
  2. 等压过程：\(W' = p \Delta V\)（气体推动活塞做的功）；
  3. 等容过程：\(W = 0\)，\(Q = \Delta U\)。
- **难度**：高考
- **延展**：
  - 横向 → `princ-energy-conservation`

#### thermo-isothermal-process（等温过程）
- **公式**：\(\Delta U = 0\)，\(Q = W'\)（理想气体等温膨胀）
  - 理想气体等温过程：\(W' = n R T \ln(V_2/V_1)\)
- **适用条件**：理想气体；温度不变。
- **易错点**：
  1. 气体吸热等于对外做功；
  2. 等温压缩时外界对气体做功，全部转化为放出的热量。
- **难度**：高考
- **延展**：
  - 横向 → `thermo-carnot-cycle`

#### thermo-carnot-cycle（卡诺循环与热机效率）
- **公式**：\(\eta = 1 - \dfrac{T_2}{T_1}\)（卡诺热机效率，\(T_1\) 为高温热源温度，\(T_2\) 为低温热源温度）
- **适用条件**：理想可逆热机。
- **易错点**：
  1. 卡诺效率是**给定温度下热机效率的上限**；
  2. 实际热机效率 \(\eta < 1 - T_2/T_1\)；
  3. 制冷系数 \(\varepsilon = \dfrac{T_2}{T_1 - T_2}\)（卡诺制冷机）。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 熵、热力学第二定律的统计解释

#### thermo-second-law（热力学第二定律）
- **公式**：开尔文表述：不可能从单一热源吸热全部转化为功而不引起其它变化。
  - 克劳修斯表述：热量不能自动从低温物体传向高温物体。
- **适用条件**：宏观自然过程。
- **易错点**：
  1. 两种表述等价；
  2. 第二定律的微观本质：孤立系统的熵总在增加（\(S\) 不减）。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 玻尔兹曼熵公式 \(S = k_B \ln \Omega\)

## 五、光学 optics

### 5.1 几何光学

#### optics-reflection（反射定律）
- **公式**：入射角 = 反射角（\(\theta_i = \theta_r\)）；入射光线、反射光线、法线共面。
- **适用条件**：光滑反射面。
- **易错点**：
  1. 平面镜成像：像距 = 物距（虚像，与物对称于镜面）；
  2. 球面镜（凹/凸）：\(\dfrac{1}{u} + \dfrac{1}{v} = \dfrac{2}{R}\)（凹面镜 \(R > 0\)，凸面镜 \(R < 0\)）。
- **难度**：基础
- **延展**：
  - 横向 → `optics-refraction`

#### optics-refraction（折射定律：斯涅尔定律）
- **公式**：\(n_1 \sin\theta_1 = n_2 \sin\theta_2\)
  - \(n = c/v\)（绝对折射率）；相对折射率 \(n_{21} = n_2/n_1\)
- **适用条件**：两透明介质界面；光从一种介质进入另一种。
- **易错点**：
  1. 光从光疏介质射入光密介质时折射角小于入射角；
  2. 折射时光线可逆（光路可逆原理）；
  3. 介质色散：不同波长折射率不同（紫光折射率 > 红光）。
- **难度**：基础
- **延展**：
  - 横向 → `optics-total-internal-reflection`

#### optics-total-internal-reflection（全反射）
- **公式**：临界角 \(\sin\theta_c = \dfrac{n_2}{n_1}\)（\(n_1 > n_2\)）
- **适用条件**：光从光密介质射向光疏介质；入射角 \(\ge \theta_c\)。
- **易错点**：
  1. 全反射时反射率 100%（无折射）；
  2. 应用：光纤、海市蜃楼、钻石闪光。
- **难度**：高考
- **延展**：
  - 纵向（竞赛）→ 倏逝波、光纤色散

#### optics-prism-dispersion（棱镜色散）
- **公式**：偏向角 \(\delta = \theta_1 + \theta_2' - A\)（\(A\) 为棱镜顶角）
- **适用条件**：三棱镜。
- **易错点**：
  1. 紫光偏向角最大（折射率最大）；
  2. 最小偏向角对应光线对称通过棱镜。
- **难度**：高考
- **延展**：
  - 纵向（竞赛）→ 棱镜光谱仪、光栅光谱

#### optics-thin-lens（薄透镜成像）
- **公式**：\(\dfrac{1}{u} + \dfrac{1}{v} = \dfrac{1}{f}\)（\(u\) 物距，\(v\) 像距，\(f\) 焦距）
  - 放大率 \(m = \dfrac{|v|}{u}\)（像高 / 物高）
- **适用条件**：薄透镜；近轴光线。
- **易错点**：
  1. 凸透镜 \(f > 0\)，凹透镜 \(f < 0\)；
  2. 实像 \(v > 0\)，虚像 \(v < 0\)；
  3. 物体在一倍焦距内成正立放大虚像（放大镜）。
- **难度**：高考
- **延展**：
  - 横向 → `optics-microscope`、`optics-telescope`

#### optics-microscope（显微镜）
- **公式**：放大率 \(M = M_o \cdot M_e = \dfrac{L}{f_o} \cdot \dfrac{d}{f_e}\)（\(L\) 为镜筒，\(f_o\) 物镜焦距，\(f_e\) 目镜焦距，\(d\) 明视距离）
- **适用条件**：复合显微镜。
- **易错点**：
  1. 物镜成倒立放大实像，目镜成正立放大虚像；
  2. 物镜焦距短、目镜焦距长 → 总放大率大。
- **难度**：高考
- **延展**：
  - 横向 → `optics-telescope`

#### optics-telescope（望远镜）
- **公式**：放大率 \(M = \dfrac{f_o}{f_e}\)（开普勒/伽利略望远镜）
- **适用条件**：天体观测；远物（\(u \to \infty\)）。
- **易错点**：
  1. 开普勒望远镜（两凸透镜）：成倒立实像；
  2. 伽利略望远镜（凸 + 凹）：成正立虚像；
  3. 增大 \(f_o\)、减小 \(f_e\) 提高放大率。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 反射望远镜、像差校正

### 5.2 物理光学

#### optics-double-slit-interference（双缝干涉）
- **公式**：
  - 明纹条件：\(\Delta r = n\lambda\)（\(n = 0, \pm 1, \pm 2, ...\)）
  - 暗纹条件：\(\Delta r = (n + 1/2)\lambda\)
  - 条纹间距：\(\Delta y = \dfrac{L}{d} \lambda\)（\(L\) 双缝到屏距离，\(d\) 双缝间距）
- **适用条件**：相干光（单色光）。
- **易错点**：
  1. 「明纹」「暗纹」条件互换不要记反；
  2. 波长变短（如蓝光）→ 条纹变密；
  3. 双缝间距变小 → 条纹变疏。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 薄膜干涉（等厚/等倾）

#### optics-thin-film-interference（薄膜干涉）
- **公式**：光程差 \(\Delta = 2 n d + \lambda/2\)（考虑半波损失时）
- **适用条件**：薄膜前后表面反射光干涉。
- **易错点**：
  1. 半波损失：光从光疏介质射向光密介质反射时有 \(\lambda/2\) 附加光程差；
  2. 等厚干涉：劈尖、牛顿环。
- **难度**：高考
- **延展**：
  - 横向 → `optics-double-slit-interference`

#### optics-single-slit-diffraction（单缝衍射）
- **公式**：
  - 中央亮纹：宽 \(\Delta y = 2 L \lambda / a\)（\(a\) 为缝宽）
  - 暗纹条件：\(a \sin\theta = k\lambda\)（\(k = \pm 1, \pm 2, ...\)）
- **适用条件**：缝宽与波长可比。
- **易错点**：
  1. 单缝越窄 → 中央亮纹越宽；
  2. 衍射与干涉的区别：衍射是同一波面上的子波叠加，干涉是不同波列的叠加。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 光栅衍射、光栅方程 \(d \sin\theta = k\lambda\)

#### optics-polarization（光的偏振）
- **公式**：自然光通过偏振片后光强减半：\(I = I_0 / 2\)
  - 马吕斯定律：\(I = I_0 \cos^2\alpha\)
- **适用条件**：偏振片。
- **易错点**：
  1. 自然光 vs 部分偏振光 vs 完全偏振光；
  2. 偏振是横波的特性（纵波无偏振）。
- **难度**：高考
- **延展**：
  - 纵向（竞赛）→ 布儒斯特角、双折射

## 六、近代物理 modern

### 6.1 波粒二象性

#### modern-photoelectric（光电效应）
- **公式**（爱因斯坦方程）：\(h\nu = W_0 + E_{k\max}\)
  - \(E_{k\max} = h\nu - W_0\)，遏止电压 \(U_c = E_{k\max}/e\)
- **适用条件**：金属表面；入射光频率 \(\nu > \nu_0\)（红限频率）。
- **易错点**：
  1. 光强只影响光电子数（饱和电流），不影响最大初动能；
  2. 红限频率 \(\nu_0 = W_0/h\) 只与金属材料有关；
  3. 光电效应瞬时性（\(\sim 10^{-9}\,\mathrm{s}\)）。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 康普顿散射（光子的粒子性）

#### modern-compton（康普顿散射）
- **公式**：\(\Delta \lambda = \lambda' - \lambda = \dfrac{h}{m_e c}(1 - \cos\theta)\)
- **适用条件**：X 射线与自由电子碰撞。
- **易错点**：
  1. 康普顿波长 \(\lambda_C = h/(m_e c) \approx 2.43 \times 10^{-12}\,\mathrm{m}\)；
  2. 散射角 \(\theta\) 越大，波长变化越大。
- **难度**：高考
- **延展**：
  - 横向 → `modern-de-broglie`

#### modern-de-broglie（德布罗意波）
- **公式**：\(\lambda = \dfrac{h}{p} = \dfrac{h}{m v}\)（实物粒子也有波动性）
- **适用条件**：任何运动粒子。
- **易错点**：
  1. 速度越大，波长越短；
  2. 宏观物体德布罗意波长极短（无可观测波动性）。
- **难度**：高考
- **延展**：
  - 横向 → `modern-uncertainty`（不确定性关系）

#### modern-uncertainty（不确定性关系）
- **公式**：\(\Delta x \cdot \Delta p \ge \dfrac{h}{4\pi}\)（或 \(\hbar/2\)）
- **适用条件**：微观粒子。
- **易错点**：
  1. 「不确定性」不是测量误差，是粒子固有属性；
  2. 宏观物体 \(\Delta x \Delta p\) 远大于 \(h\) → 经典物理可适用。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 能量-时间不确定性 \(\Delta E \Delta t \ge h/(4\pi)\)

### 6.2 原子结构

#### modern-rutherford（α 粒子散射实验与卢瑟福核式模型）
- **公式**：α 粒子散射轨迹分析 → 原子核占原子体积的极小部分，但集中几乎全部质量。
- **适用条件**：原子结构。
- **易错点**：
  1. 「汤姆孙枣糕模型」被 α 散射实验否定；
  2. 原子序数 = 核电荷数。
- **难度**：高考
- **延展**：
  - 横向 → `modern-bohr-model`

#### modern-bohr-model（玻尔氢原子模型）
- **公式**：
  - 量子化条件：\(m v r = n\hbar\)（角动量量子化）
  - 轨道半径：\(r_n = n^2 a_0\)（\(a_0 \approx 0.529 \times 10^{-10}\,\mathrm{m}\)）
  - 能级：\(E_n = -\dfrac{13.6\,\mathrm{eV}}{n^2}\)
  - 跃迁发射光子：\(h\nu = E_m - E_n\)（\(m > n\)）
- **适用条件**：氢原子。
- **易错点**：
  1. 玻尔模型成功解释了氢原子光谱，但对多电子原子失败；
  2. 「能级跃迁」吸收/发射光子能量 = 能级差；
  3. 量子化条件是人为假设（玻尔模型局限）。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 量子力学薛定谔方程

#### modern-spectra（原子光谱与激光原理）
- **公式**：\(\nu = \dfrac{E_m - E_n}{h}\)（跃迁频率）
- **适用条件**：原子光谱（线状谱）。
- **易错点**：
  1. 连续谱（白光）vs 线状谱（原子/离子气体）；
  2. 激光三要素：受激辐射、谐振腔、粒子数反转。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 受激辐射的爱因斯坦系数

### 6.3 原子核

#### modern-nucleus-composition（原子核的组成）
- **公式**：原子核 = \(Z\) 个质子 + \(N\) 个中子；质量数 \(A = Z + N\)；同位素：\(Z\) 相同 \(N\) 不同。
- **适用条件**：原子核。
- **易错点**：
  1. 质子数 = 核电荷数 = 原子序数；
  2. 中子不带电（区别于质子）。
- **难度**：基础
- **延展**：无特殊延展。

#### modern-binding-energy（结合能与质量亏损）
- **公式**：
  - 质量亏损：\(\Delta m = Z m_p + N m_n - m_{\text{核}}\)
  - 结合能：\(\Delta E = \Delta m c^2\)
  - 平均结合能：\(\bar{E} = \Delta E / A\)（越大越稳定）
- **适用条件**：原子核。
- **易错点**：
  1. 质量数中等的核（\(A \approx 56\)，铁）平均结合能最大，最稳定；
  2. 重核裂变与轻核聚变都向中等核方向变化（释放能量）。
- **难度**：高考
- **延展**：
  - 纵向（竞赛）→ 液滴模型、半经验质量公式

#### modern-radioactive-decay（放射性衰变）
- **公式**：
  - α 衰变：\({}^A_Z X \to {}^{A-4}_{Z-2} Y + {}^4_2 \text{He}\)（穿透弱，电离强）
  - β 衰变：\({}^A_Z X \to {}^A_{Z+1} Y + e^- + \bar{\nu}_e\)（穿透中等）
  - γ 衰变：激发态核释放光子（穿透最强，电离最弱）
- **适用条件**：不稳定核素。
- **易错点**：
  1. 衰变方程配平：质量数、电荷数守恒；
  2. γ 衰变不改变质量数和电荷数；
  3. β 衰变有中微子（中学一般不写）。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 弱相互作用、宇称不守恒

#### modern-half-life（半衰期）
- **公式**：\(N(t) = N_0 (1/2)^{t/T_{1/2}}\)，\(T_{1/2}\) 为半衰期
- **适用条件**：单一衰变类型。
- **易错点**：
  1. 半衰期是统计概念（对单个原子无意义，对大量原子才有意义）；
  2. 半衰期与外部条件（温度、压强、化学状态）无关；
  3. 多个独立核素的混合系统，半衰期需用各自衰变常数加权。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 指数衰减方程 \(N = N_0 e^{-\lambda t}\)

#### modern-fission-and-fusion（核裂变与核聚变）
- **公式**：
  - 裂变：重核（如 \({}^{235}\text{U}\)）被中子击中分裂为中等核 + 中子 + 能量；
  - 聚变：轻核（如 \({}^{2}\text{H} + {}^{3}\text{H}\)）结合成较重核 + 能量。
- **适用条件**：裂变——重核；聚变——轻核（需高温高压）。
- **易错点**：
  1. 链式反应需要中子增殖系数 \(k \ge 1\)；
  2. 聚变在恒星内部自然发生（如太阳氢聚变）；
  3. 聚变能量密度远大于裂变（约 4 倍以上）。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 托卡马克装置、惯性约束聚变

### 6.4 相对论拓展

#### modern-relativity-postulates（狭义相对论基本假设）
- **公式**：
  - 相对性原理：物理定律在所有惯性系中形式相同；
  - 光速不变原理：真空中光速 \(c\) 对所有惯性系相同。
- **适用条件**：惯性系。
- **易错点**：
  1. 「光速不变」与伽利略变换矛盾；
  2. 狭义相对论否定了绝对时空。
- **难度**：高考（仅基本概念）
- **延展**：
  - 横向 → `modern-relativity-time-dilation`

#### modern-relativity-time-dilation（时间膨胀与长度收缩）
- **公式**：
  - 时间膨胀：\(\Delta t' = \dfrac{\Delta t}{\sqrt{1 - v^2/c^2}}\)
  - 长度收缩：\(L' = L \sqrt{1 - v^2/c^2}\)
- **适用条件**：物体高速运动（接近光速）。
- **易错点**：
  1. 运动时钟变慢（相对论效应）；
  2. 运动尺子变短（沿运动方向）；
  3. 都是相对的：观测者与被观测物体的速度关系。
- **难度**：高考（仅概念）
- **延展**：
  - 纵向（强基）→ 洛伦兹变换、闵可夫斯基时空

#### modern-relativity-mass-energy（质能方程）
- **公式**：\(E = m c^2\)
- **适用条件**：任何物体。
- **易错点**：
  1. 质量是能量的量度，不是物质的量；
  2. 质量亏损释放能量（核反应基础）；
  3. 相对论动量 \(\vec{p} = \gamma m \vec{v}\)（\(\gamma = 1/\sqrt{1-v^2/c^2}\)）。
- **难度**：高考
- **延展**：
  - 横向 → `modern-binding-energy`

## 七、物理基本原理与方法 princ

### 7.1 量纲分析

#### princ-dimensional-analysis（量纲分析）
- **公式**：物理量由基本量纲 \([M], [L], [T], [I], [\theta], [N], [J]\) 等幂次构成。
- **适用条件**：任何物理公式。
- **易错点**：
  1. 量纲一致是公式正确的必要条件（不充分）；
  2. 常用导出量纲：力 \([MLT^{-2}]\)、能量 \([ML^2T^{-2}]\)、功率 \([ML^2T^{-3}]\)；
  3. 量纲分析可预言公式形式（特别是竞赛题）。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 自然单位制、高维物理

### 7.2 矢量与坐标

#### princ-vector-basics（矢量基础）
- **公式**：
  - 矢量加法：平行四边形法则
  - 矢量分解：\(\vec{A} = A_x \hat{i} + A_y \hat{j} + A_z \hat{k}\)
  - 点积：\(\vec{A} \cdot \vec{B} = A B \cos\theta\)
  - 叉积：\(\vec{A} \times \vec{B}\) 方向右手定则
- **适用条件**：任何矢量运算。
- **易错点**：
  1. 矢量与标量的区别；
  2. 矢量方程必须按坐标轴分解为标量方程；
  3. 物理量符号的箭头（矢量） vs 黑体。
- **难度**：基础
- **延展**：无特殊延展。

#### princ-vector-moment（力矩与角动量）
- **公式**：
  - 力矩：\(\vec{M} = \vec{r} \times \vec{F}\)（方向右手定则）
  - 角动量：\(\vec{L} = \vec{r} \times m\vec{v}\)
- **适用条件**：刚体力学。
- **易错点**：
  1. 力矩方向按右手定则确定（垂直于 \(\vec{r}\) 和 \(\vec{F}\) 平面）；
  2. 角动量守恒条件：合外力矩为零。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 刚体定轴转动、转动惯量

#### princ-relative-motion（相对运动）
- **公式**：\(\vec{v}_{AB} = \vec{v}_A - \vec{v}_B\)（A 相对 B 的速度）
  - 加速度类比：\(\vec{a}_{AB} = \vec{a}_A - \vec{a}_B\)
- **适用条件**：任何参考系。
- **易错点**：
  1. 「相对运动」的速度/加速度都要先确定参考系；
  2. 船过河、风中旗等问题用矢量合成。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 伽利略变换（低速）

### 7.3 误差与有效数字

#### princ-error-and-significant（误差与有效数字）
- **公式**：
  - 系统误差：测量方法/仪器本身的问题（重复测量不变）；
  - 随机误差：测量中的偶然因素（多次测量平均减小）；
  - 有效数字：从第一个非零数字开始到末位不确定数字止。
- **适用条件**：实验数据处理。
- **易错点**：
  1. 有效数字位数反映测量精度（不可任意增删）；
  2. 乘除法的有效数字位数 = 各因子中位数最少的；
  3. 加减法的末位对齐。
- **难度**：高考
- **延展**：无特殊延展。

### 7.4 单位制

#### princ-units（国际单位制 SI）
- **公式**：基本单位：m（长度）、kg（质量）、s（时间）、A（电流）、K（温度）、mol（物质的量）、cd（发光强度）。
- **适用条件**：所有物理计算。
- **易错点**：
  1. 计算前必须统一为 SI；
  2. 导出单位（如 N、J、W、Pa）有专门符号，不要混淆。
- **难度**：基础
- **延展**：
  - 纵向（强基）→ 高斯单位制、自然单位制

### 7.5 守恒思想

#### princ-energy-conservation（能量守恒定律）
- **公式**：孤立系统的总能量不变：\(\sum E = \text{const}\)
- **适用条件**：孤立系统。
- **易错点**：
  1. 能量形式可以转换（机械能 ↔ 内能 ↔ 电能 ↔ 核能），但总和不变；
  2. 「孤立系统」= 不与外界交换能量。
- **难度**：基础
- **延展**：
  - 横向 → `mech-energy-conservation-mechanical`、`thermo-first-law`

#### princ-momentum-conservation（动量守恒定律）
- **公式**：\(\sum m_i \vec{v}_i = \text{const}\)（合外力为零）
- **适用条件**：孤立系统或某方向合外力为零。
- **易错点**：（见 `mech-momentum-conservation`）
- **难度**：基础
- **延展**：无特殊延展。

### 7.6 建模与近似

#### princ-modeling-idealization（理想化模型）
- **公式**：常见模型：质点、刚体、轻绳、轻弹簧、轻杆、理想气体、点电荷、光滑面等。
- **适用条件**：建立物理模型时。
- **易错点**：
  1. 模型选择决定了解题范围（不可随意跨模型）；
  2. 同一问题可能用不同模型，结果差异反映物理考量。
- **难度**：基础
- **延展**：无特殊延展。

#### princ-graphical-analysis（图解法）
- **公式**：
  - 物理图像：x-t、v-t、a-t、F-x、p-V、I-t 等
  - 斜率 = 变化率（导数）；面积 = 累积量（积分）
- **适用条件**：物理图像题。
- **易错点**：
  1. 区分「图像的物理意义」（如 v-t 图斜率 = a）与「图像本身的数学性质」；
  2. 图像交点的物理意义（往往表示两状态相等）；
  3. 围成面积的正负由方向决定。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 相图、矢量图

### 7.7 微积分基础

#### princ-calculus-basics（微积分在物理中的应用）
- **公式**：
  - 速度 = 位移的导数：\(v = \dfrac{\mathrm{d}x}{\mathrm{d}t}\)
  - 加速度 = 速度的导数：\(a = \dfrac{\mathrm{d}v}{\mathrm{d}t}\)
  - 位移 = 速度的积分：\(\Delta x = \int v\, \mathrm{d}t\)
  - 变力做功 = 力的积分：\(W = \int F\, \mathrm{d}x\)
- **适用条件**：变加速运动、变力做功等。
- **易错点**：
  1. 积分上下限必须明确（起始到终止状态）；
  2. 物理量积分与微分的方向（沿路径方向 vs 沿坐标轴）；
  3. 矢量积分要按坐标分解。
- **难度**：高考（仅基础概念）
- **延展**：
  - 纵向（强基）→ 矢量分析、场论基础

#### princ-statistical-method（统计方法）
- **公式**：
  - 平均值：\(\bar{x} = \dfrac{1}{N}\sum x_i\)
  - 标准差：\(\sigma = \sqrt{\dfrac{1}{N}\sum(x_i - \bar{x})^2}\)
  - 麦克斯韦速度分布：\(f(v) = 4\pi\left(\dfrac{m}{2\pi k_B T}\right)^{3/2} v^2 e^{-mv^2/(2k_B T)}\)
- **适用条件**：处理大量微观粒子的统计量。
- **易错点**：
  1. 统计规律只在大量样本下才有意义；
  2. 宏观量是相应微观量的统计平均。
- **难度**：高考
- **延展**：
  - 纵向（强基）→ 玻尔兹曼分布、量子统计
