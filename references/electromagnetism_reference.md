## 2. 核心公式速查（均用国际单位制 SI）

### 2.1 静电场
- 库仑定律：`F = k \dfrac{q_1 q_2}{r^2}`，`k = \dfrac{1}{4\pi\varepsilon_0} \approx 9.0\times10^9\,\mathrm{N\cdot m^2/C^2}`
- 电场强度（定义）：`\vec{E} = \dfrac{\vec{F}}{q}`；点电荷：`E = k\dfrac{|q|}{r^2}`，方向沿径向
- 匀强电场：`E = \dfrac{U}{d}`
- 电势（点电荷）：`\varphi = k\dfrac{q}{r}`；电势差：`U_{AB} = \varphi_A - \varphi_B = \dfrac{W_{AB}}{q}`
- 电场力做功与电势能：`W_{AB} = q U_{AB} = -\Delta E_p`，`E_p = q\varphi`

### 2.2 电容器
- 电容定义：`C = \dfrac{Q}{U}`（C 由电容器本身决定，与 Q、U 无关）
- 平行板电容：`C = \dfrac{\varepsilon_0 \varepsilon_r S}{d}`
- 储能：`W = \dfrac{1}{2} C U^2 = \dfrac{Q^2}{2C} = \dfrac{1}{2} Q U`

### 2.3 恒定电流
- 电流：`I = \dfrac{Q}{t}`
- 欧姆定律：`I = \dfrac{U}{R}`
- 电阻定律：`R = \rho \dfrac{L}{S}`
- 电功率：`P = U I = I^2 R = \dfrac{U^2}{R}`
- 焦耳热：`Q = I^2 R t`
- 闭合电路欧姆定律：`I = \dfrac{E}{R + r}`，路端电压 `U = E - I r`，输出功率 `P_\text{出} = I U`
- **单位符号规范（强制）**：电阻单位写字面 `Ω`（**禁止** `\Omega` 命令、禁止 `Ohm`/`ohm` 单词）；面积/体积写 `m²`/`m³`（**禁止** `m^2`/`m^3` 这类代码式写法）。见 `figures_redraw_spec.md` §0.2 与 SKILL.md 第 7 条。

### 2.4 磁场
- 磁感应强度（安培定义）：`B = \dfrac{F}{I L}`（垂直时）
- 安培力：`F = B I L \sin\theta`
- 洛伦兹力：`F = q v B \sin\theta`，方向由左手定则
- 带电粒子垂直入匀强磁场做圆周运动：
  `r = \dfrac{m v}{q B}`，`T = \dfrac{2\pi m}{q B}`，`\omega = \dfrac{q B}{m}`

### 2.5 电磁感应
- 法拉第定律：`\mathcal{E} = -N \dfrac{\Delta \Phi}{\Delta t}`（单匝 `N=1`）
- 磁通量：`\Phi = B S \cos\theta`
- 动生电动势：`\mathcal{E} = B L v`（导体垂直切割磁感线）
- 自感：`\mathcal{E} = -L \dfrac{\Delta I}{\Delta t}`，储能 `W = \dfrac{1}{2} L I^2`
- 楞次定律：感应电流方向总是阻碍引起它的磁通量变化

### 2.6 交变电流（选）
- 瞬时值：`e = E_m \sin(\omega t)`，有效值 `E = \frac{E_m}{\sqrt{2}}`（正弦）
- 感抗/容抗（选）：`X_L = \omega L`，`X_C = \frac{1}{\omega C}`

## 3. 符号与坐标约定（强制统一）

1. 电荷量 `q`：正电荷为正、负电荷带负号参与运算。
2. 电场方向：规定为正电荷受力方向；电场线起于正电荷、止于负电荷。
3. 电势零点：通常取无穷远或大地为零势点，并在解析中说明。
4. 磁场方向：由磁感线切线方向表示；安培力/洛伦兹力方向用**左手定则**判定（注意四指、掌心、大拇指的对应关系）。
5. 磁通量 `\Phi`：取面法线方向与 `B` 的夹角 `\theta`，`\Phi = B S \cos\theta`；正负由法线方向约定决定。
6. 闭合电路中 `E` 为电动势、`r` 为内阻、`U` 为路端电压，三者关系 `E = U + I r`。

## 4. 易错点清单（生成解析时逐项排查）

- [ ] 库仑定律仅适用于**点电荷**；非点电荷需积分或等效处理。
- [ ] 电场强度 `E = F/q` 与试探电荷 `q` 无关，是电场本身属性。
- [ ] 电容 `C = Q/U` 是定义式，`C` 不由 `Q、U` 决定（平行板由 `\varepsilon_0\varepsilon_r S/d` 决定）。
- [ ] 混淆电动势 `E` 与路端电压 `U`；闭合电路中 `U = E - I r`。
- [ ] 安培力/洛伦兹力方向用错手（定则）；`\sin\theta` 漏写导致数量级错误。
- [ ] 带电粒子在磁场中圆周运动：半径 `r = mv/(qB)`、周期与速度无关 `T = 2\pi m/(qB)`。
- [ ] 感应电动势方向判错（楞次定律：阻碍变化，而非阻碍磁场）。
- [ ] 磁通量变化才产生感应电动势，磁通量本身大但不变不产生电动势。
- [ ] 单位未统一为 SI（如 `μC` 未换算为 `C`、`cm` 未换算为 `m`）。

## 5. 解析正确性自检清单（每题必做，不可跳过）

1. **物理依据**：每一步推导标注所用定律/公式名称（如「由法拉第电磁感应定律」）。
2. **量纲一致**：等式两边量纲相同（力 N、场强 N/C、电容 F、磁通量 Wb）。
3. **符号约定**：电荷正负、电势零点、磁场方向、磁通量法线方向全程一致。
4. **定律适用条件**：明确写出该定律为何适用（如「点电荷、真空」、「匀强磁场且 v⊥B」）。
5. **极限/特殊情形**：代入极端值是否合理（如 `r→0` 库仑力发散、`B→0` 半径发散）。
6. **数值合理性**：结果数量级符合常识（人体触电电流 mA 级、平行板电容 pF~μF 级）。
7. **结论闭环**：最终答案回到题目所问（求场强/电势/电流/半径/电动势），单位与有效数字规范。

若任一项无法满足且无法当场核实，必须在解析中以醒目方式标注「⚠️ 该步骤待核实」。

### 通用强制条款（公式符号 · 与 mechanics_reference.md §7 / SKILL.md 同源）

> 以下四类写法适用于 `given` / `note` / `basis` / `readouts` 名称 / `tex` / 每问结论式 **所有字段**，不限于 `tex`：

- **单位（强制正体 upright）**：物理量单位必须正体、**禁止斜体**。两种合规写法：① **首选——单位作为纯文本写在公式环境外**（天然正体、源码干净），如 `$m_A=0.4$ kg`、`$v_0=2$ m/s`；② **单位必须嵌在数学式内时**（分式、复合量等无法外提），用 `\mathrm{}` 强制正体，如 `1.2\,\mathrm{m/s}`、`0.20\,\mathrm{m}`、`a=9.8\,\mathrm{m/s²}`。禁止把单位裸写在公式环境内却不包裹（如 `m/s`、`kg` 直接放进 `$...$` 会渲染成斜体，正是「单位用了斜体」的根因）；禁止嵌套 `\mathrm{\mathrm{kg}}`。（参考资料公式示例为通用 LaTeX，仅作知识点对照。）
- **角度/度**：`\^{\circ}`，如 `60\^{\circ}`、`\theta=60\^{\circ}`。**禁止** Unicode `°`、禁止 `^o`/`^0`、禁止 `度` 字（如 `60度`）。
- **变化量（Δ）**：大写 `\Delta`，如 `\Delta E`、`\Delta s`、`\Delta t`。**禁止** Unicode `△`。
- **根号**：`\sqrt{被开方数}`，如 `\sqrt{v_x^{2}+v_y^{2}}`。**禁止** Unicode `√`、禁止 `sqrt()`。

> **渲染与查看（防误判）**：公式由内置 MathJax 3 运行时渲染，**必须用支持 JavaScript 的浏览器打开**（双击 `.html` 或 WorkBuddy 预览面板）。本技能已强制「单位正体」：生成稿单位一律正体——公式外纯文本（天然正体）或公式内 `\mathrm{}`（强制正体），任何查看环境都不会出现斜体单位；若仍看到斜体单位，是旧文件请重新生成。数学符号（`\Delta`、`\sqrt{}`、`^{\circ}`、`\theta`）须保留 LaTeX 命令，在 JS 浏览器正常渲染，在非 JS 查看器以源码出现属正常查看方式问题，并非生成缺陷。

## 8. 典型题型正解库（保证解析正确）

生成解析前，须对照下列「标准解题范式」与「正解示例」逐条自检，确保符号、公式、数值、单位均无误。

### 8.1 电磁学标准解题范式
1. 判明场的性质与方向：电场线 / 磁感线方向，电荷正负，电流方向。
2. 受力分析：电场力 $F=qE$ 恒沿场线方向（正电荷）；洛伦兹力 $F=qvB$ 由左手定则判定，**永不做功**。
3. 若带电粒子在匀强磁场中做匀速圆周运动：由 $qvB=m\dfrac{v^{2}}{r}$ 得半径，再求周期与圆心角。
4. 电磁感应问题：先求感应电动势，再求电流，最后求安培力与动力学方程。
5. 电路问题：先化简等效电阻，再用闭合电路欧姆定律 $I=\dfrac{\mathcal{E}}{R+r}$。
6. 量纲校验：$[E]=\,\mathrm{N/C}=\,\mathrm{V/m}$、$[B]=\,\mathrm{T}$、$[\Phi]=\,\mathrm{Wb}$、$[\mathcal{E}]=\,\mathrm{V}$。

### 8.2 正解示例
**例1 带电粒子在匀强磁场中的圆周运动**
- 半径：
$$ qvB=m\dfrac{v^{2}}{r}\;\Rightarrow\; r=\dfrac{mv}{qB}\tag{1}$$
- 周期：$T=\dfrac{2\pi r}{v}=\dfrac{2\pi m}{qB}$，**与速率 $v$ 无关**
- 动能不变：洛伦兹力始终与速度垂直，不做功，$E_k$ 恒定。
- 易错：把周期写成与 $v$ 有关；忽略磁场中圆周运动的圆心位置判定；混淆 $q$ 的正负导致偏转方向判错。

**例2 电场加速（带电粒子经电压 $U$ 由静止加速）**
- 动能定理：
$$ qU=\tfrac{1}{2}mv^{2}\;\Rightarrow\; v=\sqrt{\dfrac{2qU}{m}}\tag{2}$$
- 若有初速 $v_0$：
$$ \tfrac{1}{2}mv^{2}-\tfrac{1}{2}mv_0^{2}=qU\;\Rightarrow\; v=\sqrt{v_0^{2}+\dfrac{2qU}{m}}\tag{3}$$
- 易错：用 $W=qEd$ 时 $d$ 必须取**沿电场线方向的位移**，不是轨迹长度。

**例3 导体棒切割磁感线（导轨宽 $L$、总电阻 $R$、匀强磁场 $B$）**
- 感应电动势：$\mathcal{E}=BLv$（$B$、$L$、$v$ 两两垂直）
- 电流：
$$ I=\dfrac{\mathcal{E}}{R}=\dfrac{BLv}{R}\tag{4}$$
- 安培力（阻碍相对运动）：
$$ F=BIL=\dfrac{B^{2}L^{2}v}{R}\tag{5}$$
- 恒外力 $F_{\text{外}}$ 作用下的收尾速度：
$$ F_{\text{外}}=\dfrac{B^{2}L^{2}v_m}{R}\;\Rightarrow\; v_m=\dfrac{F_{\text{外}}R}{B^{2}L^{2}}\tag{6}$$
- 易错：电动势公式用瞬时速度，安培力也用瞬时速度；求热量须用能量守恒或积分，不能直接用 $I^{2}Rt$ 套平均电流。

**例4 闭合电路欧姆定律与功率**
- $I=\dfrac{\mathcal{E}}{R+r}$，路端电压 
$$ U=\mathcal{E}-Ir\tag{7}$$
- 电源输出功率 $P=UI=I^{2}R=\dfrac{\mathcal{E}^{2}R}{(R+r)^{2}}$，当 $R=r$ 时最大，
$$ P_{\max}=\dfrac{\mathcal{E}^{2}}{4r}\tag{8}$$
- 易错：输出功率最大（$R=r$）与效率最高（$R\gg r$，效率 $\eta=\dfrac{R}{R+r}\to 1$）是两回事，不可混淆。

- **[GEOMETRY_REVERSE_ENGINEERING] 几何反编译**：重绘前先反编译原题图几何——列出四类几何基元：① 顶点坐标（以画布左上角为原点的 X、Y 像素级相对位置）；② 线段/路径（起止点与曲率）；③ 角度标注弧位置；④ 文字锚点（m、F、v₀ 等精确落点）。**不得凭空「画」相似图形**。
- **[CANVAS_PIXEL] Canvas 2D 像素级 + 禁用 viewBox**：静态题图由 `drawStaticGraph(c)` 在左栏 `<canvas class="fig-canvas">` 上以 `t=0` 绘制，使用固定像素尺寸硬编码、像素级绘制；**严禁 SVG `viewBox` 通用缩放**（坐标会漂移）。
- **[TWIN_LOCK] 孪生锁定**：右栏动画直接复用 `drawStaticGraph()`；不动元素（斜面/地面/轨道轮廓/固定墙壁）只在背景层绘一次，移动元素（滑块/小球/箭头矢量）严格按解析运动方程（如 $x(t)=v_0t+\tfrac12at^2$）逐帧移动；**动画第 0 帧与左栏题图像素级重合**。
- **[CONSISTENCY_CHECKLIST] 一致性自检（生成 HTML 前于 CoT 隐式核对）**：[CHECK_1] 动图斜面角 θ 与左图**绝对相等**（同一 `const theta = 30 * Math.PI/180` 控制）；[CHECK_2] 矢量箭头长度比例与左图一致（如左图 $F=10\,\mathrm{N}$ 画 50px → 同一 `scale = 5px/N`）；[CHECK_3] 动图标签（$v$、$a$）移动时始终锚定物体同一相对位置（如右上角）。
- **[GREEK_SYMBOLS] 希腊角度符号禁中文名**：解析与动画中 $\theta$、$\alpha$、$\beta$、$\phi$、$\delta$ 一律用符号、禁「西塔/阿尔法/贝塔/斐/德尔塔」等中文名；时变角写 $\theta(t)$/$\phi(t)$。

### 9.1 总原则（图形位置无关）
- **无论图形在试题图片的哪个位置**，都必须完整、完美地提取并重绘/嵌入，**不得省略、裁切或只取局部**；多题同页时先切出目标图形区域（方式③）。
- **零臆造**：原题有什么画什么，不擅自增删辅助元素。

## 10. 通用强制条款（线条图形重绘 · 动画与解析严格对应 · 清晰真实）

本技能最新要求，适用于**本册涉及的全部题型**，生成解析与动画前必须逐条满足：

1. **文字 OCR 入文件（图片题强制）**：若题目以图片上传，先用 OCR（本地 `_build/ocr/run_ocr.py` 或 `yescan-ocr-universal` 技能 / Read 视觉转录）把题干文字**逐字**识别进 `PROBLEM`（title/given/asks/options），遵守「题干原文一致性」；选择题还须把 A/B/C/D 四项完整录入 `PROBLEM.options`（四项**单行横排优先、单行放不下则四行纵向排列**渲染；详见技能 SKILL.md「选择题选项录入（强制）」）；OCR 易错字符（`l↔1`、`O↔0`、`α↔a`、`×↔x` 等）须人工复核订正，禁止把错识字当原题。
2. **线条图形 1:1 重绘（强制）**：题图为线条图形（实/虚线、几何形状、字母标注）时，**按照原线条图形重新绘制成完全相同的线条图形**——优先用本册 §9 的 `FIG.*` 图元（或自定义 `ctx`）1:1 重绘；几何、线型、比例、角度、标注、填充 7 维度与原图一致；零臆造（原图没有的辅助线/法线/网格一律不画）。详见 `figures_redraw_spec.md` §6。
3. **公式排版规范（强制）**：本题所有公式（含题目原文与解析、含每问结论式）一律标准 LaTeX（见本册 §7 与 SKILL.md「公式排版规范」），禁 `/` 分数、`sqrt()`、`v0`、`sin()` 等代码风格。
4. **动画与解析严格对应·清晰真实（强制）**：动画是解析的**忠实可视化**——`STEPS` 每一步 `t0~t1` 对应动画该步状态；用同一 `stateAt(t)` 同时驱动画面与数据面板；位移/速度/受力由**解析同一套公式与参数**实时计算，真实比例与数量级、绝不夸张扭曲；关键状态（最高点/碰撞/脱离/换路）高亮或 `FIG.processBanner` 明示，清晰可懂。
5. **解析禁用微积分（强制）**：写解析一律**不得使用微积分**（`\int`、`d/dt`、`\dot{x}`、微分方程），必须用**高中物理方法**：电荷量用 `q=It`，电流线性变化取**平均电流** `\bar{I}=(I_1+I_2)/2`（I–t 图像梯形面积）；焦耳热用 `Q=I^2Rt`，电流线性变化取 `I^2` 的时间平均 `(I_1^2+I_1I_2+I_2^2)/3`（I–t 图像下抛物线弓形面积）；速度 / 位移用动量定理 `m\Delta v=BIL\Delta t=BLq`、能量守恒、图像斜率与面积，**绝不解微分方程**。`note` 允许「图像面积 / 平均值 / 抛物线弓形」等高中表述，但 `tex` **不得出现 `\int`**；校验：Playwright 检查页面文本不含 `∫` 或 `\int`。

6. **知识点分行显示·不覆盖解析（强制）**：`PROBLEM.knowledgePoints` 引用的每条知识点均**独立成卡、逐行排列（分行显示）**渲染——每个知识点占一行纵向堆叠，绝不挤成一行横排或逗号连写；卡片**只出现在左栏「试题原题」下方**（模板 `#kpInlineCards`），**绝不放入或覆盖中间「详细解析」栏**；相关知识点较多时仍保持逐行堆叠、左栏自然延伸，与中间解析板块无任何重叠遮挡。校验：Playwright 检查所有 `.kp-card` 均位于 `.col-problem` 内、`.col-analysis` 内不含任何 `.kp-card` 子元素。


8. **动画物理引擎 · 矢量可视化 · 公式零错误（强制）**：动画每一帧必须由**物理方程逐帧数值积分**得出（如 $x=x_0+v_0t+\tfrac12at^2$、简谐 $x=A\cos(\omega t+\phi)$、圆周 $x=R\cos(\omega t+\phi_0)$、竖直圆周用能量守恒 $v(\theta)=\sqrt{v_0^{2}+2gR(\cos\theta_0-\cos\theta)}$），**严禁用线性插值（Lerp）模拟物理运动**（匀速直线除外）；动力学场景须绘制受力分析（重力/弹力/摩擦力/向心力）与速度/加速度矢量箭头，箭头长度按比例缩放反映大小；所有矢量（速度/加速度/力）用带箭头线段表示，大小近零时自动淡出消失避免杂乱；抛体/圆周/振动开启「轨迹追踪」用浅灰虚线绘历史路径；画布建立合适坐标系（原点居中或左下、边缘显示坐标轴/刻度）。公式渲染**零错误**：所有 LaTeX 合法、无 `Math input error`；校验：Playwright 检查 `mjx-container.mjx-error` 数量为 0 且页面文本不含 `Math input error`。
